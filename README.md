# 中学物理实验室（CN Physics Lab）

当前工作区为 0.2.0-dev.1 / M8/M9 任务 16，包含 J-OPT-01 光的反射定律、J-OPT-03 平面镜成像、J-MECH-03 浮力、J-MEAS-01 固体和液体密度测量，以及 H-MECH-04 单摆测 g、H-MECH-03 小车加速度与力、质量和 H-ELEC-01 电源电动势与内阻实验，首批六项保持。原创代码、文字和 SVG/CSS 由 jerryshi1968 授权采用 Apache-2.0；第三方内容保留原声明。第二名教师、逐项教材和实体设备待核验项仍保留，开发扩展不代表这些门槛已经通过。

点击“高中物理实验 → 电学实验”，选择电源电动势与内阻的理想表参考、内接或外接；也可选择“空白搭建恒定电流实验”自由搭建。预接线开关断开；选电源可即时设置电动势 E 和内阻 r，原来的电表可以设置 RA、RV。电压表统一称“内阻”，勾选“理想电压表”显示 ∞，取消后使用有限内阻，新建默认 1,000,000 Ω；初中电表默认理想。闭合后调滑动变阻器，采集或手工抄录至少五个不同电流的 U、I，在“图线”查看散点、拟合线、E测、r测及 R²。内外接法按实际导线识别；配置与来源不同自动分系列，不用模型真值替换记录。支持原始记录与拟合 CSV、保存加载和 JSON。详见[模型与手算基准](docs/models/emf-experiment.md)、[需求卡](docs/requirements/H-ELEC-01.md)。

顶部实验入口统一为“初中物理实验”和“高中物理实验”。在对话框按力学、电学、光学分类，选择条目后进入原有预览确认流程；初中 19 项、高中 12 项。通用光学空白按已放器材确定兼容模型，共用刻度尺不提前锁定，互斥器材直接禁用；高中恒定电流空白使用通用电路记录。详见[实验目录与自由搭建规则](docs/experiment-catalog.md)。

单摆入口：“高中物理实验 → 力学实验 → 单摆测重力加速度实验”（或空白搭建）。新增单摆，复用支架、刻度尺和计时器；右侧可直接调整重力加速度，默认 9.81 m/s²。摆长量悬点到球心，设置周期数后释放。支持拖动摆球调角、多周期计时、毫米刻度放大、原始读数计算 g、T²–L 拟合和 CSV。大摆角采用非线性周期；教材映射待核验。详见[模型与独立基准](docs/models/pendulum-experiment.md)。

点击“初中物理实验 → 力学实验”，选择浮力影响因素、阿基米德原理或空白搭建。把测力计挂到支架，圆柱体挂到下端，拖动测力计逐渐浸入。验证排液时先称空接液杯，给溢水杯补液，再收集并称量排液。各阶段自行读数，选择来源计算、绘图和导出。[浮力模型与手算基准](docs/models/buoyancy.md)

点击“初中物理实验 → 光学实验 → 平面镜成像实验”，在镜前移动观察眼，在镜后移动对照物。用视差确定像位，再用刻度尺量物距、像距和高度，最后把光屏移到像位观察。[平面镜模型与手算基准](docs/models/mirror-image.md)

点击“高中物理实验 → 力学实验 → 加速度与力、质量实验”，可使用带定滑轮的水平轨道、动力学小车、光电门和打点计时器。把车上配重和悬挂质量作为控制变量，暂停或结束后记录光电门或纸带读数，可画 `a–F`、`a–1/M`、`x–t` 和 `x–t²` 图。系统质量包含小车、车上配重和悬挂总质量。[小车模型与基准](docs/models/cart-experiment.md)

点击“初中物理实验 → 力学实验”，选择测量固体密度、测量液体密度或空白搭建密度测量实验。新增五件器材在“力学”页签；不需要后端。

1. 游码归零、两盘空载时调节“调零螺母”，观察指针对准中央；无需额外确认。固体或烧杯拖到左盘，也可用位置下拉选择；点砝码加入/取回右盘，再移动游码，每格0.2 g。砝码盒可拖到右盘关联，左盘一次放一件待测物。
2. 固体：称质量，移开后平视量筒原液面，放固体入量筒，完全浸没后再读液面。可移动固体或用“提起固体”滑条比较部分浸没，未完全浸没不能用来求总体积。
3. 液体：称烧杯和液体总质量 m1，用“从烧杯倒入量筒”转移部分液体，重新调砝码称余液和烧杯总质量 m2，平视量筒读 V。量筒起初应空，ρ=(m1−m2)/V；换液体前先清空两个容器。
4. 展开下方记录区，每阶段手工输入 g/mL 后保存，选择三条同组来源再计算密度；模型不代填。固体默认参考54 g、50→70 mL；液体默认参考110→80 g、30 mL。记录/图线/CSV用g、mL、g/cm³，内部/JSON用SI。
5. 支持鼠标、触摸和键盘、撤销重做、保存加载、JSON和CSV。修改来源后明确重算，旧结果保留；删除来源行不删除结果引用的快照。未调零/失衡/超量程、俯仰视、溢出或未浸没有明确提示。

范围与独立基准见[密度模型](docs/models/density-experiment.md)，实际检查见[密度验收](docs/acceptance/M8-DENSITY.md)。教材映射仍待核验，当前不模拟吸水、溶解、挂壁、浮体压入或倒液动画。

点击“初中物理实验 → 光学实验”，选择光的反射定律实验或通用光学空白，预览确认后开始；器材库“光学”页签也可找到新增五件器材。

1. 独立摆放平面镜、光源、可折纸板、半圆量角器和法线标记，移动/转动光源瞄准镜面。校准按钮只在点击时对齐指定器材；“光源圆周方位角”会明确移动并转动光源。
2. 展开纸板，零线沿法线，读 1° 分度量角器。改变入射方向至少三组，自行填写入射角、反射角和观察；数据不会用理论代填。
3. 鼠标/触摸折角滑条或键盘箭头折起右板，观察连续光迹消失，展开复现。右侧空间观察图显示折板几何；自由空间光路与理论默认关闭。光仍传播，正入射沿折轴是不能证明共面的特殊情况。
4. 下方角度摘要用 °，通用记录/图线/CSV 用 SI rad，原始度数、折角和观察随快照保留；支持撤销、保存加载、JSON 和 CSV。折动预览时不能采样，离板/未校准不输出正常角度。

点击“高中物理实验 → 力学实验”，选择平抛运动实验或对应空白搭建，预览确认后开始。默认 h=1.25 m、v0=2 m/s、g=10 m/s²；教材具体条目仍待教师核验。

1. 将小球装入发射器，摆好水平地面和二维标尺。可拖小球到枪口松手，也可用装配下拉；选发射器修改初速/转角，面板可设置相对地面的高度并主动校准水平。发射前可在放大读尺窗估读发射点与地面的竖尺读数，手工填写后相减测得高度。
2. 点击“发射 / 重新发射”，或直接“单步 Δt”；支持暂停、继续与重置。小球、计时和等时位置标记共用同一时间，跨落地帧仍准确停在地面，不穿地续跑。
3. 运行中编辑只配置下一次，本次轨迹和时钟保留发射初态。需要新参数时重新发射；已有飞行中的小球不直接拖动，可先重置。理论辅助默认关闭，等时标记按需开启。
4. 暂停或单步后，在放大窗上读取本次起点与小球的横/竖尺位置，cm 换算为 m，并抄录计时。两个方向分别相减得到 x 与向下位移 ydrop；不要用世界 y 代替向下位移。至少记录三组落地前数据，落地后还可记落地时间和射程。
5. “图线”比较 x–t、ydrop–t²，同次轨迹用至少三点拟合斜率；固定高度改初速、固定初速改高度要重新发射，图中按运行分别成组。默认三点预期斜率为 2 m/s、5 m/s²；图与拟合只读学生记录，不拿模型值填表。
6. CSV/JSON、本地保存与加载保留两套快照：本次真实发射初态、采样时待发配置。保存不续跑，刷新或同文档导入后重新准备。独立演示：`node scripts/projectile-experiment-demo.mjs`。

模型与限制见[平抛说明](docs/models/projectile-experiment.md)，真实检查与截图见[任务 13 验收](docs/acceptance/M6-TASK13.md)。

点击“高中物理实验 → 力学实验”，选择胡克定律探究实验或弹簧空白搭建，预览后确认。高中教材具体版次、章节和页码仍待教师核验。

1. 将弹簧安装到支架横臂，独立尺竖直向下摆在弹簧旁。默认器材起点已安装，钩码尚未挂接，盘质量为零；放大读尺窗只标两端，不填数字答案。
2. 无挂码且盘质量为零时读原长 L0；拖钩码上钩到弹簧下端，或用装配下拉挂接。其余钩码接下挂钩串成一串，不能重叠挂到同一点。修改质量立即更新静态长度，移开即卸载。
3. 下方填写上端/下端读数、无载原长及钩码质量（不含盘）。刻度标数为 cm，换算为 m；总长 L=下端−上端，形变量 Δx=L−L0，F=(所填钩码质量+配置盘质量)g。记录至少五个不同工作点，并保留卸载复测点。
4. 切到“图线”查看 F–Δx 和最小二乘斜率 k（N/m）、截距及 R²。图线与拟合只用记录值，缺失不补零，不用隐藏的劲度系数代替拟合；同组配置改变请另分组。CSV/JSON、保存重载保留原读数、阶段及装配快照。
5. 超线性范围、额定载荷、支架容量或移动预览中不采样；不模拟振动或塑性。可关闭的理论辅助仅供核对。独立演示：`node scripts/spring-experiment-demo.mjs`。

详见[弹簧模型与读尺](docs/models/spring-experiment.md)及[任务 12 实际验收](docs/acceptance/M6-TASK12.md)。

点击“初中物理实验 → 力学实验”，选择滑动摩擦实验或对应空白搭建，预览后确认。空白时在木块装配区选择接触面、测力计及可选牵引器，再“放到接触面上”；不安装牵引器也可直接控力。

1. 选择匀速牵引或可控水平拉力，点击“开始牵引”；支持暂停、单步、重置和正负方向。鼠标拖动只改初态，不产生牛顿读数。
2. 等“滑动稳态”后读表；静止、启动和加速阶段不能把牵引力当作滑动摩擦力。可记录非稳态标签和真实牵引示数，异常摩擦值不作为图点。
3. 在同一材料/面积下改变木块质量，或把砝码拖到块顶加载；同一质量下改木板/布面，再保持质量/材料改变接触面积。条件变化重置运动，牵引控制可运行中调整。
4. 下方记录区选择手工抄表或仪表采集，保存压力、牵引力和滑动摩擦力及材料/面积/时刻快照；可画 F–N 图、导出 CSV/JSON、保存加载。保存的是初态与记录，重载从 t=0 重跑。

模型限水平干摩擦，不模拟斜拉或复杂碰撞；Matter.js 只表示形状/接触，自研模型独占轨迹与教学摩擦。见[模型](docs/models/friction-experiment.md)、[验收](docs/acceptance/M5-TASK11.md)。独立运行 `node scripts/friction-demo.mjs` 可查看三组手算基准与步长收敛结果。

点击“初中物理实验 → 力学实验”，选择杠杆平衡实验或对应空白搭建，预览确认后开始。器材库的“力学”页签在默认工作台也始终可见，空白场景可直接放置力学器材。

1. 将杠杆安装到支架（起点器材已安装），无挂载时调节右侧“左端/右端平衡螺母”的滑条或每次 1 mm 的按钮，观察杆由倾斜变为水平，再点击“确认空载调平”。中部块与手填转角入口已移除；默认理想测量忽略已经调平的杆和螺母自重，空载准备始终按实物重心计算。详见[两端螺母说明](docs/models/lever-end-nuts.md)。
2. 拖钩码到挂点附近松手，或选中器材，在“器材挂接”中选择杠杆和编号，设置立即生效。移动支架/杠杆后挂载跟随，拖离或选择“不挂接”可解除。
3. 修改质量、挂点与测力计施加拉力/方向，观察平衡或顺/逆时针趋势。失衡时画布会明显向对应一侧倾斜，钩码跟随；虚线保留计算时的原位置，倾斜角仅作趋势示意，不用于读尺或写入模型。方向 0° 向右、90° 向上、−90° 向下，−30° 为右下斜拉；不自动改力或挂点。改变支点、调平配置或自重后，需卸载重新空载调平。
4. 自行摆放独立刻度尺、缩放读细格；斜拉力臂是支点到作用线的垂距。按需打开“显示力、作用线与理论”核对，关闭不改装置；目标拉力只在约束可唯一求解时显示。
5. 在记录表填写各力和力臂、判断力矩方向，由本组手工输入相乘形成有符号力矩，至少记录三组。学生输入与理论真值分开，空值和超量程不补零；图线比较多组力矩，CSV/JSON、保存刷新保留受力挂接和方向。

搭建操作：

1. 点击器材卡片，再点击画布放置；也可拖入，或使用“在视口中心放置”走键盘路径。
2. 选中器材或从“选择器材”列表选择，修改位置 m、转角 °、电源电压 V/电阻 Ω 或开关闭合状态后立即生效，无需“应用属性”。空白、未输完或不满足约束的数值不覆盖当前有效值，失焦或按 Esc 恢复。器材也可拖动，获焦后方向键每次移动 0.01 m。
3. 将“导线”卡片拖入画布，或选择后点击放置。未接线时可拖动线身移动整根线；拖动线头到接线柱附近，松手吸附连接。两端都接好后才形成电气连接，多根线可以共用器材接线柱；交叉不会自动导通。也保留依次点两个接线柱快速添线的方式。
4. 选中导线后，拖动黄色弯曲点调整曲线，或用方向键移动弯曲点；已接线时也可拖动线身弯曲。属性区可添加/清除弯曲点、拔开线头，或先选择“连接线头 A/B”再点目标接线柱。Escape/取消终止待接线；颜色切换仅改变所有导线的本次视图样式，不写入连接图。
5. 使用滚轮/缩放按钮、平移模式拖动空白处或画布方向键调整视图；物理参数与连接不随缩放改变。点击选中器材，按住 Shift 点击可增选/取消选中，按 Delete 删除所选器材；属性区也可删除单件或多件。相连导线保留，原接线头在原位置变成自由线头，弯曲点和另一端接线保持，可重新连接。选中导线时 Delete 删除该导线；在输入框中按 Delete 只编辑文字。
6. 使用实验区域右上角“撤销/重做”，或 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z / Ctrl/Cmd+Y。一次拖拽或多选删除为一步，撤销删除会恢复器材及其原接线；输入框保留文本撤销。平移/缩放不占编辑历史。
7. 选中电池、电流表、电压表等器材后点属性区“左右翻转”；接线柱与导线一起跟随，图中文字保持正向。翻转支持撤销/重做和保存。
8. 电流表串联、电压表并联，均接公共端和一个正量程端；两个正量程端同时接线会诊断报错。默认自动计算，直接点击/触摸开关刀柄，或用 Enter/Space、属性复选框开合，灯泡亮度和表针随实际电路自动更新，无需启动按钮。改接线/参数、加载/刷新实验也会自动计算；可显式“暂停自动更新”，随后“恢复自动更新”，或用“重新计算”清除旧结果再重算。反偏、超量程和求解失败会明确提示，不沿用旧值。
9. 电表外圈显示大量程、内圈显示小量程，两圈同时保留并高亮当前接线档。导线 A/B 为线头标识，已连接线头不再在表盘旁叠加字母；可悬停或在属性区查看线头身份。
10. 四柱滑动变阻器下柱 A/B 为电阻丝两端，上柱 C/D 共用滑片。接一上一下调阻，接 A-B 恒为全阻，接 C-D 直接导通。拖动红色滑片，或获焦后用方向键（Shift 加快）、Home/End 调整；Escape 取消拖动。拖动预览不写入保存或测量记录，松手并完成计算后再采集。独立演示：`node scripts/rheostat-demo.mjs`。

保存与分享：

- 点击标题旁“修改名称”，输入实验名称后按 Enter 或“确定名称”；名称不能为空、最多 200 个字符。改名可撤销/重做，点击“保存”后下次打开保留，导出文件名随实验名称改变。
- 点击“保存”手动保存当前实验；不同实验分别保存，同一个实验再次保存只更新它自己，改名不会另建一份。“新建实验”生成独立实验，不覆盖其他保存；同名实验也可并存。“加载”显示实验列表，选择后预览确认加载。下次打开或刷新仍自动恢复最近一次保存的实验。
- 删除保存：点击“加载”，在对应实验旁点“删除”，核对名称后“确定删除”。只移除本地保存，当前工作台保留；若删除当前实验的保存，会标为“尚未保存”，可再次保存。删除无法撤销；删除最近保存后，刷新恢复其他最近保存的实验，没有剩余则打开空白实验。
- 点击“导出”下载 JSON 备份；“导入”选择文件，校验通过并确认预览后才替换当前工作，取消或坏文件不影响原场景。支持格式 2 和旧格式 1 的显式迁移；未知器材或版本会拒绝，文件上限 5 MiB、200 器材、500 连接、10000 记录。
- 本地保存只在同一浏览器配置和同一地址源内有效；127.0.0.1 与 localhost、开发 5173 与预览 4173 不共享。换设备、浏览器或地址请用 JSON 导入导出。
- 旧版单槽保存升级后，仍存在的那份实验会加入列表并保留原始备份；旧版已经被覆盖且没有导出备份的实验，无法由本次升级恢复。多实验说明与实际验证见[验收记录](docs/acceptance/M1-MULTI-SAVE.md)。
- 保存文件包含实验初态、配置、记录和视口，重载后从初态重新运行；撤销历史与导线共用颜色不跨刷新恢复。当前历史各栈最多 100 项 / 20 MiB 文本估算，详见[持久化说明](docs/models/history-and-persistence.md)。

电源—电阻—开关的最小回路可连接“电源正极→电阻 A，电阻 B→开关 A，开关 B→电源负极”，闭合开关即自动更新；串入电流表即可读电流，也可将电阻换成小灯泡观察发光。坐标公式、端口和触摸边界见[工作台说明](docs/models/workbench.md)。

测量与导出：

1. 在下方“记录表”点击“展开记录区”，勾选要记录的电表，填写组别/接法和测点名称。
2. 点击“采集仪表示数”记录按分度值显示的数值；或自己读表填写空白输入框，再“保存手工抄表”。留空记缺失，异常只记录状态，不填正常值。模型真值不会覆盖手工输入。
3. 采样后优先显示记录表；“展开测点与抄表”可继续设置。手工行可修订或删除，均可撤销；“追溯详情”保留采样时的原文、仪表显示、模型真值、参数和接线，后续改电路不改旧记录。
4. 切到“图线”，选择电流或电压多测点比较；图线使用表格有效值，缺失/异常断线，不补零。
5. “导出 CSV”下载全部记录及追溯信息；同组完整接线/器材快照附在首行，其余行以采样标识引用。继续使用顶部“保存”或 JSON“导出”保存完整实验，CSV 不能直接作为实验导入文件。
