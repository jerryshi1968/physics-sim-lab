更新：2026-11-12。顶部实验入口固定为“初中物理实验”和“高中物理实验”；保存、加载、导入、导出和新建实验保留。目录数据统一位于 `src/experiments/catalog.ts`，界面不通过实验名称决定物理模型。

共 33 项。每项显示名称与一句说明；没有高中光学内容时不显示对应页签。所有空白项的实验台初态均为零器材，不以“空白”名义预放一套装置。液体密度预放空量筒与盛液烧杯，沿用倒出前后称重法；固体密度使用盛水量筒。

初中电学仅保留一个“空白搭建电学实验”（J-ELEC-FREE）。进入后右侧选择普通记录、I–U 探究或 I–1/R 探究；模式切换只切换记录校验和图线，不替换器材、导线、文档身份或已有记录。通用空白的器材仍可自由组合；专用探究需要满足其接线条件。I–U 和 I–1/R 两个预搭建入口保留，旧 J-ELEC-02 空白存档继续加载。

流程为学段按钮 → 学科页签 → 选择条目 → “进入实验” → 原有起点预览/确认替换。原来各实验独立的起点选择窗口不再作为入口。目录选择、切换页签与取消不改变当前实验；确认替换后沿用既有清历史、从初态运行和保存标记处理。

桌面与平板使用有最大高度的对话框，列表内部滚动，标题、学科页签和底部操作区保留可见；手机为单列卡片。支持 Tab、单选框方向键、学科页签左右键/Home/End、Esc 取消及触摸。器材库明确的“新建某学科实验”也进入同一目录并定位学科；高中没有光学条目时，主动新建光学转到初中光学目录。选择器材本身继续执行禁用规则，不打开目录。

## 光学空白的模型归属

通用光学空白使用 `J-OPT-FREE`，不沿用凸透镜空白身份。初始视口不带透镜实验的横向偏移；独立尺是被动工具，不单独指定模型。已放器材与各模型支持范围求兼容集合：

- 尚有多个兼容模型时，仅显示“光学自由搭建”，不提前调用透镜观察或输出正常读数。
- 凸透镜、蜡烛或光具座等确定透镜模型；平面镜本身保留反射/平面镜成像两种可能。
- 平面镜配可折纸板、光源、量角器或法线标记确定反射；配成像标记物、对照物、观察眼或光屏确定平面镜成像。
- 某模型确定后，器材库禁用与当前装置互斥的器材；点击、键盘放置、拖入和中心放置共用检查。新器材不能抢占已放器材确定的范围。
- 删除或撤销后按剩余器材重新判断，不隐式增删器材、重建文档或清空已有记录。保存重载保留自由搭建身份并得到相同结果。
- 导入混合互斥器材时保留原装置，说明冲突并停止领域结果；不静默选择其中一种模型输出正常值。

画布、观察面板、属性、记录和模型说明共同使用 `equipmentSupport` 的判定，不能只放开器材卡片。光学自由反射允许独立尺作为被动工具，尺的位置、长度与翻转不参与反射方程；正式 `J-OPT-01` 的原支持范围保持。该工具不构成新的光学耦合模型，不支持把透镜和镜面混合成任意多元件光路。

## 电学空白与兼容

初中电学空白使用 `J-ELEC-FREE`，高中恒定电流空白使用 `H-ELEC-FREE`。共用已有电路搭建与直流求解能力，源/表内阻仍可显式设置，使用通用电学记录；高中空白不会直接绑定电动势成组记录。初中空白保留可展开的灯泡串并联指导，指导不改变接线或求解。

三种电动势起点继续使用 `H-ELEC-01`，实际接线、加载公式、成组观测与五点拟合不变。其他既有模板 ID、物理参数、坐标与初态保留；新建文档标题采用目录中的名称。已有存档不重命名、不替换 ID，不增加强制迁移字段或改变 JSON 版本。各实验已有手机视口缩放继续沿用，包括平抛的 128 px/m。

课程与教材映射继续保持 `pending_teacher_review`。本次改变入口、分组及自由搭建调度，不代表教材条目或实体课堂验收完成。实际检查见[本轮验收](acceptance/M9-EXPERIMENT-CATALOG.md)。
