# J-OPT-01：探究光的反射定律

主学段：初中。任务 16 / M8；仅此一项第 9.2 节扩展，属于 0.2.0-dev.1 开发内容，不追加到原 v0.1 必做六实验或冻结候选包。

## 目标与操作

从器材库光学页签放置平面镜、窄光束光源、半圆量角器、法线与可折承接纸板。独立摆放、瞄准并校准原点/零线；从法线读角，至少三组改变入射方向，手工比较 i 与 r。折起右板观察连续反射光迹的变化，展开复现；不能把光迹不在板上理解成光消失。

## 空间证据与测量

实际三维射线—有限承接面裁剪，纸板绕法线折转而自由空间反射方向保持。i=30°、折起 30° 时，反射光前进 0.20 m 后距右板平面 0.05 m；正入射沿折轴为不能证明共面的退化对照。从右侧入射而光在固定左板，也不作为右板共面证据。

1° 分度量角器；手工 ° 输入转换 SI rad，原文和定性判断随场景快照追溯。失校准/离板/边界异常不输出正常角度读数；图线、CSV、JSON 和保存加载共用原记录，不用理论填表。模型角差门槛 ≤1e−6 rad。
