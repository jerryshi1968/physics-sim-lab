# J-MECH-09 测量滑轮组的机械效率

- 学段与入口：初中物理 → 力学，一个预搭建入口，不增加重复空白条目。
- 课程主题：有用功、总功、机械效率与滑轮组；教材版次/册次/章节/页码、审阅人和审阅日期待核验，状态 `pending_teacher_review`。
- 器材：全部复用支架、两只现有滑轮、测力计、钩码和两把独立尺。
- 流程：先直接称重，再装成一定一动滑轮组；选择支架/动轮挂钩固定绳端，沿对应方向缓慢拉绳，读 F、h、s；改变钩码数量并重复至少三次。
- 数据：学生手填 G/F 和四个位置，转换单位后计算 W有用=Gh、W总=Fs、η；保留原始/修订、缺失/异常、来源、CSV/JSON 与保存加载。
- 模型：两股/三股竖直绳承重、准静态、忽略摩擦，默认计入动滑轮 50 g 自重；绳长和两轮位移/转角一致，不以固定百分比生成效率。
- 交互：直接鼠标/触摸提拉、两轮点选、质量步进、挂接、取消/一次撤销、删除引用保护、读尺与测力计放大。
- 边界：装配、量程/承载、接触、尺覆盖不满足时不输出正常读数；缺失与零分母不生成效率，超过 100% 显示核对提示。
- 验收：独立手算/绳长/功和效率、三组实际浏览器操作、首批六实验代表回归、窄屏及 WebKit 模拟；实体课堂与教材待教师核验。

- 绕法追加：右侧选择支架固定绳头（2 段、向下拉）或动滑轮上挂钩固定绳头（3 段、向上拉）；记录保留各次绕法，兼容 v1 旧数据。任意多滑轮自由绕线暂缓，不能只增加图形而没有相应连接与约束模型。
