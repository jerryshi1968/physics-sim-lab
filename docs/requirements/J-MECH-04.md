# J-MECH-04：测量物体运动的平均速度

学段：初中；分类：力学。依据用户提供的实验图片实施，不根据图片推断教材版次、章节页码或审阅结论；映射保持 `pending_teacher_review`。

- 初中力学新增“测量物体运动的平均速度”和一个空白搭建入口。
- 复用已有动力学小车、轨道、木块、独立刻度尺和计时器；只新增金属挡片。斜面场景采用木板外观，不携带高中小车实验的滑轮、悬挂砝码或挡光片效果。
- 预搭建右高左低的小坡度装置。静止释放小车，同步计时，到挡片时停止；先测全程，再将挡片移至中部，从相同起点重新释放测上半程。
- 金属挡片和小车可拖到斜面上吸附；坡度和属性即时生效，改变关键初态须重新释放。支持暂停、继续、单步与慢放，播放速度不改变计时的物理时间。
- 刻度尺沿斜面放置，读取释放前同一车头与挡片的尺读数；提供毫米格放大尺和横向滚动。学生填写读数及时间，或显式采集停表时间，不自动填写路程和速度。
- 表格包含路程、运动时间、平均速度；s 为尺读数差，v=s/t。零路程、零时间、缺失或无效记录不输出正常平均速度。两个路段保留各自的独立测量。
- 复用原始记录、冻结快照、修订、删除、撤销、CSV/JSON 和保存加载。运行位置不覆盖小车初态，重载回到原起点、停表归零。
- 提供独立数值基准、边界、手机/平板模拟和首批六实验回归；课堂、教材和实体设备仍待教师核验。
