# H-ELEC-01：测量电源电动势与内阻

来源：实施文档 9.2“电源电动势与内阻 | 有限内阻源、电表加载、U-I 拟合、内外接法”，任务 16 高中扩展。

1. 用已有电源的可选内阻参数建立有限内阻源；兼容旧的理想电源。源内耗参与功率守恒，短路按显式内阻处理，不引入隐藏小电阻。
2. 提供理想表参考、内接、外接及空白起点，开关初态断开。器材库仅启用电源、双量程表、开关、电阻、四柱变阻器和导线，不点击器材切换实验。
3. 源与电表参数即时生效，接法从真实导线识别；明确电压表跨电源端或跨负载，比较电流表分压和电压表分流。
4. 同一求解回复成对采样 I、U，支持手工估读和按分度值采集。保留参数、接线、模型真值与显示值快照，异常与缺失不作正常值。
5. 至少五个不同电流作 U=b+kI 普通最小二乘，散点、拟合线、E测、r测、R²可观察；配置、接法与来源分系列，修订与删除能更新拟合。
6. 保留命令历史、保存加载、JSON 与原始记录 CSV，另支持拟合 CSV。工程回归覆盖独立物理预期、加载误差、读数舍入、无效状态及旧实验。

物理与边界详见[模型说明](../models/emf-experiment.md)，工程记录见[验收记录](../acceptance/M9-EMF.md)。教材映射、版次、章节、页码、审阅人和审阅日期均保持 `pending_teacher_review`。
