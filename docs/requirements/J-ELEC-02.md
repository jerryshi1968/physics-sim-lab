# J-ELEC-02：电流与电压、电阻的关系

来源：实施方案 9.2 与任务 16；入口在“初中物理实验 → 电学实验”。本次仅实现此扩展，不实施伏安法测未知电阻 J-ELEC-03。

1. 全部使用现成器材：电池盒、开关、定值电阻、电流表、电压表、四柱滑动变阻器和导线；不新增器材类型或另一套电表/变阻器。
2. 提供 I–U、I–1/R 两个器材起点。空白搭建统一使用初中通用电学空白，右侧可选普通记录或两种探究模式，目录不再单列专用空白入口。器材起点开关断开，6 V 理想源，50 Ω 变阻器从最大接入阻值开始，电流表 0～0.6 A、电压表 0～3 V，电压表默认理想。
3. I–U 保持本组定值电阻不变，通过滑片改变电阻两端电压；I–1/R 替换 5/10/15/20/25 Ω 电阻，调节滑片保持目标电压，默认 2 V、允许偏差 ±0.05 V。可即时修改控制目标；不自动稳压、不自动改滑片。
4. 替换以现有定值电阻的阻值切换实现，保留器材 ID、位置和导线。先断开开关；右侧替换按钮及属性修改共用此要求。仍可在属性区设置其他正阻值。
5. 由实际接线校验串并联、电表极性和量程、四柱变阻器的一上一下接法；不以器材摆放或图线名称假定接线正确。
6. 手工读表或显式采集一组 I、U；标称 R 从该次器材配置取值并明确标注，不伪称测得的未知电阻。每次冻结接线、量程、控制目标与仪表示数，不将模型真值补进学生输入。
7. 未保持 R 或目标 U 的记录保留并标记，不进入拟合；缺失、反接、超量程、删去半组或旧结果也不生成正常图点。修改手工源记录后重新检查、重算。
8. I 为纵轴，U 或 1/R 为横轴；至少五个不同横坐标进行保留截距的最小二乘拟合，显示斜率、截距和 R²。按组别、关系、来源、控制目标和器材配置分系列。支持图线/检查 CSV、既有原始记录 CSV、JSON、本地保存和撤销。

模型及独立预期见[模型说明](../models/ohm-experiment.md)，实际结果见[验收](../acceptance/M9-OHM.md)。课程具体条目、教材版次、册次、章节、页码仍为 `pending_teacher_review`，审阅人和审阅日期保持空缺。
