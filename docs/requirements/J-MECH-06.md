# J-MECH-06 探究二力平衡的条件

- 初中物理 → 力学实验，一个预搭建入口，不增加重复空白项。
- 复用现有小车、水平轨道和钩码；本实验将轨道显示为双定滑轮光滑水平台，不增加器材类型。
- 比较两端质量不等、相等，以及等质量扭转后释放；小车可在水平面内平动和转动，支持非零初速度对照。
- 鼠标/触摸弯箭头、键盘或角度设置扭转；质量和初态参数立即生效，放大观察、释放/暂停/继续、单步、倍速与重置。
- 两绳始终接在同一辆车上，不声称提供“分别作用于两个物体”的对照。竖直重力/支持力抵消，研究水平两力。
- 手工记录两侧总质量、大小/方向/共线/运动状态和备注，缺失不补零、现象不代填；CSV/JSON、修订、来源快照及保存加载。
- 图线页呈现条件与现象对照表，不把定性选择自动转换为拟合或平衡结论。
- 无阻尼理想绳轮模型，移动/转动由耦合动力学给出；边界停止，不输出越界后正常观察。
- 用户教材图片只作流程参考，未复制图文；版次、章节、页码、教师审阅与实体课堂状态均保持 `pending_teacher_review`。
