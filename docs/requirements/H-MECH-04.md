# H-MECH-04：用单摆测量重力加速度

来源：实施方案 9.2 与任务 16。目录位置为“高中物理实验 → 力学实验”，提供器材起点及零器材的空白搭建。

1. 新增单摆（夹头、摆线、摆球），复用支架、力学独立刻度尺与计时器，不新增另一种外观相同的秒表。单摆可挂接或拖离支架；静止准备时拖动摆球改变释放角度，属性即时生效。
2. 区分摆线长度和摆长：有效摆长 L 从悬点到球心，等于摆线长度加球半径。尺可自由摆放，竖直向下时提供毫米分度放大窗；学生自行填写悬点、最低位置球心的尺读数。
3. 释放时从端点开始计时，返回同一端点为一个完整周期。可设 1、5、10、20、30、50 个完整周期；到达 N 周期事件后准确停止。提供暂停、继续、单步、播放速度及重置。计时器是理想自动计数计时，不模拟人的反应时。
4. 重力加速度在右侧可直接设置，默认 g=9.81 m/s²；L=0.5 m、5°；推荐测 g 时不超过 5°。允许 ±60°，采用非线性周期和轨迹，研究角度对周期及小角公式表观 g 的影响。质量变化不改变理想周期。
5. 记录原始尺读数、N、t，计算 L、T=t/N、g=4π²L/T²；原始值修订或删除后重新计算。按相同组、摆角、球半径、质量及 g 分组；至少五个不同小角摆长拟合 T²–L，由斜率求 g。大角记录保留但不混入小角拟合。
6. 记录含装置、配置、计时窗口快照；支持既有撤销、CSV、JSON 和本地保存加载。摆动装置或计时参数变动清除当前计时，独立尺可在计时后移动，重新打开文件从初态开始，不恢复动画时间。
