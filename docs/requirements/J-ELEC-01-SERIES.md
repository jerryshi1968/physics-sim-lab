# 探究串联电路中各处电流的关系

2026-11-24，按教师三张装置图片、三份 JSON 及补充要求修订 J-ELEC-01。目录身份 `J-ELEC-01-SERIES`，作为已有电路实验的专用起点，继续复用同一电学模型和工作台。

- 合并“串联 · 相同灯泡”“串联 · 不同灯泡”为一个初中电学入口：“探究串联电路中各处电流的关系”。原并联两个入口和通用电学空白保留。
- **不使用电压表**。仅预放已有电源、开关、一只电流表、两只灯泡，共五件器材、五根导线；本实验禁用电压表及其他不支持器材。
- 器材位置、翻转和三套导线端点/弯曲路线采用教师提供的 JSON；原文件保持不动，预搭建开关断开。电流表保持在图示下方，改变的是串入的电气测点。
- 右侧可选 A 点（电源与灯泡 L1 之间）、B 点（两灯之间）、C 点（灯泡 L2 与开关之间）；画布灯泡明确标记 L1、L2。
- 右侧选择相同/不同灯泡：相同为两只 3 V / 0.3 A 灯泡；不同为 3 V / 0.3 A、6 V / 0.3 A 灯泡。切换只改变灯泡参数，保留当前电源电压及其他电源参数；只换测点也不改变电源、灯泡参数或器材位置。默认新入口沿用教师 JSON 的 9 V 电源，需要其他电压时由用户自行设置。
- 切换先断开开关，接线与参数在一个命令中更新，支持一次撤销/重做；学生自行闭合开关后读同一只电流表。三处采用原 MNA 实际接线求解，不按位置菜单伪造相同读数。
- 记录复用原抄表/采集、修订、追溯、CSV、SI JSON 和保存加载；默认测点带灯泡组合与 A/B/C 名称。比较页按原快照的实际接线归类，用学生记录列三处电流，不自动填值或结论。
- 自定义改线后不静默覆盖，参考选项禁用；明确点击“恢复串联参考接线”才能重建五根路线，保留器材姿态及参数。删除重取后按器材类型绑定现有身份，不要求新器材沿用旧 ID。
- 教师上传的五件旧装置可导入后使用位置选项，不修改其标题和身份；既有含电压表的旧串联存档、旧并联及通用空白继续原样加载，不自动删改器材。
