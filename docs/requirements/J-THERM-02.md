# J-THERM-02：探究固体熔化时温度的变化规律

学段：初中；领域：热学；任务 16 扩展，教师提供实验图片作为步骤参考。教材映射 `pending_teacher_review`，版次、章节、页码和教师签署不猜测。

- 提供预放装置与空白搭建两个入口，均位于初中热学。水沸腾原空白标题明确为“空白搭建水沸腾实验”，旧 ID 和存档兼容。
- 复用已有烧杯、加热装置、支架、温度计和计时器，仅新增“试管（熔化样品）”。同一试管可选择海波或石蜡，质量 5～50 g、初温 0～40 ℃可设；各器材最多一件，不兼容器材禁用。
- 试管样品段浸没水浴、管口露出水面且管底不碰杯底才传热。温度计玻璃泡埋入样品才显示有效样品温度，不能把水浴温度当样品温度。
- 支持加热/停止、暂停/继续、单步和倍速。参数即时生效；改变初态或材料重置当前过程，调功率、传热系数及器材位置不重置热状态。
- 约 40 ℃开始记录，每约 1 min 保存一次，完全熔化后继续 4～5 次。记录计时可单独归零，保留当前温度、物态及加热过程时间。
- 手工抄表、物态备注和显式采集；时间/温度成对冻结，海波与石蜡可顺次实验并对比。记录支持修订、删除、撤销、CSV/JSON 和保存加载，材料或初态改变不覆盖旧快照，不自动给结论。
- 内部为 s、K、kg、J，界面和记录图线使用 min、℃。重载恢复初态和记录，不续跑。
- 海波用近似单一熔点，石蜡用分布熔程示意；教学常数与边界详见模型文档，不能冒充实际牌号测定值或实体课堂验收。
