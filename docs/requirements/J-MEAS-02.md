# J-MEAS-02 用天平测量固体和液体的质量

- 学段/分类：初中物理 → 力学实验。
- 入口：用天平测量固体的质量；用天平测量液体的质量。初态分别只放固体或空烧杯，均复用天平和砝码盒。
- 器材：现成托盘天平、砝码盒、待测固体和烧杯；没有新增器材类型，不要求量筒。
- 操作：空载、游码归零后用螺母调平；左物右码，直接点砝码、拖游码配平。支持橡皮/铅笔与质量参数；液体先称空杯，再加水称总质量。
- 记录：手工 g 读数、缺失/无效状态、来源快照、液体两次质量差、修订/删除、质量图线、CSV/JSON、保存加载和撤销。
- 边界：未调零、未平衡、超量程、错误阶段、错误来源不得生成正常结果；容器或校准条件不一致不得拼接，空杯的液体标签不限制后来加水。
- 复用：原密度与浮力的称量、绘图和直接操作；原实验 ID、器材、导入存档及记录保持兼容。
- 模型：[质量测量模型与独立预期](../models/mass-measurement.md)。实际工程检查见[验收记录](../acceptance/M9-MASS.md)。
