# J-OPT-04：探究光折射时的特点

学段：初中；领域：光学；任务 16 的单项扩展。按教师提供的图片设计空气与水的界面实验，不复制教材图片。教材版次、章节和页码 `pending_teacher_review`，不填写未经核验的审阅信息。

- 初中光学增加“探究光折射时的特点”。沿用“空白搭建光学实验”，不新增重复空白入口。
- 复用窄光束光源、半圆量角器（两把）、法线标记和可选独立尺；仅新增透明水槽。水槽与光源各一件、量角器最多两把、法线最多一件；不兼容器材禁用，不弹出切换实验窗口。
- 从空气以不同方向射入水中，观察两侧光路、传播箭头与偏折；垂直入射为对照。可直接拖动光源或修改参数，均即时更新。
- 支持水射向空气，并提供“沿折射光反向入射”显式操作，只调整现有光源，保持其余器材不变，用于对照光路可逆。没有传播折射光时不提供正常折射角。
- 两把量角器分别在界面两侧，零线沿法线，刻度每格 1°；下侧文字保持正立。中心/零线可独立摆放和校准；放大量角观察可滚动和缩放，保持实际器材关系，不自动校准。
- 学生填写入射角、折射角与观察，不代填规律；理论和模型值默认隐藏。两种传播方向分系列，支持成组来源、修订/删除、图线、CSV/JSON、撤销、保存加载和复现装置。
- 角度内部 rad、界面与 CSV 为 °；来源快照保留真实器材和传播方向。非法装置、失准量角器、关闭光源或缺失光线不产生正常测量。
- 二维单一水平空气—水界面，不实施高中玻璃折射率专题、玻璃壁二次折射、干涉、散射亮度或完整三维水槽。
