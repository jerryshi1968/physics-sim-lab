# J-OPT-02：探究凸透镜成像规律

主学段：初中。实现状态：任务 09 / M4 工程门槛通过，教材与课堂待教师核验。来源：实施方案 7.3、8.1、11.2；小样为任务 01 / M0。见[实际模型](../models/optical-bench.md)及[验收证据](../acceptance/M4-TASK09.md)。

## 目标与操作

从器材库放置光具座、虚拟蜡烛、凸透镜、光屏、独立刻度尺，分别调节位置和高度。先调三心同高，再探索五类物距，移动光屏寻找清晰实像，比较正倒、大小和虚实；虚像由辅助视图观察。

## 测量与基准

记录物距、像距、屏位置、像的特点、清晰程度和对齐状态。f=10 cm，u=30/20/15/10/5 cm 时，v=15/20/30/无有限像/-10 cm，m=-0.5/-1/-2/不适用/+2。实像依次缩小、等大、放大，u<f 时正立放大虚像不可被真实光屏承接。

## 模型边界与验收

采用近轴薄透镜与离焦教学近似，不模拟衍射、像差。覆盖接近焦点、未同高、屏错侧、物镜重合和光具座范围；u=f 不序列化 NaN/Infinity。不能自动移动光屏到答案位置。远离焦点的有限像距误差 ≤1e-6 m，光屏位置真实影响离焦，显示、光线和记录同源；正式实验须可编辑、保存重载。

参考 [Ray Optics 官网](https://phydemo.app/ray-optics/)的理想薄镜、尺与辅助视图说明；公式、传播、图形与交互独立实现，未引入其代码或素材，未声称逐文件复用授权已核验。
