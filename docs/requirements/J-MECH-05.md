# J-MECH-05 探究重力的大小跟质量的关系

- 学段/分类：初中物理 → 力学实验；一个预搭建入口，不增加重复空白条目。
- 复用：现有支架、弹簧测力计、钩码；五件 0.05 kg 钩码起步，最多六件。沿用器材质量和量程参数，新增可选挂计引用，不增加器材类型。
- 操作：拖测力计到支架、拖钩码到测力计下钩或前一钩码下钩；可逐件挂上/取下，直接更改质量和量程即生效；放大读表。
- 数据：手工输入 kg 与 N，冻结挂接、g 和仪器配置；表格列出质量、重力、G/m，使用有效配对学生数据绘制 G–m 图，不代填模型答案。
- 状态：空载只观察零位，实际悬挂后记录；过载、接触桌面、非竖直、错误挂接和拖动中不输出正常读数。
- 兼容：原弹簧、杠杆、浮力等实验保留；可选 `forceMeterId` 不改变旧文档默认字段或格式版本。
- 保存：修订/删除、图点更新、CSV/JSON、本地保存加载及单次删除/撤销；不同 g 分开成组。
