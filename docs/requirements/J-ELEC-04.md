# J-ELEC-04：小灯泡电功率

学段：初中；领域：电学；来源：实施文档 9.2 / 任务 16。

教材映射：`pending_teacher_review`。出版社、版次、册次、章节页码与审核签署未核验，不填写通过结论。

复用首版灯泡及亮度模型，使用现有电源、开关、四柱变阻器和理想双量程表。学生调变阻器，分别在低于、达到和高于额定电压时记录 U、I 及亮度，计算实际功率，在额定工作点测额定功率。

验收范围：

- 初中电学新增一个预搭建入口；空白搭建复用现有唯一入口的记录模式，不新增重复器材或专用空白项。
- 开关断开、变阻器最大阻值、大量程起步；电流表串联、电压表跨灯泡，四柱按实际一上一下接法计算。
- 保留初中理想电表 0 Ω / ∞，量程可实际改接或使用既有导线快捷选择，滑片可鼠标/触摸拖动，不自动跳到额定电压。
- U、I、观察备注与装置快照保存；每次 P 由原始读数相乘，额定功率只取额定电压附近的记录，不混合平均不同工作点。
- 显示 P–U 散点，提供功率 CSV、JSON、原始修订与删除、撤销和保存重载。历史灯泡设置冻结，修订后派生结果更新。
- 超量程、模型越界、缺失、零值、陈旧回复和错误接线不作为正常功率。
- 给出独立数值基准，检查额定点和亮度变化、手机/平板模拟及首批六实验回归，保留实体设备与教材核验项。
