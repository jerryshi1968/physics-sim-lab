# J-THERM-03：比较不同物质吸热的情况

初中热学，任务 16 单项扩展。教师上传图片作为步骤参考；教材版次、册次、章节、页码、审阅人和日期未核验，映射保持 `pending_teacher_review`。

- 初中物理实验 → 热学实验，新增一个预搭建入口，不新增重复空白项。
- 复用已有烧杯、加热装置、温度计、支架和计时器，各最多两件。加热装置在此实验显示为浸入式电加热器，器材类型和其他实验外观保留；不新增第三方依赖。
- 水和食用油默认各 100 g、20 ℃，加热器各 100 W。共同质量 50～200 g、初温 0～40 ℃、功率可设；等质量液体按各自密度显示不同体积。质量是配液设置值，学生抄入记录，不伪称由天平自动采集。
- 相同加热时间比较温升；相同温升比较各自加热时间。后者在每杯达到目标后独立断电；计时器仅累计本杯实际受热的时间。两杯统一开始/停止，也可分别开关；支持暂停、继续、单步和倍速。
- 电热丝完全浸入且不碰底、壁才供热；玻璃泡在液体内且不碰底、壁才提供正常温度读数。温度计可分别放大；缺失、错放和超范围装配显示诊断。
- 手工记录两组质量、时间、初温和末温，每次八条来源可追溯记录。计算温升、按学生读数绘制温度—加热时间图线；控制条件不一致或缺值保留原记录并说明原因，不绘比较点，不自动给出实验结论。
- 复用修订、原始 CSV、SI JSON、撤销和保存加载。参数修改重启当前过程，姿态预览暂停且禁止记录，取消恢复；旧记录和来源不随运行改变，重载从初态重新运行。
- 模型使用理想均匀液体，默认忽略容器热容和散热，观察上限 80 ℃ / 3600 s。食用油参数是教学近似，不声称代表所有品种或实体测定。
