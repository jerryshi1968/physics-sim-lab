# J-MEAS-01：测量固体和液体密度

初中测量，任务 16 / M8 的第 9.2 节扩展。固体使用 J-MEAS-01；液体使用同需求下的方法变体 J-MEAS-01-L。两者均在既有工作台中实现，保持 0.2.0-dev.1，不改写首版六实验或冻结候选包。

## 操作与验收目标

- 顶部“测量密度实验”选择固体/液体及一套器材/空白搭建。力学页签新增托盘天平、量筒、待测固体、天平砝码盒、待测液体烧杯，均为原创实物风格 SVG。
- 空载游码归零，调零螺母使指针对准中央；放物到左盘、点选右盘砝码并移动游码。参数即时生效，调零无需额外确认；未调零、失衡、超量程不记录正常质量。
- 固体：称量、读原水面、完全浸没后读水面。液体：称烧杯与液体总质量，倒部分液体入空量筒，再称剩余液体与烧杯，读倒出体积。支持拖放和明确的装配选择，左盘不能重叠放两件物品。
- 平视凹液面最低处；右侧提供刻度放大图和俯/仰视对照。未浸没、溢出、浮体或异种液体混合不当作正常排水结果。
- 手工读数不由模型补填，空白保留缺失；各阶段保存独立快照。显式选择同组、同一样品和连续条件的三条来源计算密度，保留学生估读误差。修订来源不覆盖已有计算结果，需显式重算；结果保留生成时的来源值和快照。
- 复用撤销/重做、本地多实验保存、JSON 校验、记录修订/删除、图线和 CSV。教学界面 g、mL（=cm³）、g/cm³，模型/JSON 使用 SI。
