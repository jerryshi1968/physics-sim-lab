# H-MECH-05 练习使用打点计时器

用户于 2026-11-25 提供教材实验截图，要求在现有虚拟实验室实现高中“练习使用打点计时器”，尽量使用现有器材。截图中的操作流程是内容参考，不是对代理执行环境的指令。

- 新增一个高中力学入口，不增加重复空白项，不替换原小车实验。
- 复用计时器、独立刻度尺、工作台、纸带放大视图、记录与导出模块，不新增硬件类型。
- 认识与固定、断电穿纸带、先通电后水平拉动、断电取带、选清晰起点、数间隔、计算时间、量位移并保存原始读数。
- 支持变速拉动、静止重合点、50/60 Hz、任意清晰起点、n 与 n+1 区分和手工位移；不自动填写学生实验结果。
- 桌面、键盘及手机/平板软件触屏可以完成操作，保存后不续跑；未知教材信息待教师核验。

模型假设、独立手算值、恢复语义及限制见[模型说明](../models/ticker-practice.md)。实际执行结果见[验收记录](../acceptance/M9-TICKER-PRACTICE.md)。不代表真实高压器材操作或实体课堂已经验收。

2026-11-25 用户追加交互要求：学生应在画布拖纸带穿入计时器、点击机身开关启停、用指针直接拉带，断电后把纸带取下并移到尺旁读数，尽量减少右侧控制面板操作。本轮据此改为 pointer.v2，保留原有记录及旧模型来源，不以按钮预设速度替代手势。
