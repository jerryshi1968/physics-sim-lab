# J-OPT-03 平面镜成像

- 学段：初中光学。来源：[实施计划 §9.2](../implementation-plan.md#92-后续初中与高中扩展建议)。
- 学习任务：从镜前观察虚像，移动镜后对照物，换观察位置确认重合，手工测量像到镜面的距离和像高，与物距、物高比较。把光屏移到所定像位，观察屏面能否接到清晰的像。
- 实验入口提供预置器材与空白搭建。画布可移动器材，右侧有观察窗与光屏正视图。读尺辅助与反射光路独立控制，默认隐藏光路与理论像位。
- 记录包含组名、四项长度和可选光屏观察。图线比较像距与物距、像高与物高。使用工作台统一的撤销、保存、重载、JSON 与 CSV。
- 教材映射：`pending_teacher_review`。版次、章节与页码待教师核验。
