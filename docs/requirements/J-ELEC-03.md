# J-ELEC-03：伏安法测量定值电阻

学段：初中；领域：电学；来源：实施文档 9.2 / 任务 16。

教材映射：`pending_teacher_review`；出版社、版次、册次、章节、页码与审核签署未核验，不填写通过结论。

学生用现有电源、开关、未知定值电阻、四柱变阻器与双量程电表连接电路。电表采用理想模型（电流表 0 Ω，电压表 ∞）。先大量程观察，再自主改接端子或用右侧量程选择移动已有线头；调变阻器记录至少三组不同 U、I；计算各次 R、均值并比较读数分辨率和测量离散性。

验收范围：

- 初中电学新增一个预搭建入口，统一空白电学增加记录模式，不新增重复空白项或重复器材。
- 未知电阻默认隐藏数值，可断开开关换 A/B/C，保留位置与导线；支持既有拖动、触摸、翻转和即时属性。
- 每条成对记录冻结装置和两表量程、分度；手工读数不预填，采集必须明确触发。
- 无效接线、陈旧计算回复、缺失、零读数、反偏和超量程不输出正常电阻；非理想表导入后须显式恢复。
- 多组 U/I、U–I 拟合、相对均值偏差与半分度读数区间；分析不偷用隐藏阻值。
- 原始值可修订/删除，分析更新；模式与装置支持撤销、保存加载及 CSV/JSON 导出。
- 原首批六项回归、独立物理基准、触屏模拟和构建检查记录在验收文件。模拟不代替实体设备/课堂验收。
