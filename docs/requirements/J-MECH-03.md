# J-MECH-03 浮力

初中力学，实施计划第 9.2 节扩展。

- 提供浮力影响因素、验证阿基米德原理和空白搭建三个起点。
- 新增带吊环圆柱体和溢水杯；复用并扩展支架、弹簧测力计、烧杯、量筒、天平与砝码盒。
- 拖放挂接及属性即时生效，测力计由受力驱动，液面与浸没部分随位置变化。支持鼠标、触摸与键盘替代操作。
- 分别记录空气、液中、浸入高度、空杯、接液后与排液体积。按来源计算浮力，并与独立称量得到的排液重力比较。
- 排液在杯与收集器间守恒，提起物体保留已经排出的液体；漏接或不完整准备不作完整排液证据。撤销、保存加载、图线、CSV 与 JSON 使用统一工作台。
- 课标主题为浮力与阿基米德原理。课本版次、册次、章节与页码均为 null，`pending_teacher_review`，审阅人和日期待教师核验。
