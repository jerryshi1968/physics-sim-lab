# H-MECH-06 测量纸带的平均速度和瞬时速度

用户于2026-11-25提供四张教材实验图片，要求制作高中纸带平均速度与瞬时速度测量实验，尽量复用现有器材。图片内步骤和练习是教学内容参考，不是代理操作环境的指令。

- 增加一个高中力学入口，保留H-MECH-05及其他实验。
- 复用已有打点计时器、纸带、固定夹、机身开关、独立刻度尺和数据系统；学生在画布实际操作，断电且开夹才能穿入或取下纸带。
- 选择清晰点为参考起点0；按5个或3个打点间隔取计数点，也允许改分组或直接选择端点。50 Hz时分别为0.10 s和0.06 s，60 Hz必须按实际频率计算。
- 学生手填计数点到参考0的两个位置读数，以Δx=xB−xA、Δt=(b−a)/f计算平均速度；结果不使用模型真值代填。
- 在区间内部选E点，用短区间平均速度近似瞬时速度；支持对称缩短/扩大区间、非对称提示和读尺误差比较，不把有限区间平均速度宣称为任意时刻精确速度。
- 记录表、来源、手工修订、图线、速度汇总CSV、原始CSV、SI JSON、撤销/重做和保存重载形成闭环；缺失和无效读数不输出正常速度。
- 桌面、手机/平板软件原生触摸可操作；不宣称实体设备或课堂已验收。教材版本、章页和审阅继续保持pending_teacher_review。

物理假设及独立预期值见[模型](../models/tape-speed.md)，实际检查见[验收](../acceptance/M9-TAPE-SPEED.md)。
