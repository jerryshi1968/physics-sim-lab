# J-MEAS-03 探究同种物质的质量与体积的关系

- 学段/分类：初中物理 → 力学实验；新增一个预搭建入口，不新增重复空白。
- 器材：复用托盘天平、砝码盒、待测固体、力学独立刻度尺；四块不同大小的正方体铝块由原固体参数表示，不增加器材种类。
- 操作：空载调零、左物右码、直接点击砝码和拖游码；取下铝块、摆尺并放大读两端刻度；更换样品重复。
- 记录：手工质量 g、起止刻度 cm，选择同一块铝块的质量和读尺来源，计算边长与体积 cm³；缺失不补零，模型不代填。
- 图线：横轴 V、纵轴 m，以成组手工数据描点连线；可选理论原点与实测点分开，不自动给结论。
- 来源：阶段独立校验、快照冻结、修订后明确重算、删除来源保留引用、CSV/JSON 和本地保存加载。
- 边界：未调平/失衡/超量程、尺未覆盖/倾斜/过远、铝块仍在盘上、混用不同铝块、非配套材料参数和操作预览不得生成正常结果。
- 教材来源：用户上传的实验图片仅作教学步骤参考，未复制图片或原文。出版社、版次、章节、页码与审阅信息保持 `pending_teacher_review`，不编造通过结论。
