# v0.1.0-rc.1 已知限制

- 当前为本地审核候选包，未创建远端仓库、上传、打标签或正式发布。许可已获维护者授权，不代表课堂和设备门槛同时通过。
- 一名用户自述兼教初中、高中物理并反馈总体测试未发现问题，也提醒可能不够细致；未逐条列出六实验或教材。第二名教师、逐项结论和具体教材映射仍待补齐。
- 已测本机安装版 Edge 158.0.4370.1、Chrome 153.0.8010.48、指定桌面/投屏视口、150% CSS 布局缩放及软件触摸；未替实体平板/笔、OS 高 DPI、真实投影字号、学校实际电脑或所有浏览器发行通道验收。部分器材初始视图需缩小/平移，属性和记录区需滚动。
- 本机约五分钟的性能结果不能外推到所有设备或多小时运行。M7 实测 DOM/监听与应用 rAF/Worker 未累加，堆有预热和检查脚本数组增长，未声称无限运行绝无泄漏。
- 主脚本约 705.65 kB，构建仍保留 >500 kB 提示。当前复杂度是受限教学模型，不是任意大电路、通用光线追迹或多体仿真。
- 随机误差尚未实现；超模型、无效挂接、未调平或异常量程有明确诊断，不给正常采样。各实验具体范围见 MODEL-SUMMARY 与详细模型。
- 本地保存受浏览器配置和地址源隔离，清理站点/无痕模式可能丢弃数据；重要实验请导出 JSON。没有账号、云同步或业务后端。加载不恢复动态时刻。
- 离线需预装 Node.js 并保留本机 HTTP 服务，不能双击 HTML。外网阻断/禁缓存冷启动已测，未安装 PWA/Service Worker；关闭服务后不保证再次加载。
- 当前平台未安装的 npm 可选开发包仅记录锁信息，不分发其代码。源码审核包不携带 node_modules、本机缓存、局部代理配置、原始截图/测试日志、用户本机 AGENTS 指令或旧构建。
- 数据表手工行可独立修订，改尺读数后需自行核对派生量；图/拟合不自动把学生读数纠正为理论答案。
