## 首批六项

- 初中：J-OPT-02 凸透镜成像、J-ELEC-01 灯泡串并联、J-MECH-02 杠杆平衡、J-MECH-01 滑动摩擦。

包含实物风格器材、接线/挂接、即时属性、鼠标/软件触摸、键盘、命令历史、多实验保存、严格 JSON 导入、手工读表/读尺、记录/图线/拟合和 CSV/JSON。六实验共享器材、领域模型与数据通道，从空白搭建，模板可改。

M7 已修复摩擦在同文档导入、切换返回或初态撤销后可能复用旧运行态的问题。任务 15 不改物理或工作台逻辑，完成实际来源/许可审查、原创正式许可、完整声明、贡献指南、模型/演示索引与候选打包工具。

## 交付物

- source.zip：原创源码、测试、配置、贡献/模型/演示/限制说明及声明，可按锁文件安装和构建。
- offline.zip：已构建静态资源、完整许可/NOTICE、只用 Node 内置模块的本机 HTTP 启动器及课堂操作说明，不需要 npm 或 Python。
- RELEASE-CONTENTS.json / SHA256SUMS.txt：版本、文件哈希、保留/排除范围与两个 ZIP 的校验。包内 BUILD-MANIFEST.json 自身不列入自己的内容哈希，避免循环。

源码包省略本机验收历史和原始日志/截图；模型文档中指向省略文件的历史链接会改为明确的本地路径说明，并在包清单标出文档整理前后哈希。源代码、测试与已有代码注释逐字保留。当前验证使用独立公开摘要，不用伪造占位报告替代省略的历史文件。
