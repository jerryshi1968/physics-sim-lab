# 纸带平均速度与瞬时速度近似

实验H-MECH-06，派生计算版本`mechanical.tape-speed.v1`。打点运动继续使用`mechanical.ticker.pointer.v2`，复用H-MECH-05的计时器、独立刻度尺、夹具、电源、跟手纸带与高倍率读尺；无新硬件、依赖或外部素材。只实现本项，不扩展下一实验。

## 操作和坐标

断电开夹 → 拖入纸带 → 扣夹 → 通电并水平拉带 → 断电开夹 → 拖出并移到尺旁。松手停止拉动但仍打点，重合点不能用于测量。纸带上限0.8 m、通电上限12 s、失焦断电及指针事件间线性插值保持。原始点按实际打点顺序编号k，时刻t_k=k/f，f支持50、60 Hz。

学生选择清晰点z作为参考起点0，选择端点a、b（z≤a<b）。计数点为z+j·stride，默认平均速度每5个打点间隔取点，瞬时近似每3个间隔取点；实际共有n=b−a个间隔、n+1个点。也可直接点选任意清晰端点。选择瞬时近似时目标E须严格位于a、b之间，不能取端点或重合点。

纸带点的世界坐标为paper.x−x_k，尺刻度向右增加。参考0、A和B都必须位于水平正向尺的实际刻度内，纸带与尺基准线纵向距离绝对值≤0.060 m，允许前景尺叠放。学生应分别量出相对参考0的距离xA、xB：用参考0处真实尺读数减去相应点尺读数。尺不自动对齐纸带0点，不自动填写读数。移动独立尺保留纸带；改变计时器装置使当前纸带失效。

## 计算及近似的含义

全部内部计算使用m、s、m/s。有效手工读数满足0≤xA<xB≤尺长：

- Δx=xB−xA；Δt=(b−a)/f；区间平均速度v̄=Δx/Δt。
- 平均速度图线将其标在该区间的中点时刻`((a+b)/2−z)/f`，该标点不表示一般运动下的精确瞬时速度。
- 瞬时近似以相同区间平均速度近似目标E点，目标时刻为`(E−z)/f`。界面始终标明“近似值”，保留目标相对区间时间中点的偏差`(E−(a+b)/2)/f`；非对称区间明确提示偏差。
- “围绕E缩短/扩大区间”保持目标点不变，在可用点范围内对称取点。最短使用E前后各一个原始时间间隔，不能生成零时长或区间外测量。

有限区间平均速度对一般运动不能等同于其中任意一点的瞬时速度。对足够光滑的轨迹，围绕目标对称缩短区间可减小方法近似误差，但读尺误差相对占比增大；匀加速运动的对称区间平均速度恰等于中点速度只是特殊情况。实现不假设实际指针手拉为匀加速，也不生成一个未经测量的“精确瞬时速度”。保存的物理位置真值用于追溯区间数据，不用来替代学生结果。

以两端位置各估读±0.5 mm为一个明确的教学误差设定，Δx的最坏误差界示意为1 mm，速度读尺误差界为0.001 m/Δt。它不是统计标准不确定度，也不包含手拉、频率、方法近似或相关误差。该提示不注入随机误差，不改变原始点。短区间并非越短越好。

## 来源、修订和恢复

每次测量保存两个手工位置记录及一份冻结来源；来源包含纸带/测点/参考起点、分组间隔、频率、目标E、原始物理位置、纸带摆放、实际尺读数和备注。通用快照完整保存当时器材与模型配置。组别、参考起点、方法和纸带运行区分图线，区间比较还按同一E分组。

Δx、Δt、v和对应时刻由当前两个手工记录及冻结的点编号/频率实时派生，不另存可能在修订后失效的速度常数。通用修订保留原始输入和来源，表格、图线及速度CSV随当前读数重算；SI JSON保存重算所需的所有原始和修订数据。仅存一个位置记录时仍显示该组但速度为空，两条都删除后该组消失。留空、负数、超尺长、反序或相同读数不输出正常速度；不使用模型值或零补齐。异常纸带、参考/端点/目标不合法、斜尺、尺外或未取带时拒绝采样。

一次保存为单个历史事务，可撤销/重做。完整未取样纸带不续存；保存重载恢复记录与计算结果，装置从断电、开夹、未装纸带初态开始，不续跑。H-MECH-05和旧来源语义保持，通用原始CSV与专项派生速度CSV分别保留原始读数与计算结果。

## 独立预期值

1. 50 Hz、5个间隔：Δt=0.10 s；xA=0.020 m、xB=0.040 m，Δx=0.020 m，v̄=0.20 m/s。60 Hz的同5间隔为1/12 s，速度0.24 m/s，不能硬写0.10 s。
2. 50 Hz、3个间隔：Δt=0.06 s；Δx=0.012 m，近似速度0.20 m/s。60 Hz则Δt=0.05 s，速度0.24 m/s。a=5、b=8、E=6、z=0时E时刻0.12 s，区间中点0.13 s，偏差−0.01 s。
3. 匀速轨迹x=0.2t，z=2、a=5、b=10、50 Hz：学生相对位置0.012 m与0.032 m，速度0.2 m/s，对应区间中点相对参考0时刻0.11 s。纸带paper.x=0.40 m、尺零点x=−0.18 m时，0/A/B真实尺读数分别0.572/0.560/0.540 m。
4. 解析对照轨迹x=t³（SI），目标t=0.10 s，精确导数3t²=0.030 m/s仅用于独立测试。对称区间[0.06,0.14] s的平均速度0.0316 m/s；[0.08,0.12] s为0.0304 m/s，方法误差减小；读尺误差界分别±0.0125、±0.025 m/s，反而增大。
5. 同一目标t=0.10 s，非对称[0.08,0.16] s的平均速度为0.0448 m/s，与目标精确导数不同，偏离区间中点−0.02 s；不能宣传“任一点都精确”。
6. 学生把xB从0.0430 m修订为0.045 m，xA=0.020 m、Δt=0.10 s：速度从0.23变为0.25 m/s，原输入0.0430及物理位置真值0.040 m不改变。
7. 60 Hz通电12 s共有721个原始点，最大编号720，不能沿用50 Hz的600号上限。匀速0.02 m/s、参考700号、区间715～720号，xA=0.005 m、xB=1/150 m、Δt=1/12 s，平均速度仍为0.02 m/s。
