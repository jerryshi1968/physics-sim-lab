# 测量记录、图线与 CSV（M3 / 任务 07）

M4 / 任务 09 复用下述快照、表格、修订和 CSV 契约，增加光学手工读尺及观察：蜡烛/透镜/光屏位置、物距 u、屏距 s、实测像距 v 共六项，v 只在清晰实像时有效。五类物距、尺零点、空值与图轴详见[光学模型](optical-bench.md)；以下为任务 07 的电学记录说明。

日期：2026-11-04。本阶段提供电流/电压多测点记录、图线与导出；不提供任务 08 的实验模板或自动归纳答案，不生成其他领域的假测量。

## 操作与数值来源

在“记录表”点击“展开记录区”，选择电表并填写组别/接法、测点名称和备注。默认选中当前电表，可取消勾选。

- “采集仪表示数”保存当前量程按分度值显示的值，不采集未量化的模型真值。
- “保存手工抄表”保存学生输入和原始文本，输入框不预填真值，不要求估读值恰好落在分度线上。有限十进制/科学计数法可用，公式、NaN、Infinity、十六进制或混入单位的文字拒绝整批提交。
- 手工留空记录缺失，值为 null；反偏、超量程、断线、浮置、求解失败分别保存状态，异常行没有正常数值。手工文本仍保留，不能把异常状态下抄入的数字升级为有效采样。
- 手工记录可“修改抄表”，当前值和修订时间更新，采样时原始输入、仪器显示、真值和场景快照保持。仪表采集行不允许修改为手工值。
- 采样后自动收起设置，优先显示记录表；“展开测点与抄表”可继续设置。标签切换保留本会话的测点/草稿，切页滚动回顶部。草稿不是已保存记录，刷新只恢复已保存文档内容。

同一次点击可记录多个电流/电压测点，共用采样标识和组次。组别/接法由用户命名，不根据画面位置或实验 ID 猜串并联，不替学生接线/换档。可用一个电表移动测点，也可同时使用多表；只有所选且实际存在的电表参与本次记录。

## 文档与采样快照

格式仍为 schemaVersion=2，新增可选 measurementSnapshots、record.context 和 correctedAt。旧格式 2 没有这些字段也能原样读取；旧记录明确显示无接线快照，不伪造历史。格式 1 继续严格校验，并拒绝冒充旧版的新增快照/上下文字段。

MeasurementRecord 保留 source、quantity、SI unit、value/rawInput、equipmentId、range、measurementStatus、recordedAt、documentRevision、runId、sequence 和 modelConfigSnapshot。新增 context 包括采样引用、器材名称快照、测点名称、原始抄表文本、仪器状态/显示、物理真值与诊断码；三种数值独立，表格主值只使用 record.value。

每次采样只存一份共享 MeasurementSnapshot：文档/版本、运行/序号、采样时间、组别/备注、实际模型版本、全套器材参数/姿态、连接及全局配置。记录引用 sampleId，避免每个测点重复保存全电路。采样标签必须匹配当前文档和 revision；无当前计算结果不能采样，旧回包不能为新装置形成记录。暂停后未编辑可记录同版本静态结果，修改装置后必须恢复计算。

追加命令再次核对快照与当前规范化场景相同；引用、标签、时间、配置和器材均经过校验。快照内的历史连接单独按注册表验证，不用后来改动的场景覆盖。表格“追溯详情”按需展开参数/接线，避免默认重复渲染大快照。

追加同批多条记录、修订单条、删除单条均进入命令历史；同批采样一步撤销。删除最后一条引用后清理对应快照。引用测量记录的器材仍按原规则禁止删除，防止断开追溯关系。记录与快照各最多 10000 条，采样后的漂亮格式 JSON 仍须不超过 5 MiB；操作超限或校验失败不留下部分记录。保存、加载和 JSON 导入导出包含已完成记录及其快照，不含 Worker、指针动态快照或 UI 草稿。

## 表格、比较图与后续领域接口

表格、图线、CSV 共用 measurementRows，组次按采样引用而非物理量分别计数。图线只读表格 record.value，按器材/测点/来源/组别分系列；手工和仪表采集不混为一条线，模型真值不参与作图。当前开放“电流多测点比较”（A）和“电压多测点比较”（V），横轴为采样组次；连线只辅助比较顺序。

无效、缺失、非稳态记录不作有效点，缺少的组次断线，不补零，不跨异常连线。确实有效的 0 正常绘制。极端有限值先缩放再投影，避免跨度溢出造成 NaN/Infinity；不改写原记录数值。

核心 MeasurementAxis 配置 quantity、unit、label、可选 pointLabel 及 power=1/2；支持同一次采样的唯一 x/y 配对，含糊或无效的横轴不猜值。已预留但在 UI 禁用：

| 配置 | 横轴 | 纵轴 |
| --- | --- | --- |
| 杠杆力矩 | 力臂 m | 力矩 N·m |
| 摩擦 F-N | 压力 N | 摩擦力 N |
| 弹簧 F-Δx | 形变量 m | 弹力 N |
| 平抛 x-t | 时间 s | 水平位移 m |
| 平抛 ydrop-t² | 由记录时间平方得到 s² | 向下位移 m |

变换只作用于图轴，不把 t² 写回时间记录，也不由此生成未实现领域的测量。

## CSV 契约与防护

“导出 CSV”导出全部记录。UTF-8 BOM、CRLF、双引号包围文本并将内部引号加倍；数值以有限十进制/科学计数法输出，无效 value 为真正空单元格，来源/状态/原始文本保留。导出当前修订后的表格值，同时单列采样时原始抄表和修订文本。

列还包括量程/分度值、时间、器材和测点、文档/revision/runId/sequence、sampleId、实际模型版本、仪器/真值快照、配置/器材/连接/备注。同组完整器材与连接快照仅附在首行，其余行通过采样标识引用首行，避免放大导出体积；导出上限为 20 MiB。

文本若含前导空白后的 =、+、-、@、全角变体或前导制表符/换行，引用字段内部加制表符作中和；合法负数的数值列仍是数字。JSON 原始数据不加中和字符，适合作为精确保真备份。防护思路核对 [OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)；不同表格软件及另存后再打开的行为不相同，本项目未进行真实 Excel/LibreOffice 往返验收，不宣称通用防护保证。
