# 平面镜成像模型（J-OPT-03）

模型版本 `optical.mirror-image.planar.v1`。实验台画的是包含物高的竖直截面。薄玻璃板固定竖直，反射和透视对照在同一面进行。相对于玻璃板，镜前在左，镜后在右。为复用器材库，平面镜沿用反射实验的器材定义，在本实验中以竖直薄玻璃板绘制和计算。

## 几何与观察

- 镜面横坐标为 `m`，物点为 `(x, y)`，镜中虚像为 `(2m − x, y)`。物高由成像标记物的上下端给出，像的上下端同高且正立。镜前物点和观察眼必须在反射侧。
- 从眼位置 `E=(xe, ye)` 向像点 `P=(xp, yp)` 连线，镜面交点高度为 `ye + (yp − ye)(m − xe)/(xp − xe)`。交点在镜面范围内才可见。观察窗用固定比例显示视线斜率 `(yp − ye)/(xp − xe)`，并以像的可见部分为中心取景。标记视高随眼到像的水平距离增大而减小。红色像和青色对照物使用同一投影，即使在某一眼位重合，深度不同也会随观察眼移动而出现视差。
- 启用光路后，物点到镜面、镜面到眼的实线表示实际光线，向镜后延长的虚线用于定位虚像。光屏模式只显示屏面；光线在镜后没有会聚，屏上没有清晰像。只有光屏距虚像所在平面的偏差不超过 5 mm 且覆盖像的上下端，光屏观察才作为有效证据。
- 理想薄板忽略玻璃厚度、折射偏移、遮挡、双反射、亮度差和随机误差。镜前标记和镜后对照物为固定朝向；本实验不模拟转动镜面或三维绕镜观察。

## 手算基准与记录

模板中 `m=0`，成像标记物中心 `(-0.22, 0.08) m`，高 `0.12 m`。像中心为 `(0.22, 0.08) m`，上下端为 `0.02 m` 和 `0.14 m`。眼位 `(-0.39, 0.19) m` 时，像的两端分别投影在镜面 `y≈0.08131 m`、`0.15803 m`。将对照物中心移到像中心并设成相同高度，上下移动眼位仍重合。若仅在单个眼位上以调整高度来补偿深度偏差，换眼位后两轮廓分离。

观察窗取固定比例 360 个绘图单位。眼睛的 `x` 分别为 `−0.20 m`、`−0.39 m`、`−0.75 m` 时，未裁切像高分别为 `360 × 0.12 / 0.42 ≈ 102.9`、`360 × 0.12 / 0.61 ≈ 70.8`、`360 × 0.12 / 0.97 ≈ 44.5` 个绘图单位。刻度尺测得的实际像高始终为 `0.12 m`。

水平尺读三处位置并作差，竖直尺读标记物与对照物的上下端并作差。可选辅助线只投影实物位置。读数由学生手工填写，显示、修改抄表、图线和 CSV 用 cm，内部快照和 JSON 用 m。对照物应由学生通过视差独立找位，模型保留所抄读数和对应装置。刻度尺未覆盖测点、像或对照物无法完整观察、光屏未到像位时，相应项目标为不可用。空白保持缺失。
