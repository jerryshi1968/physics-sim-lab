# 单摆：摆长、非线性周期与多周期测量

实现：`src/equipment/pendulum/`；需求 H-MECH-04。SI 内部单位：m、kg、s、rad、m/s²。界面释放角以 ° 输入，进入模型时换算 rad。

## 模型与坐标

无质量、不可伸长摆线，摆球按球心处质点处理；半径 r 只用于定义有效摆长 L=摆线长度+r。忽略空气阻力、阻尼、转动惯量、支架弹性和人的计时反应。世界坐标 y 向上，θ 从竖直向下偏右为正。悬点由支架高度和横臂确定，球心为 (xp+L sinθ, yp−L cosθ)。支架载荷按底部最大张力 mg(3−2cosθ₀) 检查。

θ″=−(g/L)sinθ；初态 θ(0)=θ₀、θ′(0)=0。k=sin(|θ₀|/2)，精确周期 T=4√(L/g)K(k)，K 用算术几何平均计算。运动由不完全椭圆积分的反解获得：θ=±2asin(k sinφ)，F(φ,k) 随四个四分之一周期往返；F 以 64 子区间 Simpson 积分、带括区间 Newton 迭代反解。模型不以小角正弦轨迹代替大角运动。

小角周期 T₀=2π√(L/g)。5° 为本软件的测 g 建议上限，不冒充已经核验的教材条款；大角仍显示运动与计时，保留测量，但小角公式求得的是偏小的表观 g，不进入小角拟合。

摆线 0.08～0.7 m、半径 0.005～0.025 m、质量 0.005～0.2 kg、释放角 ±60°；延用支架最高 0.8 m。最低球面必须高于底座，载荷不得超支架额定值。未挂接、器材旋转或翻转安装、碰底、超载及参数越界均不给出正常运行；0° 保持静止且不能开始周期测量。须有且仅有一个计时器才能计时。读尺保存要求竖直向下的尺覆盖悬点到最低球心。

重力加速度在右侧参数框即时调整，默认 9.81 m/s²，须为大于零的有限数值。无效草稿不应用，失焦或 Esc 恢复有效值。修改 g 清除当前计时，可撤销/重做，并随 JSON 和本地保存；已记录的配置快照保持原值。旧文件的 g 保留，不用新默认值覆盖。

## 时间、记录和拟合

从释放端点到返回同一端点计一个完整周期，N=1/5/10/20/30/50。事件终点为 N×T，跨帧准确截断；帧时间推进与轨迹共用同一时间源。播放速度只改视觉播放快慢，不改物理秒数；暂停冻结模拟时间，不表示摆球受外力停止。计时器按配置分辨率舍入。本阶段使用理想自动周期门控，不模拟人工启停的反应误差。

摆长、摆球、安装支架、计时参数和重力变化使当前计时失效；独立尺的位置和计时器的摆放位置不改变摆动，可以在计时后移动读尺；撤销及替换文档也清除当前计时，旧测量快照保留。本地保存/JSON 不写入运行状态，加载从初态重跑。

四个原始手工值为悬点尺读数、最低位置球心尺读数、完整周期数 N、总时间 t；可显式采集秒表的舍入示数，但不自动填写尺读数和周期数。不接受未完成或已过期的计时窗口。留空、非正时间、非整数 N、N 与本次计数不一致、逆向尺读数、超范围均不生成正常计算值。原始记录可用既有表格修订；派生结果始终重新从四条源记录计算，不把模型真值用于拟合。删除源行后派生结果无效，来源快照继续保留。

L=球心尺读数−悬点尺读数；T=t/N；g=4π²L/T²。T²–L 普通最小二乘保留截距，g_fit=4π²/斜率；需至少五个不同摆长、同组、相同质量/球半径/释放角/配置 g，且 |θ₀|≤5°。重复点不能补足五种摆长。不同摆角和重力配置分组；大角只供角度对照，不混入小角拟合。CSV 分为既有原始追溯 CSV 与本实验计算 CSV。

## 独立预期与容差

预期值使用 Python 标准库 Decimal、55 位精度，独立展开 K 的二项式级数：K=π/2 Σ[((2n)!/(2²ⁿ(n!)²))² k²ⁿ]；不是调用被测 AGM。sin 以 Taylor 级数求值、150 项求和，π 使用公开数学常量。无新增第三方依赖。

原始独立基准保留 L=0.5 m、g=9.8 m/s²（显式测试输入，不是新建默认值）：

| 释放角 | 周期 / s | 说明 |
| ---: | ---: | --- |
| 0° 极限 | 1.4192268951137287478 | 实际 0° 不振动，不可测周期 |
| 5° | 1.4199026919125544424 | 20 周期 28.3980538382510888 s，0.001 s 表显示 28.398 s |
| 30° | 1.4439339288735007393 | 非线性角度影响 |
| 60° | 1.5230887678985118490 | 显著长于小角周期 |

新默认 g=9.81 m/s²、L=0.5 m、5°：用原独立基准乘 √(9.8/9.81)，T=1.4191788057110770528 s；20 周期 t=28.383576114221541056 s，0.001 s 表显示 28.384 s。g 改为 2.4525 时周期恰为原来的两倍。

周期绝对误差≤1e−11 s；轨迹四分之一相位角绝对误差≤1e−8 rad，独立有限差分检验 θ″+(g/L)sinθ 的残差≤1e−4 rad/s²。L 变四倍使周期变两倍，g 变为四分之一使周期变两倍；质量改变不改周期。单次大步与分割步对终止时间完全一致，显示分辨率不作为积分精度。

例如 L=0.5 m、N=20、t=30 s，学生读数计算 g=8.772981689857207 m/s²；手工将 t 改为 30 必须得到该数值，即使模型计时不同。5° 记录的小角公式 g 与配置真值有小角近似偏差，不能把测试预期强制写为模型 g。
