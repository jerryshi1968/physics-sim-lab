# J-MECH-07 动能影响因素模型

## 装置与范围

全部复用现有 `mechanical.cart-track`、`mechanical.projectile-ball`、`mechanical.friction-block`、`mechanical.friction-surface`、`mechanical.ruler`。在本实验显示为弧形斜槽、钢球、木块、水平接触面和独立刻度尺；预放两把尺，分别观察高度和水平位移。没有新器材类型。

钢球质量 m=0.02～0.5 kg，木块质量 M=0.05～2 kg，释放高度 h=0.02～0.4 m（还受斜槽几何范围限制），木块摩擦系数 μ=0.05～0.8。球半径 r=0.025 m 固定，不用图示大小暗示质量；通过质量参数代表不同钢球。g 默认 9.81 m/s²；不启用随机误差。不支持其他实验的发射、牵引器、测力计连接。

## 滚下与衔接

理想均质实心球，I=2mr²/5，纯滚动且无滚动阻力。轨道给球心规定平滑摆线轨迹，出口与水平面相切；支承曲线在球心轨迹法向下方 r 处绘制。球心相对出口球心的落差就是 h，不能把球底到桌面的距离错当落差。

令 R=斜槽水平长度/π，θ∈(0,π]，出口坐标 (x₀,y₀)：

```
x = x₀ + R(θ−sinθ−π)
y = y₀ + r + R(1+cosθ)
u = 4R cos(θ/2)       （距出口的剩余弧长）
h = u²/(8R)
ω₀² = 5g/(28R)
u(t) = u_initial cos(ω₀t)
t_出口 = π/(2ω₀)
v_出口² = 10gh/7
```

由 `½mv²+½I(v/r)²=mgh` 得上式。摆线用于让轨迹位置、速度和释放时间有同源解析计算；到达出口后匀速滚动至木块。初始球无平动或自转速度；同高度下，撞前速度与 m 无关。转动标记角度随实际滚动弧长/r 改变。

## 碰撞与停止

球从木块左侧中心高度碰撞，采用完全非弹性接触近似，碰后球块保持接触、共同运动。球仍纯滚动，接地静摩擦可提供所需冲量但不做功；接触约束下球的等效惯性质量 A=m+I/r²=7m/5。冲量方程为 `A(v−V)=MV`：

```
V = A v / (A+M)
a = μMg/(A+M)
s = V²/(2a)
  = [A/(A+M)] · mgh/(μMg)
碰后总动能 = ½(A+M)V² = μMgs
```

木块是唯一耗散滑动摩擦做功者，钢球滚阻忽略；有碰撞能量损失，不能把 `μMgs` 直接等同碰前的钢球总动能或平动动能。此近似用于相同球形、同一木块与接触面下的定性实验，不预测真实钢球反弹、弹性变形、声音、打滑或任意碰撞。

固定 m，s 随 h 增大；固定 h，v 相同，而 `[A/(A+M)]m` 随 m 增大，s 也增大。模型没有把 s 简单写成预设的“正比于球质量”动画。

## 独立手算基准

取 m=0.05 kg，M=0.1 kg，h=0.15 m，μ=0.2，g=9.81 m/s²：

- v²=2.102142857142857 m²/s²；A=0.07 kg。
- s=(0.07/0.17)×(0.05×0.15)/(0.2×0.1)=0.15441176470588233 m。
- h=0.30 m 时，s=0.30882352941176466 m，速度变为原值 √2 倍。
- 同 h=0.15 m，m=0.1 kg 时，v 不变，s=0.4375 m。
- μ 加倍时，其他条件不变，s 减半。

完整核心用例还独立检验滚动能量、广义冲量、碰后功—能关系、弧线/水平/碰撞段位置连续及第一次边界。

## 无效状态与证据

装置错位、旋转、错误引用、重复/不兼容器材、非有限或范围外参数不准释放。接触面有限，先到边界就停止在边界前 5 mm，保留剩余速度并显示边界终止，拒绝正常记录。不能把“滚出了桌面”当成正常停下。

改质量、高度、木块或接触面重置运动；移动读尺不重置已结束试验。保存只保存初态和已录证据，不恢复正在运行的动画。读数必须手填，留空不补理论值；位移由两端读数相减，修订原始读数后重算，来源快照不改变。控制条件检查比较实际冻结的装置、质量或高度，不用模型代写动能结论。
