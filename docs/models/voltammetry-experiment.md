# J-ELEC-03 伏安法测量定值电阻

## 范围与器材

复用现有电池盒、开关、定值电阻、电流表、电压表、四柱滑动变阻器和导线。不新增器材类型。电流表串联，电压表跨接待测电阻，变阻器一上一下接入。沿用 J-ELEC-02 的实际接线拓扑检查，不按器材坐标或导线外观判断连通。

教师明确本项初中实验使用理想电表：电流表内阻 0 Ω，电压表内阻 ∞，不研究内外接法与电表加载。属性中电流表内阻只读，电压表内阻显示只读 ∞，不提供有限内阻开关。导入有限内阻配置不会静默改写；提示恢复理想电表，恢复前不允许成组采样或正常结果。恢复操作使用既有属性命令，可撤销。

定值电阻仍为 `electrical.resistor`，可选 `concealResistance` 隐藏图形与普通属性中的数值，`sampleLabel` 区分 A/B/C。普通旧电阻参数不变。A/B/C 的模型值分别为 7.5、12.5、22.5 Ω；这些数字是开发基准，不显示在待测电阻按钮上。断开开关才允许更换阻值，保持 ID、位置和导线。隐藏是教学显示设置，可显式取消；纯前端 JSON 仍含模型值，不承诺保密考试。

预搭建起点 ID 为 J-ELEC-03，6 V 电源，开关断开，变阻器 50 Ω、接入最大阻值，两表接大量程。自行观察后断开开关，按原有接线柱改接量程；右侧量程选择会通过既有导线命令移动同一线头，保持导线 ID 与弯曲形状并支持撤销。若多条导线共用正端或两个正端同时接线，快捷选择禁用，需逐条改接。没有重复的专用空白目录项；J-ELEC-FREE 的既有 `ohmControl.mode` 扩展为 `measurement`，仅决定记录规则与图线。切换不改变器材、接线或文档身份，支持撤销、保存、旧文件加载。其余两个控制参数在该模式不参与计算，保留以兼容原来的 I–U / I–1/R 配置。

## 计算与数据

全部计算及存储使用 SI。定值电阻温度不变、理想导线，不模拟温升。准静态 MNA 按实际变阻器端子计算，滑片不自动定位。物理参考：

- [OpenStax 21.5：用电压、电流测电阻](https://openstax.org/books/college-physics-2e/pages/21-5-null-measurements)
- [OpenStax 21.4：理想电表与实际仪表对电路的影响](https://openstax.org/books/college-physics-2e/pages/21-4-dc-voltmeters-and-ammeters)

每次主动保存一对原始 U、I，快照冻结器材、量程、分度值、接线、文档修订和计算回复。手工留空为缺失，采集只取按分度值舍入后的示数，均不以隐藏阻值或模型真值代填。

`R_i=U_i/I_i`。仅同一快照内同源、同修订、同次计算的有效两表示数进入计算；不完整对、异常仪表、非正 U/I、非法接线与非理想电表配置排除但保留原记录。旧回复拒绝采样。零电流不做除法。

按组名、抄表来源、同一待测电阻及配置分系列；隐藏阻值只用于区分装置是否换过，不用作学生计算结果。量程不拆系列，每行保留自己当时的分辨率，允许比较不同量程。参数变化不改变历史快照；修订抄表或删除记录会重新推导结果，不使用陈旧缓存。

- 算术平均：`R̄=ΣR_i/n`。
- 平均绝对偏差：`d=Σ|R_i−R̄|/n`；相对平均偏差 `d/R̄×100%`。
- 每次相对本组均值的有符号偏差 `(R_i−R̄)/R̄×100%`。未提供参考值时不称为真实相对误差；零离散不等于没有系统误差。
- 图线横轴 I、纵轴 U。至少三个不同 I 才做保留截距的普通最小二乘拟合，斜率为拟合电阻，不强迫通过原点。不把重复同一工作点作为三个不同点。
- 分辨率估计显式假设：`δU=电压分度值/2`，`δI=电流分度值/2`。读数区间下界 `max(0,U−δU)/(I+δI)`，上界 `(U+δU)/(I−δI)`，仅 `I>δI` 时有有限上界。它只是半分度读数区间，不是仪器准确度、置信区间或完整不确定度；不模拟仪器等级、视差和随机误差源。手工抄错仍保留实际输入。

原始表格、修订及原始 CSV 沿用测量模块；分析 CSV 另含 U/I、量程、半分度区间、均值、偏差及拟合，不导出待测参考阻值。JSON 保留完整模型与来源快照。
