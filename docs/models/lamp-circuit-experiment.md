## 入口与可编辑初态

顶部“灯泡串并联实验”打开起点选择器，提供空白、串联/并联各两种灯泡组合。选择后先预览配置，确认才替换当前工作并清空历史；取消不改当前文档。每次创建新 documentId，不覆盖已有本地实验。普通“新建实验”仍创建自由搭建。

正式场景使用既有 `experimentId=J-ELEC-01`；它只关联教学指导，求解器不按实验 ID、标题或模板名判断电路。模板可自由移位、翻转、改线、删改器材和参数。模板带一对双量程表，初态开关断开，电流表接 0～3 A、电压表接 0～15 V；这属于明确选择的模板初态，提示不会改接量程。记录为空，不预写理论答案。空白入口连器材和导线都不生成。

| 起点 | 电源 | 灯泡 L1：Ur / Ir / Rcold | 灯泡 L2：Ur / Ir / Rcold |
| --- | --- | --- | --- |
| 串联，相同灯泡 | 6 V | 3 V / 0.3 A / 2 Ω | 3 V / 0.3 A / 2 Ω |
| 串联，不同灯泡 | 9 V | 3 V / 0.3 A / 2 Ω | 6 V / 0.3 A / 4 Ω |
| 并联，相同灯泡 | 3 V | 3 V / 0.3 A / 2 Ω | 3 V / 0.3 A / 2 Ω |
| 并联，不同灯泡 | 3 V | 3 V / 0.3 A / 2 Ω | 3 V / 0.2 A / 2 Ω |

模板电源设置分别保存并在预览标出，不将 6/9/3 V 默认为所有接法通用。不同串联模板使用 9 V 是为了在共同额定电流下观察不同分压，不把并联或相同灯泡的对称现象推广为普遍结论。初态线形为人工布置的可编辑曲线，改变线形不改变电气关系；窄屏初始缩放较小，可继续缩放和平移。

## 教学流程与数据

正式实验在“属性与诊断”上方提供可折叠“实验指导”，含探究问题、步骤建议、空白测量安排和三个按需展开的提示层级。提示依次从接线/开关/异常状态、对照测点，推进到检查电流与电压关系；不校正学生线路、不闭合开关、不改电源/灯泡或选择量程，不预填学生数值。模板标识和所有指导内容均不参与求解。

四行空表规划“串联/并联 × 相同/不同灯泡”，每行包含 I总/I₁/I₂ 与 U总/U₁/U₂，单位 A/V，均为“待测”。它是测点规划，不是第二套测量数据；“前往记录表”进入既有真实数据入口。可用三对表同时测量，也可断开开关后移动一对表逐点测量。记录区由学生填写接法/组别、测点及观察备注，手工抄表或采集；观察备注随采样快照保存。无仪表或未采样时没有伪造记录。

图线、CSV、JSON 及本地保存均复用任务 07/04 的路径。后续更换灯泡、电源或线路不覆盖旧记录、备注和当时快照；不把学生估读值改成模型真值。保存、导入或刷新后按 `experimentId` 恢复指导入口，接线/配置/测量快照保持，从初态重新求解；提示展开状态和未采样输入仍为会话 UI 状态。

## 独立手算与边界

灯泡本构 U=Rcold·I+a·I³，a=(Ur−Rcold·Ir)/Ir³，各灯在自身额定点满足 U=Ur。独立预期如下，I 总按电源供电方向取正，P=UI：

| 已闭合模板 | I总 / I₁ / I₂（A） | U总 / U₁ / U₂（V） | P₁ / P₂（W） |
| --- | --- | --- | --- |
| 串联，相同 | 0.3 / 0.3 / 0.3 | 6 / 3 / 3 | 0.9 / 0.9 |
| 串联，不同 | 0.3 / 0.3 / 0.3 | 9 / 3 / 6 | 0.9 / 1.8 |
| 并联，相同 | 0.6 / 0.3 / 0.3 | 3 / 3 / 3 | 0.9 / 0.9 |
| 并联，不同 | 0.5 / 0.3 / 0.2 | 3 / 3 / 3 | 0.9 / 0.6 |

相同功率仍等亮，亮度 b=P/(P+0.9 W)，不同串联灯泡分别为 0.5、2/3，不同并联灯泡分别为 0.5、0.4。验证容差为 1e-9+1e-6·|预期值|，归一化 KCL/本构/功率残差≤1e-6；表盘与采集继续按档位分度值舍入，学生估读单独保留。

线性 3 V/10 Ω/20 Ω 的第 8.2 节基准继续由原 MNA 测试验证。原非线性、开路、短路、电表反接/超量程/多量程、浮置、超模型与不收敛测试全部保留。新增模板测试覆盖断开开关无灯泡功率、并联支路断开、反接、多量程误接及电流表直接跨源导致零压约束冲突，不输出正常旧读数。亮度不能替代测量，不模拟热惯性、烧毁或新非理想器材效应。
