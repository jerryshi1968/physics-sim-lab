# 四柱滑动变阻器

日期：2026-11-04。按用户追加要求，在 M3 任务 07 之后加入自由搭建器材；正式任务 08 实验流程未开始。

## 端口与模型

器材类型为 `electrical.rheostat`，定义版本 1。默认最大电阻 `maxResistanceOhm=20 Ω`，滑片位置 `position=t=0.5`。最大电阻必须有限且大于零，位置必须有限且在 [0,1]；拒绝内部正电阻乘法下溢成零的参数，正常端点的零电阻允许。

| 接线柱 | 物理含义 | 未旋转时局部坐标 / m |
| --- | --- | --- |
| A (`a`) | 电阻丝左端 | (-0.075, -0.032) |
| B (`b`) | 电阻丝右端 | (0.075, -0.032) |
| C (`c`) | 上方金属杆左端，与滑片 S 相连 | (-0.075, 0.040) |
| D (`d`) | 上方金属杆右端，与滑片 S 相连 | (0.075, 0.040) |

滑片由 A 端向 B 端移动，电气支路为 R_AS=t·Rmax、R_SB=(1−t)·Rmax，C-D 为理想导线。编译时以 C 表示 S；两段正电阻进入原有 MNA，实际为零的段直接合并为理想导线，不添加小电阻、gmin 或猜测接法。三个/四个柱同时使用时仍按完整网络求解，可形成带负载分压器。

| 接法 | 等效结果 |
| --- | --- |
| A 与 C/D | t·Rmax，滑片靠近 A 时减小 |
| B 与 C/D | (1−t)·Rmax，滑片靠近 B 时减小 |
| A-B | 固定 Rmax，与滑片无关 |
| C-D | 直接导通，与滑片无关 |

零阻端若直接跨接理想电源，会返回原有 `IDEAL_SOURCE_SHORT` 诊断。模型不模拟温升、允许电流、接触电阻、烧毁或真实线圈寄生效应。

内部支路 ID 按变阻器 ID 排序分配，避开所有用户器材/导线及其他生成 ID，保持 80 字符以内；不把用户 ID 截断或依赖数组顺序。端子输入上限由 1600 调整为 1800，覆盖 200 个四柱器材及 500 根双自由端导线；支路上限 2000、每连通分量最多 256 未知量及数值病态诊断保持。

## 操作与持久化

器材库和实验区复用本项目原创实物风格 SVG。四柱均可点击接线或拖入导线吸附；旋转、左右翻转后接线柱和导线跟随。删除器材保留原接线位置的自由导线，撤销恢复。

拖动红色滑片用世界坐标反变换到器材局部坐标，保留抓取偏移并限制在行程内，支持鼠标和 Pointer Events 触摸。滑片获焦后方向键调整 0.01，Shift+方向键调整 0.1，Home/End 到 0/1；键盘位置增减按 A→B 的局部方向定义。属性区可精确输入最大电阻及滑片位置，合法值立即生效，无需另行应用。

滑片图形逐事件预览，电路计算预览限速 80 ms，并补发停下后的最后位置；沿用 Worker 20 ms 合并调度、超时与文档/revision/runId/sequence 保护。下一次预览计算期间可保留同一器材、同一文档版本的上次成功预览；失败结果立即清除正常效果，不沿用成功值。默认自动更新时，灯泡和表针随预览变化；显式暂停时仍按暂停规则处理。

拖动不修改正式文档、保存标记、revision 或历史；预览结果不能采集测量。松手一次提交，重新求解后才可采样，撤销/重做为一步。Escape、pointercancel 或丢失捕获取消，清除待发预览并恢复正式位置。保存/JSON 导出只读取正式文档，不把预览写入存档。采样快照保留当时滑片参数，之后移动不改旧记录。

## 独立基准与验证

6 V 电源串联 10 Ω 负载及 20 Ω 变阻器：A-C 接法的 t=0、0.5、1 分别为 0.6、0.3、0.2 A；B-D 顺序相反。A-B 恒为 0.2 A；C-D 恒为 0.6 A。

6 V 跨 A-B，t=0.25，10 Ω 负载接 C-B：R_AS=5 Ω，R_SB=15 Ω，15∥10=6 Ω，因此负载电压 36/11 V，电流 18/55 A，电源供电 6/11 A。这验证三柱同时参与，不依靠两端模式判断。

测试按独立手算比较，容差为 1e-9+1e-6·|预期值|，KCL/本构/功率归一化残差≤1e-6；仪表按自己的分度值舍入，不把显示分辨率当求解精度。
