## 器材与坐标

统一 SI：位置、火焰高度、焦距、孔径和屏尺寸均为 m，角度内部为 rad。实验画布为器材立面，光屏采用斜侧视外观，右侧正视投影为垂直光轴的 y-z 平面；画出的白板宽度不作为光程厚度，外观斜视也不改变真实屏面的朝向。当前支持水平光轴、左向右照明、一座、一蜡烛、一薄凸透镜、一光屏；多镜、倾斜/翻转与混合电学场景明确拒绝，不按实验 ID 推断成像。

| 类型 | 参数与范围 | 坐标含义 |
| --- | --- | --- |
| optical.bench | lengthM：0.2～2 m，默认 1.2 | x 为座刻度零点，y 为座基准高度 |
| optical.candle | heightM：0.002～0.04 m，默认 0.02 | x 为物面，y 为火焰物体中心 |
| optical.convex-lens | focalLengthM：0.02～0.5 m，默认 0.10；apertureRadiusM：0.002～0.04 m，默认 0.006 | x 为薄镜面，y 为光心 |
| optical.screen | widthM、heightM：0.02～0.2 m，默认各 0.08 | x 为屏面，y 为屏中心 |
| optical.ruler | lengthM：0.05～1.2 m，默认 1 | x 为独立尺零点；自由摆放，不绑定其他器材 |

三件成像器材的 x 须在光具座区间，中心 y 在座基准以上 0.01～0.3 m；世界基准坐标绝对值不超过 1000 m。源必须在镜左，不与镜重合。操作位移只改被拖器材，不移动或自动调高其他器材。独立尺平移不改变任何光线或像，只改变读尺零点。

入口“凸透镜成像实验”提供空白与未同高/未对焦的一套器材，先预览确认再替换当前工作。默认镜位 0.50 m，源位 0.20 m，屏位 0.73 m；源/屏中心 0.06 m，镜中心 0.07 m。没有对焦按钮，也不会移动屏到答案位置。几何器材无需接线柱；光学场景不启动电学 Worker，混合器材仅提示超出当前支持范围。

器材库增加常驻“电学 / 光学”页签，默认空白工作台也能切到光学并直接放置。切页不改文档，只清除待放置状态；已有其他领域装置或正式实验时，显示器材与新建对应领域的空白实验入口，预览确认才替换，不插入当前模型不支持的混合器材。页签支持鼠标、触摸、左右键及 Home/End。

## 同一模型中的公式、射线与投影

u=xL−xC>0，s=xS−xL 为当前屏距。薄镜公式 1/f=1/u+1/v、m=−v/u，实像 v>0、m<0，虚像 v<0、m>0。复用 solveThinLens；u=f 时 v/m 为 null。坐标差只在 8·Number.EPSILON·max(1,|xL|,|xC|) 内与 f 重合时归一到精确焦点，修正减法舍入，不按毫米或实验分度值夹平焦点两侧。u=f±1e-10 m 仍保留实/虚分类与大有限像距；像不在光具座内时允许找不到清晰像。

物体采样火焰发光区域，不模拟蜡烛燃烧或环境照明下整支蜡烛的相机照片。9 个纵向层、5 个横向位置构成上下不对称的火焰轮廓；每个物点通过圆孔径中心及周边 8 点，共 405 条固定采样光线。上下不对称轮廓使倒立可见。

对物点 (yO,zO)，孔径落点 (yA,zA)，镜光心 yL：

```text
qY,in  = (yA-yO)/u         qZ,in  = (zA-zO)/u
qY,out = qY,in-(yA-yL)/f   qZ,out = qZ,in-zA/f
yS = yA+s·qY,out           zS = zA+s·qZ,out
```

入/出射斜率合量超过 0.35 时停止正常结果，明确提示超出近轴范围。成像公式与这些光线共享同一套坐标/参数；光屏移动仅改变传播到屏面的落点。偏心物点的中心像位置为 yL−(s/u)(yO−yL)，不会被暗中拉回光轴。

屏上同一物点的离焦圆半径 r=R·|1+s/u−s/f|，来自圆孔径映射。清晰度教学指标 Q=1/(1+(r/0.0005)²)，Q≥0.8 且有采样落屏、实像及屏在镜右时称清晰；不是抵达某个像距才切换图像的硬布尔开关。同高标记以中心差≤2 mm 为教学容许值，不作为光线强行对齐条件。

右侧正视投影裁剪到真实屏宽/高，实验区只画光屏斜侧视器材。采样落屏比例是几何样本比例，不是光度计值。渲染将每个落点绘为随 r 展开的柔和色斑，基础绘图斑半径 0.7 mm、附加半径 r/3，透明度随展开面积减小；此绘图核不是衍射或像差模型，不宣称真实照度精度。完全未落屏、错侧或无有效模型时不保留旧像。

u<f 时真实右侧光屏上只可能有发散光斑，不绘制可承接虚像；u=f 也只有平行束投影，无有限像。默认关闭辅助；开启后才显示光线/反向虚线、公式数值及独立的“虚像观察辅助示意（非光屏）”。示意按放大率绘制，超过 4 倍裁限示意大小并明确说明；不将它放到实物光屏上。

## 操作、读尺、记录与重载

拖动器材横向调位置、纵向调光心高度；精确值可在属性区输入。缩放和平移只改变视图；尺零点移动与器材移动独立。座刻度为 1 cm，独立尺细分 1 mm（画布放大显示细格）；记录区另有可横向滚动的读尺放大窗，按原尺的零点/分度显示器材标记，不直接给自动数字答案。图形、放大窗与模型使用同一世界坐标。

拖动预览不改 revision、存档或记录，预览期间不能采样；松手一笔历史，取消/丢失捕获/Escape 回滚。光学同步求解为固定小规模采样，不另建 Worker；电学调度默认逻辑保持。

每次手工输入三件器材的尺读数（m）和学生判断的虚实/正倒/大小/清晰度，附备注。三位置留空记缺失；物距 u 与屏距 s 由当时手工位置相减。2026-11-07 按用户反馈移除独立的实测像距输入，学生选择“实像”和“清晰”且模型确为清晰实像时，由同次手工光屏位置减透镜位置得到实测像距 v；不使用理论值或器材精确坐标填充。六项长度记录复用既有 MeasurementRecord，原输入、按尺分度的显示、模型真值分开，成像观察及模型状态写入共享快照备注。

未确认“实像”和“清晰”，或非实像、离焦、未落屏时，实测 v 的原文留空、有效值为 null，并保留不可用诊断；透镜或光屏位置读数缺失时也不补值。已有存档中的手填像距保持原值，无格式迁移。虚像理论 v 不冒充实测值，u=f 也不写 Infinity。屏距始终是当前屏位置的距离，不能无条件当成像距。所有原始器材/尺零点/参数和六行记录共用同一次快照。

读尺出界时相应位置及依赖它的距离记录无正常值。有限十进制/科学计数可用，公式和算术溢出拒绝整批；没有从模型自动填测量值或自动判改学生观察。事后修订各行独立，不隐式重算其他手工记录；界面提示改位置后核对距离。CSV/表格同源，屏距—物距图可画五组位置；实测像距—物距图只画清晰实像的有效值，缺失/不可用不补零。

保存 JSON/本地存储后从初态重新算像，旧读尺、观察、备注及参数快照保持；辅助开关、滚动位置及未采样草稿是会话 UI，不跨刷新保存。继续使用格式 2，不新增 schema 或迁移分支；教材映射保持 pending_teacher_review，未编造审阅信息。
