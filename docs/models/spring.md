# 静态弹簧与线性范围小样

实现：`src/physics/samples/spring.ts`。接口：`solveSpring(input)`。假设支架固定、竖直无质量理想弹簧、静态平衡，无振动或塑性模型。

## 符号与公式

`originalLengthM=L0`（m，>0），`stiffnessNPerM=k`（N/m，>0），`hangingMassKg` 与 `trayMassKg`（kg，均≥0），`gravityMPerS2=g`（m/s²，>0），`maxExtensionM`（m，≥0），`ratedLoadN`（N，>0）。`supported` 表示理想有效支架，`transitioning` 表示过渡示意期间禁止读数，两者当前直接由调用者提供，尚无挂载图。

总质量 m=钩码质量+挂载盘质量；由竖直平衡与胡克关系得 F=mg=kΔx，故 Δx=F/k，总长 L=L0+Δx。返回原始数值不提前按仪表分度值舍入。尺零点和学生读尺过程尚未实现，不能把理论 L 当作学生完成测量。

## 独立五点基准

L0=0.10 m、k=20 N/m、g=10 m/s²、盘质量 0、最大线性伸长 0.06 m；小样另显式配置额定载荷 1.2 N。由质量乘以 10 得力，再除以 20 得伸长：

| m（kg） | 手算 F（N） | 手算 Δx（m） | 手算 L（m） |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 0.1000 |
| 0.025 | 0.25 | 0.0125 | 0.1125 |
| 0.05 | 0.50 | 0.0250 | 0.1250 |
| 0.075 | 0.75 | 0.0375 | 0.1375 |
| 0.10 | 1.00 | 0.0500 | 0.1500 |

各期望量是测试中的独立常量。Δx 与 L 绝对误差 ≤1e-6 m。测试对五个返回工作点另作带截距的一元最小二乘，斜率 `Σ(x-x均)(F-F均)/Σ(x-x均)²` 应为手算 k=20 N/m，相对误差 ≤1e-6；不在本任务引入通用图表/拟合产品模块。

## 边界与无效状态

力或伸长超过配置边界返回 `RATED_LOAD_EXCEEDED` / `LINEAR_RANGE_EXCEEDED`，不返回外推长度；两个边界同时超出时先报额定载荷。恰好达到边界允许，比较仅容纳 `8×Number.EPSILON×max(当前量,边界量)` 的浮点舍入（伸长容差单位 m、力容差单位 N），不是额外材料弹性范围。0.12 kg 为 1.2 N、0.06 m 的边界点；0.120001 kg 超载，额定力放宽到 2 N 时 0.13 kg 仍超线性范围。

支架无效、过渡期、k≤0、负质量或非有限参数均禁止正常读数。盘质量单独计入：盘与钩码各 0.025 kg 时 F=0.5 N、Δx=0.025 m。卸载回零载时恢复 L0；不承诺范围外真实材料能恢复。
