# 水沸腾：集总热学模型 v1

实验 `J-THERM-01`；模型版本 `thermal.boiling.lumped.v1`。

## 量与假设

内部使用 SI：温度 K、时间 s、水质量 kg、液量 m³、功率 W。摄氏温度显示为 T−273.15；温差 K 与 ℃ 数值相同。水密度近似 1000 kg/m³，比热容取教学近似 4200 J/(kg·K)，汽化潜热 2256000 J/kg。烧杯热容量按其质量 × 800 J/(kg·K) 近似，非材料标定值。

默认 200 mL 水、20 ℃ 初温和环境、500 W 输入、效率 0.7、散热系数 h=0.5 W/K、烧杯 30 g。以上装置参数是可调教学设定，不声称真实酒精灯标定功率。标准大气压、纯水，沸点固定 373.15 K；不实现气压计算、过热、温度计热惯性、沸腾前蒸发、局部对流和泡径动力学。画面气泡仅示意净供热为正的沸腾状态。

热容量 C = m×4200 + C杯。加热有效功率 P有效 = ηP（烧杯未放在网面或关火时为零）。非沸腾时：

`C dT/dt = P有效 − h(T−T环境)`。

恒定功率一段内用解析指数解（h=0 时用线性解），跨沸点先精确计算到达时间。达到沸点后，若净供热 Q净 = P有效−h(T沸−T环境)>0，则温度保持沸点，`dm/dt = −Q净/Lv`；不把潜热变成温升。蒸干在事件时刻截断，禁止继续显示水温。停止加热则按余下水量的热容量冷却。净供热不足时只能趋向低于沸点的平衡温度。

## 独立预期值

使用水 0.1 kg、杯热容量 20 J/K、20 ℃ 初温、200 W×0.5、无散热：C=440 J/K。

1. 44 s 输入 4400 J，升温 10 K，水温 30 ℃。
2. 加热到 100 ℃ 需 `440×80/100=352 s`。
3. 再加热 225.6 s 输入 22560 J，汽化 0.01 kg，余水 0.09 kg，温度仍为 100 ℃。
4. 蒸干总时刻 `352 + .1×2256000/100=2608 s`，再多步也不推进水状态。
5. 独立冷却：100 ℃、同样质量和热容量、h=2 W/K、关火 220 s，得到 `20+80/e=49.4303553 ℃`，水质量不变。
6. 100 W、h=2 W/K、20 ℃ 环境，平衡温度 70 ℃，不会沸腾。

30/60 Hz 分段推进与单大步跨相变结果对比，检查温度、余水质量和时刻；不依赖画面帧率或播放速度改变热学方程。

## 装配、采样与保存

烧杯沿竖直方向摆放，底部距加热网面容差 2.5 cm，横向中心容差 3.5 cm；这些是交互装配容差，不是热学测量精度。温度计玻璃泡以实际旋转后位置检查，离杯壁 7 mm、离杯底 8 mm、完全低于液面才读水温；液面随余水量下降。支架作固定支撑显示，不新造机械连接模型。额外不兼容器材/重复装置、非水密度或非法水量均禁止正常求解。

时钟上限 7200 s；可 1/5/20/60 倍播放，单步 1～300 s。暂停冻结过程；停止加热继续计时以观察冷却。运行时温度、余水与火焰开关不写回初态。初始水量/温度/环境/杯热容量或关键器材改变重置过程；功率、效率、散热、温度计分度与移动器材不抹掉已发生的温度。移动烧杯离开网面后停止向水供热，温度计移出水后读数无效。

记录在用户保存/采集时冻结时间、温度、余水量、供热状态、器材与配置。手工空值记缺失；图线只用存下的成对有效时间/温度，不用模型曲线替代抄表。修订后派生图线重新计算；重置后的过程另组连线。JSON 中温度数值和修订计算使用 K，原始手工输入文本仍保留学生输入的 ℃ 字符串；界面与 CSV 为 ℃。保存重载从初态开始，历史记录和快照仍保留。
