## 器材、单位与连接

世界 x 向右、y 向上；位置/力臂 m、质量 kg、力 N、力矩 N·m，内部转角 rad。测力计方向编辑器为 °，0 向右、90 向上，−90 向下；进入模型转换为单位向量。默认 g=10 N/kg，为文档教学配置，不声称唯一自然常数。

器材库常驻电学/光学/力学三个页签。力学包含杠杆、支架、钩码、弹簧测力计、独立刻度尺。力学尺为独立类型 `mechanical.ruler`，默认长度 1 m、允许 0.05～1.2 m，沿用光学尺同一原生图形、1 mm 分度与 cm 标数，光学原类型保持。移动尺不改变支点、挂载或计算；可缩放读细刻度。

| 器材 | 参数及范围 |
| --- | --- |
| 杠杆 | 每侧挂点数 2～10、间距 0.01～0.1 m，默认各 6、0.05 m；支点编号在实际挂点内；质心、螺母均在杆长内 |
| 可选自重 | 杆质量 0～2 kg，默认 0.1；质心距杆中点默认 0.02 m；螺母质量默认 0.02 kg，可通过文档参数配置 0～0.5；自重开关默认关 |
| 支架 | 高 0.1～0.8 m，默认 0.32；可承受反力合量 1～200 N，默认 100；理想固定铰支点可承担水平及竖直反力 |
| 钩码 | 总质量包含自身挂件，0～2 kg（不含 0），默认 0.1；不附加未声明的挂盘质量 |
| 测力计 | 施加拉力 0～100 N、方向 −360～360°、量程 0.1～50 N、分度 0.001～1 N，默认 0 N / −90° / 5 N / 0.1 N；分度大于量程为不可读状态 |

杠杆位姿的原点为杆中点。沿杆挂点 k 的世界位置为 C+Rot(θ)(k·spacing,0)。支架位姿为底座，顶端为 (x,y+height)；杠杆 `supportId`、`pivotIndex` 指定支架和支点，实际杆中点由该安装约束确定。钩码/测力计用 `leverId`、`hookIndex` 指定受力挂点，随杆、支架及支点配置变化移动。连接在器材参数中显式保存，不伪装成电线或创建第二套场景格式。

选中后可在挂接区指定支架或杠杆/挂点，解除时选“不挂接”。也可拖动到支架顶端或挂点附近，松手在 0.04 m 内吸附；拖离则解除。吸附仅建立学生选择的安装/挂载约束，不改质量、力或调平。预览不写 revision/历史/保存，期间不采样，松手一次事务，Escape/触摸取消恢复。未挂接的器材保留且不施力；有非空失效引用则诊断，不偷偷视为正确挂接。当前一根杆、可有多个挂载，多个独立杠杆或混合领域明确拒绝。

## 力矩、反力与范围

对每个实际受力点 P，r=P−pivot，τ=rxFy−ryFx。逆时针为正、顺时针为负；非零力的力臂 d=|τ|/hypot(Fx,Fy)，零力取 0。挂码 Fy=−mg；测力计 Fx=Fcosα、Fy=Fsinα，F 是用户明确施加的拉力，不从鼠标拖速推算。仪器显示另按分度舍入，手工原文另存。

自重关闭时忽略杆和调平螺母的重力，保留实物；自重开启时，杆重作用于配置质心，螺母重作用于其实际位置，两者作为真实 loads 加入。调平不会对后来力矩添加隐含抵消项。支点所需反力 R=−ΣF，合量超过支架上限即无有效模型解；失衡时反力为该静力约束计算中的合力平衡要求，不声称完整转动动力学中的瞬时反力。

Στ 容差为 1e−9 N·m+1e−9Σ|τi|，并公开顺/逆力矩和归一残差 |Στ|/max(1,Σ|τi|)。非平衡保留真实杆位姿，只报告顺/逆趋势，不自动转杆、移挂点或改力；不制造有时间含义的动画。

目标拉力仅在一个测力计、支点/挂点/方向足以唯一确定时，通过 F=−Στknown/(rxny−rynx) 反求。分母 ≤1e−12 m 为零力臂；负 F 表示该方向不能平衡；无测力计或多个未知力不输出唯一目标。目标平衡所需反力若超出支架能力也明确拒绝；有限性包装防止极端独立 API 输入溢出。理论目标在学生勾选辅助后才显示，不写入施加拉力或记录。实际读数超量程、零力臂或未调平时为空，不沿用旧值。

坐标限 ±1000 m、转角限 ±2π、g≤100 N/kg；有限参数和数量先经原场景校验。支架/挂码不支持倾斜或翻转，拉力方向通过独立参数设置；杆和尺可转动。缺支架、杆数不符、失效引用、越界挂点/质心/螺母、过载、数值溢出等不携带正常解。旧纯小样保持不变，新适配层与求解包装检查全部有限结果。

## 空载调平与教学显示

实验起点为已安装但不水平的空杆，钩码/测力计均未挂载。先调转角至水平，自重模式下还需调整螺母使空载力矩平衡；只有无挂载、水平且力矩平衡时“确认空载调平”可用。忽略自重时只需调水平，不假造螺母重力。

确认保存的是杆参数、转角、支架参数、g 的零位指纹，不是后来可用来抵消外力的数值。改变支点、间距、杆重/质心、螺母或重力设置即不再匹配，必须先卸载重新调平。整个装置平移不改变力矩或调平状态。尚未确认时不显示正常仪表示数，不能采集本实验记录。

力/作用线/垂线/理论默认关闭，可随时关闭；打开辅助只改变视图。表针依据实际施加拉力/量程，超量程和不可用明确显示。测力计为静态拉力输入与量化读数接口，不在本任务模拟内部弹簧形变；`forceReading` 可供下一任务的真实牵引力读数复用。

## 记录与独立基准

每组对挂载手填力和力臂、判断顺/逆，由本组手工输入相乘得到有符号力矩，不用模型真值填学生表。记录自己的平衡判断；挂点、拉力方向、自重模式、实际状态、调平指纹和 g 随原器材共享快照保留。错误/缺失/超量程不补零；事后各行修订独立，修改力/力臂后自行核对力矩。力矩/力图线只取记录有效值，CSV/JSON 与表同源，保存重载保留全部挂接与方向。

| 已知条件（g=10） | 独立预期 |
| --- | --- |
| 左 −0.20 m、0.10 kg；右 +0.10 m、0.20 kg；忽略自重 | τ=+0.20/−0.20 N·m；平衡；R=(0,3) N |
| 左同上，右 +0.10 m 竖直向下拉 | F=2 N；d=0.10 m；R=(0,3) N |
| 右 +0.10 m 与杆夹角 −30° | F=4 N；d=0.05 m；Fx=2√3 N、Fy=−2 N；R=(−2√3,3) N |
| 两挂码都在支点左侧 | 同向力矩，相加为正，不能平衡 |
| 测力计在支点或方向沿杆 | d=0，不能唯一反求拉力，不除零 |
| 计自重：杆 0.1 kg 在 +0.02 m、螺母 0.02 kg 在 −0.10 m | 空载力矩 −0.02+0.02=0 N·m，反力 1.2 N；之后左挂码另加 +0.20 N·m，必须失衡 |

数值基准误差：力矩≤1e−9 N·m、目标拉力≤1e−6 N；显示分度与求解精度分开。测试常量来自上述手算，不从被测函数生成。真实执行证据见[任务 10 验收](../acceptance/M5-TASK10.md)，演示 `node scripts/lever-experiment-demo.mjs`。教材版次、章节、页码与审阅信息继续 `pending_teacher_review`，没有教师通过结论。
