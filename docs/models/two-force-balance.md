# J-MECH-06 二力平衡条件

模型 `mechanical.two-force.rigid.v1`，初中力学。复用已有动力学小车、带定滑轮轨道和钩码三种注册器材；本实验将轨道表现为两端装定滑轮的光滑水平台，不新增器材类型或通用绳轮系统。小车和台面为俯视，左右钩码以侧视示意，不能把屏幕里钩码的绘制方向当作水平面的第三个方向。

## 教学操作与范围

比较两端钩码质量不等、相等，再保持相等并把小车在水平面内扭转后释放。可拖小车改变初始位置，从而改变拉力方向；选中小车用弯箭头扭转，或输入/选择起始角度。先重置再拖动运行中的装置；修改质量、位置、扭转角或初速度会结束本次运动，旧记录保留。可设置非零水平初速度，用来区分平衡时保持静止与保持匀速直线运动。

两根绳均接在同一辆小车上，本项不提供把两力分别接到两个物体的对照。讨论的是水平方向的二力；小车竖直方向的重力和支持力抵消。采用光滑平面、轻质不可伸长绳、理想定滑轮，不模拟轮转动惯量、侧向轮胎约束、阻力、摩擦或阻尼。扭转后可以振荡，不会自动停在零角度，不能用外加阻尼偷偷制造平衡现象。

## SI 与耦合动力学

内部统一 kg、m、s、rad、N、N·m。小车广义坐标 `q=(x,y,θ)` 相对于实验台中心；半长 `a=0.11 m`，半宽 `b=0.05 m`，总质量 `M=车体质量+车上配重`，均匀矩形惯量 `I=M((2a)²+(2b)²)/12`。悬挂总质量包括同侧串接的全部钩码，不把闲置钩码算进去。

左右固定导向点为 `A_i=(s_i H,0)`，其中 `H=台长/2`、`s_i=-1,+1`。小车两端连接点为 `p_i=(x,y)+s_i a(cosθ,sinθ)`，水平绳长 `ℓ_i=|p_i-A_i|`，钩码下垂距离 `h_i=0.25+ℓ_i(0)-ℓ_i(q)`。每侧两段绳长度之和恒定。令 `j_i=∂ℓ_i/∂q`，`c_i=q̇ᵀ(∂²ℓ_i/∂q²)q̇`，由运动约束和牛顿定律得到：

```text
[diag(M,M,I) + Σ m_i j_i j_iᵀ] q̈ = −Σ m_i (g+c_i) j_i
T_i = m_i [g+c_i+j_i·q̈]
F_i = −T_i (p_i−A_i)/ℓ_i
τ_i = (p_i−(x,y)) × F_i
```

因此运动中的绳张力不能一概设成钩码的 `m_i g`；小车同时满足 `M(ẍ,ÿ)=ΣF_i` 与 `Iθ̈=Στ_i`。既检查合力，也计算力矩，不把合力为零单独当成小车运动状态不变的充分条件。

能量检验使用 `E=½M(ẋ²+ẏ²)+½Iθ̇²+Σ[½m_iℓ̇_i²+m_i gℓ_i]`；势能只差一个与初始垂长有关的常数。数值积分为 RK4，子步最长 0.002 s；第一次越界在最后有效子步内二分定位，不把小车或钩码穿过限位后继续输出正常状态。

## 独立预期

默认 M=0.35 kg、台长 1.6 m、两侧各 0.05 kg、g=9.81 m/s²，初始对正、静止。两张力均为 0.4905 N，合力/合力矩为零，释放后位置和角度保持。若同一装置初速度为 +0.1 m/s，1 s 后位移为 +0.1 m，速度仍是 +0.1 m/s。

左 0.05 kg、右 0.10 kg、对正静止时：

```text
a_x = (m_R−m_L)g/(M+m_L+m_R) = 0.981 m/s²
T_L = m_L(g+a_x) = 0.53955 N
T_R = m_R(g−a_x) = 0.8829 N
T_R−T_L = M a_x = 0.34335 N
0.5 s 后 x=0.122625 m，v=0.4905 m/s
左钩码下垂距离 0.127375 m，右钩码 0.372625 m
```

左侧钩码升到 0.05 m 上行限位时，小车位移为 0.20 m，时刻 `sqrt(0.4/0.981) s`；应在该边界终止，不能继续算作未碰限位的实验。

等质量但中心扭转 θ=30° 时，初始合力仍为零，力矩却不为零。独立对称化：`ℓ=sqrt(H²+a²−2Ha cosθ)`、`j=Ha sinθ/ℓ`、`θ̈=−2mgj/(I+2mj²)`、`T=m(g+jθ̈)`。由此得到 `I=0.0017033333 kg·m²`、`θ̈≈−29.205673 rad/s²`、两张力各约 0.3996041 N、总力矩约 −0.049746997 N·m。小车开始转动，不能因两力等大反向就显示“已平衡”。核心测试还检验两秒无阻尼转动的能量误差小于 1e-7 J。

## 有效状态与兼容

一张台、一辆车、两组直接接入钩码，最多六件钩码、每侧总质量不超过 1 kg。小车起始扭转角限 ±60°，初速度限 ±0.3 m/s；台和钩码保持正立，重力加速度正值且不超过 30 m/s²，不启用随机误差。小车必须在台上，钩码引用/父子链有效，无重复直挂、分支、循环或同时连接其他模型。

到达台边、台面横向边界、钩码上下限、松绳或转角有效范围时终止；这些边界终止状态不接受正常观察记录。每次观察最长 8 s，对正静止等对照也能结束。暂停/继续/0.1 s 单步及播放速度只改变运行，不写回文档初始位置。局部有效范围之外不声称支持通用任意绳轮或完整碰撞。

小车新增可选 `twoForceTableId`、`twoForceSpeedMPerS`；钩码新增可选 `twoForceTableId`、`twoForceSide`，继续复用 `parentWeightId`。旧字段、器材定义版本、文件格式和其他实验默认值保留；缺省可选字段不被补成 undefined。现有悬挂质量字段不被当作本实验第三组钩码，额外无关小车参数不显示为本实验控制项。
