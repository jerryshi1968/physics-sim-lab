# 命令历史、保存加载与导入（M1 / 任务 04）

## 命令与事务

任务 07 新增 record-measurements、correct-measurement、remove-measurement 命令；同批多测点采样一次提交，修订保留原始抄表与采样状态，删除最后一条引用时清理共享快照。保存/JSON 包含记录及快照，CSV 是单独的分析导出，详见[测量契约](measurements-and-export.md)。

后续补充 rename 命令与标题旁“修改名称”入口：名称去除首尾空白，不能为空、最多 200 个字符；内部空格保留。改名参与历史、文档保存与导出文件名；取消或无变化改名不产生历史。

`src/core/workbench/history.ts` 是不依赖 React/DOM 的命令入口。SceneCommand 包含放置器材/导线、移动/参数修改、接线、删器材/线、修改路径和线头形状；复用原有核心编辑函数，成功校验后才存入历史。App 用同步引用读取最新历史，再更新 React 视图，避免连续事件用旧场景覆盖新结果。

按用户要求增加 remove-equipment-batch 命令：单件与多件删除均保留导线，原端口在删除前的世界坐标转为自由线头，曲线和其他接线不变；多选一次删除只提交一笔历史，撤销恢复器材和全部原端子引用。未知 ID 或已有测量记录引用时整批拒绝，不产生部分结果。Shift 选择不修改文档或占用历史，Delete 快捷键避开输入控件及模态文档流程。见[多选删除验收](../acceptance/M2-SELECTION-DELETE.md)。

器材、线身、线头、弯曲点的拖动沿用本地预览，松手只执行一个命令；Escape/指针取消不提交。无效或内容没有变化的编辑不增加 revision、不清空重做。有效新命令清空重做分支；删除器材时的相连导线与器材作为一个快照恢复，保留 ID、参数、姿态、已接端口、自由端位置和所有弯曲点。

撤销/重做恢复完整文档编辑状态，同时保留当前视口；revision 单调递增，updatedAt 为操作时间。历史记录中的测量、模型快照和来源信息不被后续参数编辑改写。平移/缩放只是 UI 状态，写入当前文档以供保存，但不占用编辑历史或清空重做。导线共用颜色、选择、接线预备、打开面板不持久化。

两个历史栈各限制为最近 100 项及 20 MiB 的文档 JSON UTF-16 字节估算，以先达到的限制为准；不是 JS 堆内存精确上限。超出最旧的历史被淘汰。撤销历史仅限当前会话；新建、确认导入/加载、刷新恢复均建立新历史。Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做；输入框、选择框和可编辑文本使用浏览器自身的文本撤销。

## JSON、迁移与边界

`src/core/scene/transfer.ts` 提供 parseSceneJson / serializeScene，`migrate.ts` 提供独立可测试迁移入口；错误不返回部分场景。文件选择后先按 File.size 拒绝超过 5 MiB 的文件，再读取；纯核心再次按 UTF-8 字节长度检查。JSON 解析不执行代码，明确拒绝任何对象层级的 __proto__、constructor、prototype 字段，避免校验库忽略危险键造成静默丢弃。

解析后先检查最多 200 件器材、500 个连接、10000 条记录。版本 2 直接完整校验；版本 1 先按旧契约严格校验（两端必须有端口、禁止自由位置字段），迁移只将 schemaVersion 改为 2，其余字段保留，再执行注册表/参数、唯一 ID、引用、端口能力及记录引用校验。未知版本、未知器材/定义版本、未知字段、同一接线柱连自身、数量超限等均拒绝；已注册的历史 junction 保留，不添加库入口。

导入成功只展示原生模态对话框中的标题、数量、版本和替换提示；标题始终按文本渲染，不插入用户 HTML。确认才替换当前文档并清空历史；取消、Escape、坏文件或读文件失败都保留当前工作。导出为 UTF-8 JSON，校验并检查输出 5 MiB 上限后通过 Blob 下载；包含初态、模型配置、测量记录、来源和视口，不包含动态运行态或命令函数。

## IndexedDB

`src/app/persistence/localSceneStore.ts` 使用浏览器原生 IndexedDB：数据库 cn-physics-lab 已升级为版本 2（与场景 JSON schemaVersion 无关）；experiments 仓库按 documentId 分别保存 json/title/savedAt，documents/latest 保留最近保存快照用于启动恢复。保存记录与 latest 在同一个 readwrite 事务提交，任一写入失败都回滚；只有事务完成才更新界面已保存状态。不同 ID 不覆盖，同一 ID 再次保存更新自身，改名不改变 ID，同名也可并存；导入相同 documentId 的文件仍视为同一个实验。

启动时读取并校验最近保存内容，在读取完成前工作区暂不可编辑，避免慢加载覆盖刚创建的工作。有效内容自动恢复；没有保存则新建空白；损坏或不支持的数据保留在库中并报错，工作台仍可编辑/导入备份，不自动修复或删除数据。“加载”打开按保存时间排序的实验列表，展示名称、时间和 ID，选择记录后完整校验，再预览确认替换；关闭列表、取消预览和损坏记录都不替换当前工作。“新建实验”生成新 ID，只清空当前工作，不删除本地保存。加载旧实验本身不会更改“最近保存”的启动快照，只有再次保存才更新。

从数据库版本 1 升级时，在版本变更事务内备份原 documents/latest 到 documents/legacy-v1-latest，具有可识别 ID/名称的旧快照原文复制到 experiments；原 latest 保留。迁移失败会中止升级，不删除旧数据；旧文件版本仍在加载时走原有 v1→v2 校验。旧单槽中在升级前已被覆盖的历史实验没有可恢复副本，除非用户另有 JSON 备份。列表按游标只收集摘要，不把所有实验的完整 JSON 同时保留在 React 状态。

列表每行提供删除按钮，按 ID 定位，二次确认展示名称、ID 和不可撤销说明，默认聚焦“取消删除”；Escape 退回列表，取消不改数据库。删除本地记录不修改当前打开场景或历史，删除当前文档的保存时清除已保存指纹，再次保存可重新加入列表。

删除在同一 readwrite 事务中移除 experiments 记录；若 documents/latest 对应目标，按保存时间选剩余记录替换，或没有剩余时删除 latest。同时移除与目标 ID 对应的 legacy-v1-latest 备份，避免留下被删除的保存副本；不删除其他实验或备份。任意步骤失败整事务回滚，UI 保持原列表和已保存状态并提示错误。删除成功的记录不会因刷新或旧版升级恢复而重新出现。详见[删除验收](../acceptance/M1-DELETE-SAVE.md)。

异步保存使用点击时的场景快照；如果等待期间继续编辑，保存完成后界面仍标记有未保存更改。已保存状态比较完整文档指纹，视口变更也计为待保存；导出不冒充本地保存。打开/访问库有 10 秒超时，blocked、权限、配额、损坏和事务失败提供诊断，释放连接；失败后仍可编辑与 JSON 导出。

本地数据只属于同一浏览器配置与同一源（协议/主机/端口）；localhost 与 127.0.0.1、开发 5173 与预览 4173 的保存互不共享。换浏览器、设备或地址请用 JSON 导出/导入。清除站点数据会删除本地保存。

界面页脚、导入/加载预览和恢复提示均说明：首版重载从实验初态重新运行，不保证任意动态时刻续跑。当前已有电学求解和自动更新，任务 07 的历史测量快照独立保留；不续跑旧 Worker 或把当前计算值写回旧记录。
