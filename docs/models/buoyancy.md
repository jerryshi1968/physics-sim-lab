# 浮力与排液测量（J-MECH-03）

模型版本 `mechanical.buoyancy.static.v1`。竖直悬挂、缓慢浸入的静态实验，使用薄且无质量的绳，忽略空气浮力、黏滞阻力、挂壁液滴和表面张力。浮体的自由运动超出本模型，松绳时不输出正常悬挂读数。

## 几何与力

圆柱体截面积为 S、高为 H，体积 V=SH，密度由质量与体积决定。杯内底部基线为杯位置上方 0.01 m，盛液烧杯等效面积 A=0.004 m²、液柱高 0.15 m，杯沿在杯位置上方 0.16 m。物体下端高度为 z，液面为 h，浸没体积为 `S × clamp(h−z,0,H)`。从液体体积守恒求解 `A(h−base)=V液+V浸`，同步液面上升与物体浸没部分。杯壁碰撞由杯和物体的水平半径判断，物体下端到达内底部即为触底。

物重 G=mg，浮力 F浮=ρ液gV浸，悬挂张力 T=G−F浮。测力计指针连续反映 T，读数按所选分度值取整。未挂接、触底、碰壁、T≤0 或超量程时显示对应状态，禁用正常力读数。支架上的测力计可上下拖动，附属圆柱体随动，柱身每 1 cm 一条刻线，可自行读浸入高度。

## 溢流和准备

溢水杯的等效面积同为 0.004 m²，溢水口在内底部以上 0.12 m，满液体积 480 mL。物体浸入后，超过溢水口的体积从杯内扣除。有效接液杯位于出水口下方时，液体进入接液杯，带入相同液体密度。接液杯容量 250 mL，等效面积 0.0025 m²，杯沿在杯位置上方 0.11 m；出水口须高于其杯沿。缺杯、位置不合、异种液体混合或杯满的部分记为漏接。

体积变化按一次历史命令同时更新容器、排液量和接液杯，撤销或取消拖动会一起恢复。拖动预览累计处理经过的浸入位置，已经排出的液体不会因随后提起物体而回流。加至溢水口会建立新的准备批次并清零本批累计排液与漏接，但保留接液杯内已有液体。学生应明确清空杯或称取空杯。液体从接液杯转到量筒为一次完整转移，要求量筒为空且容量足够。

## 记录和来源

空气中示数、液中示数、浸入高度、空杯质量、接液后质量、排液体积各自保存快照。手工读数不由模型代填。界面和 CSV 使用 N、g、cm、mL，JSON 和内部计算统一 SI。

称重法浮力由同组同物体、相同质量尺寸的空气和液中示数相减。可再选择同一液中摆放状态的浸入高度，用圆柱截面积计算体积，绘制浮力—排液体积图。液体密度是已知配置条件，可绘制浮力—液体密度图。

排液重力使用空杯和接液后总质量之差乘 g，独立于浮力公式。比较时要求来源于同一接液杯、同一准备批次、补液至溢水口且无漏接的排液。派生快照引用两到三个较早快照，保持来源追溯；删除或修订源行不静默覆盖已生成的结果。量筒比较要求同一批排液已经全部转入空量筒。保存加载保留已经发生的排液及实验记录。

## 独立预期

默认圆柱质量 0.100 kg、面积 0.001 m²、高 0.05 m，体积 50 mL，g=10 N/kg。

| 状态 | 浮力 | 测力计张力 |
| --- | --- | --- |
| 空气中 | 0 N | 1.00 N |
| 水中浸没 25 mL | 0.25 N | 0.75 N |
| 水中完全浸没 50 mL | 0.50 N | 0.50 N |
| 密度 1200 kg/m³ 的液体中完全浸没 | 0.60 N | 0.40 N |

400 mL 水的盛液烧杯中，25 mL 排水后液面高为 `0.01+0.000425/0.004=0.11625 m`，圆柱体下端应在 0.09125 m，测力计挂接高度为 0.39125 m。完全浸没后继续降低但未触底，浮力保持 0.50 N。

盛液烧杯装满 600 mL 时，液面在 0.16 m；圆柱体下端在 0.155 m 时，浸入 0.005 m，排出 5 mL，杯内剩余 595 mL，测力计张力为 0.95 N。

溢水杯满液 480 mL，完全浸没后保留 430 mL，接液杯收集 50 mL。提起物体后这两份液量保留，重新浸至原位不会再多排液。空杯 30 g，接液后 80 g，排液重力 `(0.080−0.030)×10=0.50 N`。记录估读 1.00 N 与 0.55 N 时，学生计算结果为 0.45 N，参考真值仍为 0.50 N。
