# 水平一维摩擦实验：Matter.js 受控适配

任务 11 / M5，需求为 [J-MECH-01](../requirements/J-MECH-01.md)。自研模型位于 [model.ts](../../src/core/mechanical/friction/model.ts)，约束/材料适配在 [frictionScene.ts](../../src/equipment/mechanical/frictionScene.ts)，Matter.js 表示在 [matterAdapter.ts](../../src/core/mechanical/friction/matterAdapter.ts)。M0 [代数小样](friction.md)保持原文和独立测试。

## 唯一运动来源与单位

教学模型独占时间、x、v、静/滑状态、牵引力、摩擦力和读数。输入全部 SI：m/kg、g/(m/s²)、x/m、v/(m/s)、t/s、面积/m²、力/N；μs、μk 无量纲，μs≥μk≥0。坐标右正、上正；限一只木块、水平面、水平拉力，木块材料为木质，加载砝码集中在块顶，忽略测力计/绳质量、转动、变形、摆动和复杂碰撞。

Matter.js 0.20.0 只创建水平接触面和木块的形状及受限接触查询。两者均为静态表示，gravity=0，friction/frictionStatic/frictionAir=0，不向引擎施力或使用引擎积分结果求测量。Matter.js 在创建静态体时会设置自己的默认摩擦值，故创建后再次显式清零。

自研轨迹逐步通过 `Body.setPosition` 同步，显示速度用 `Body.setVelocity` 映射。固定 1000 引擎长度单位/m；引擎 y 向下，速度基准为 1/60 s，转换为 `v×1000/60`。`Engine.update` 后检查表示位置/速度与 SI 源一致、无额外力，并用 `Query.collides` 验证接触；失败停止且不能采样。接触表示带总计 0.002 引擎长度单位（2 μm）的形状容差，不改变 N 或教学轨迹。此映射与画布缩放无关，保存的参数和测量始终是 SI。官方行为依据：[Body API](https://brm.io/matter-js/docs/classes/Body.html)、[Engine API](https://brm.io/matter-js/docs/classes/Engine.html)，未复制上游物理实现。

## 自研干摩擦与事件积分

仅在水平无竖直加速度时 `N=(m块+Σm已加载砝码)g`；未加载器材不参与受力。v=0 时按需求匹配 `Ff=−Fpull`，只要 `|Fpull|≤μsN` 就保持静止；超阈值后 `Ff=−sign(Fpull)μkN`。v≠0 时摩擦反向于当前速度，拉力反向并不立即翻转摩擦。

每个常力片段用 `x+=vΔt+½aΔt²`、`v+=aΔt`。若 `a·v<0` 且本步经过零速，先精确积分到 `tstop=−v/a`，再重新判定静摩擦能否维持静止；不能维持时才在剩余时间按新方向滑动。可控拉力不以任意速度 epsilon 抹掉微小速度，1e−12 m/s 的停止也走同一事件路径。速度控制器仅对已经接近目标的浮点尾差（≤1e−12 m/s）落到精确目标，避免零目标下持续微小漂移。

可控拉力模式直接设置有符号 F。牵引器为可选：未连接牵引器时由测力计控制力的大小与左右方向；连接后可切换匀速牵引/可控力。正负号表示改变水平牵引方向，显示组件随该方向摆在木块一侧，不从拖动速度推算牛顿值。

匀速控制器不是瞬间匀速：通常以 `a=clamp((v目标−v)/Δt,−0.4,+0.4) m/s²` 计算所需牵引力 `Fpull=ma+sign(v)μkN`。静止启动时需突破静摩擦，瞬时选择至少 `μsN+1e−8 N`，实际加速度仍按牛顿定律求；启动峰值可能大于后续 ramp 所需力。零目标且已经静止则牵引为 0。仪表示数来自实际牵引力，不来自目标速度、鼠标速度或 Matter.js 约束伸长。

## 稳态、边界与采样

滑动净力容差沿用小样 `1e−9 N + 1e−9×max(|Fpull|,μkN)`，速度须大于 1e−6 m/s，并连续满足 0.3 s 才允许将牵引力作为滑动摩擦力。改牵引模式/控制值重开稳态窗口。停住、启动、加速与反向阶段保留实际状态，不自动当作匀速。

场景固定步长为 1/120 s，可验证范围 0.001～0.05 s；浏览器固定步推进，每帧累计至多 0.1 s，以仿真时钟为准，慢帧不靠变大物理步长追赶。300 s、速度上限 100 m/s、块到达面边缘、材料配置不一致、斜拉/倾斜/悬空、无效装配或适配失配都停止/拒绝正常输出；没有实现的随机误差配置明确拒绝。修改质量、材料、几何或装配重置运动；控制力/目标速度运行中可调，保留当时 x/v。独立尺仍可手动摆放。

手工/仪表记录共用现有 SceneDocument、历史、表格和 CSV 通道。每组记录压力、牵引力、滑动摩擦力，保存初态器材快照，以及 t/x/v、质量、面积、材料/μ、模式和稳态状态。初态 t=0 不能采样。未稳态时牵引力数字带 `non-steady`，滑动摩擦力记录为模型外、值为空，不能误当作 F–N 图点；超量程也不作正常零读数。修正手工抄表不能消除非稳态资格。理论值、仪表示数与原始手工文本分开保存，图线只画有效稳态点。

模型没有改为时间续存：保存/加载只恢复初态与既有记录，重新从 t=0 开始，运行轨迹不写入源设备姿态或撤销栈。砝码拖到木块顶端可加载，拖走可取下；装配为参数引用并作为一次原子历史操作，沿用文档格式 2。

面积为接触面积参数，可理解为改变本侧视图未显示的深度；保持质量和材料相同时，干摩擦近似不随面积改变，不把它当作所有材料/压力条件下的普遍定律。预设材料系数只是明确配置的教学参数，不是声称测得真实木板/布的统一常数；自定义时须保持 μs≥μk。

## 独立基准与检查

| 条件（g=10 N/kg） | 独立手算预期 |
| --- | --- |
| m=0.5 kg、μk=0.2、正向匀速 | N=5 N，Ff=−1 N，Fpull=1 N |
| m=1 kg、μk=0.2 | N=10 N，Ff=−2 N，Fpull=2 N |
| m=0.5 kg、μk=0.4 | N=5 N，Ff=−2 N，Fpull=2 N |
| m=0.5 kg、μs=0.5、μk=0.2、初静止 | F=2.5 N 保持静止；F=2.6 N 时 a=(2.6−1)/0.5=3.2 m/s²，1 s 后 v=3.2 m/s、x−x0=1.6 m |
| 相同 m/μ，v0=0.2 m/s、F=0 | a=−2 m/s²，0.1 s 停止，位移 0.01 m，此后不反向抖动 |
| m=0.5 kg、μk=0.2，v0=0.2、F=−3、Δt=0.05 s | 先向右制动再向左，最终 v=−0.1 m/s，位移 0.00125 m |

静态/稳态力误差门槛 1e−6 N；动态稳定窗口的牵引读数相对误差要求 ≤1%，当前标准分度下上述 1/2 N 基准误差为 0。运动/适配测试通常绝对容差 1e−8（SI）；Matter 位置一致性 1e−10 m、速度一致性 1e−8 m/s。dt=1/60、1/120、1/240 s 对比启动轨迹收敛、最终速度与稳态力，同时对可控恒力用解析 x/v 独立核对。
