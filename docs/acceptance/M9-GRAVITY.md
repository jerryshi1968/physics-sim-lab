## 首次失败与修正

集成脚本曾因原记录区域的条件形式定位错误停止，采用全部变更校验后统一写入，未发生部分覆盖。初次类型检查提示新画布标签未导入 FORCE_METER，补齐后先通过类型、ESLint、构建再运行浏览器。

首批三个新 E2E 用例均被未限定的指针定位影响：器材库图标与实验台都包含同类 SVG。收窄到实际画布后，五次称重与原生触摸通过，未删除测试。新实验补齐实际挂接横臂，读表视图将 5 N 量程标为正立 0～5，同时保留 0.1 N 分度。

删除用例先错误预期“已有记录的测力计可直接删除”，多次失败后核对工作台现有 `EQUIPMENT_HAS_MEASUREMENTS` 保护规则。未为通过用例改变全局规则或丢弃记录；现用例明确断言保护提示、记录保留，另验证没有直接记录引用的支架删除后解除挂接、单次撤销恢复。核心也加入测力计删除被保护的断言。此前失败日志 `gravity-e2e-complete.log`、`gravity-e2e-final.log` 保留。

WebKit 首次复载断言在异步保存/初始加载完成前读取了空场景；脚本改为分别等待“已保存”，并与最后实际保存的视口/文档比较，最终两设备通过。原日志 `artifacts/gravity-webkit.log` 保留；未修改存储逻辑。

已目视复核最终桌面装置、WebKit 手机/平板放大测力计和手机图线；10 份修改的已有源码/测试通过 TypeScript AST 注释审计，原注释保持完整。`git diff --check` 通过，依赖、dist、缓存、测试截图和日志仅为本机忽略证据；本次未提交 GitHub。
