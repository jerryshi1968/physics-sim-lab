# J-MECH-03 浮力实施与复测

日期：2026-11-11。范围为实施计划第 9.2 节“浮力”，保持版本 0.2.0-dev.1。

## 实现范围

- 新增带吊环圆柱体、溢水杯，复用支架、弹簧测力计、烧杯、量筒、托盘天平和砝码盒。
- 提供影响因素、阿基米德原理、空白搭建三个起点。测力计可沿支架上下拖动，圆柱体随动；也可即时修改挂接高度、质量、尺寸和液体密度。
- 液面按体积守恒求解，测力计按重力减浮力驱动。触底、碰壁、松绳和超量程不提供正常悬挂读数。
- 溢出的水进入对准的接液杯，漏接单独计量；提起物体不回流。拖动预览、取消、撤销、重做和保存加载一起保持水量。
- 空气示数、液中示数、浸入高度、空杯质量、接液后质量、量筒体积各自手工保存，按来源计算并绘图、导出 CSV/JSON。

## 检查中发现的问题

1. 排液预览已计算但右侧提示仍显示提交前状态，已改为使用同一预览场景；往返拖动保留排液、取消整体恢复的断言通过。
2. 共享烧杯的默认用途在浮力编辑器预校验前没有明确，400 mL 输入被旧密度实验的容量约束拒绝；已在浮力编辑和补液操作中明确用途，保留密度实验原有容量约束。
3. 满杯时的杯沿几何与液柱基线有 1 cm 差异，已统一并增加 600 mL 满杯、5 mL 浸入排水的独立基准。
4. Chromium CDP 原生取消输入后可抑制后续兼容点击，在最小 HTML 页面也能复现。测试分别核对原生取消、原生提交、按钮轻点撤销，以及原生拖动后的键盘撤销；保留全部水量、力值和历史断言，不以软件模拟代替实机结论。
5. 摩擦测试期望撤力后静止，整套及组合运行中实际到达接触面边缘。最后单独执行通过，但尚未定位时序差异的根因。本次不改动该实验或删除其失败断言，作为后续回归稳定性事项保留。

## 限制和下一步

当前使用缓慢竖直浸入的静态模型，忽略空气浮力、表面张力、黏滞阻力和器材弹性；自由漂浮运动不在本模型范围。教材版次、章节、页码、审阅人和日期继续保持待教师核验。下一步复核摩擦计时差异，并在实体设备和课堂中验证挂接、读尺、接液与称量流程；未开始下一扩展实验。
