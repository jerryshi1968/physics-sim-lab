## 完成范围

复用轨道、小球、木块、接触面和两把独立尺。钢球从弧形斜槽由静止滚下，在水平面撞击并继续推动木块，直至摩擦停止。支持质量、高度及木块/接触面参数即时修改、直接鼠标/原生触摸拖动、键盘、取消预览、单次撤销、释放/暂停/继续/单步/倍速、重置、整套装置和碰撞放大视图、毫米读尺与横向滚动。

分别完成同质量不同高度、同高度不同质量对照。学生手填质量、高度和木块同一边缘的起止读数，位移按读数相减；条件表检查真实冻结装置中的受控量，不自动填写动能结论。原始记录修订/删除、来源快照、CSV/SI JSON、保存加载保持独立证据，重载从初态准备，不恢复正在运行的动画。

## 首次失败与修正

首次类型检查指出小球可选质量 schema 输出可能包含 undefined，沿用现有器材的类型收窄过滤，缺省字段不写回旧文档；目录新增 family 后补全预览来源类型。首次核心发现独立尺的既有上限是 1.2 m，初态改用合法的 1.2 m 尺，没有扩大旧器材范围。完整核心首次在沙箱内遇到旧静态服务器符号链接测试的 EPERM，原日志 `artifacts/kinetic-core-all.log` 保留，获准后完整运行通过，没有删除该用例。

首轮 Edge 目录数量断言仍为 17，更新为实际 18；播放速度下拉补明确 aria-label，避免选项文本影响准确名称。拖动过程中工作台本来拒绝导出，测试改为检查可见预览并在取消后导出核对原文，保留取消和原始装置不变的断言。日志 `artifacts/kinetic-e2e-first.log` 保留。

控制条件检查最初把整套参数再次塞入快照备注，超过既有 500 字符上限，导致新记录用例真实失败。改为从已有来源快照计算控制条件，不扩大 schema、不丢来源。后续全部 16 条记录、四份快照、修订及保存断言通过。失败批次仍记录在 `artifacts/kinetic-e2e-verified.log` 和对话工具输出。

截图复核发现新增 polyline 不在既有 CSS 的非缩放描边选择器内，斜槽被画得过粗；仅为两个新 polyline 显式设置非缩放描边。参数面板复用现有网格标签样式，随后调整窄屏初始比例、放大视图中心与标签位置，不改全局 SVG 或样式规则。首次 WebKit 缓存缺失，下载到项目忽略的本地缓存后再验证，未改变 package/lock 或生产环境。

## 模型与限制

均质实心球纯滚动，斜槽平滑相切，忽略滚阻；完全非弹性接触近似，球块碰后共同减速。位移用于相同装置的定性比较，有碰撞能量损失，不能直接当作碰前钢球动能读数。没有真实反弹、声音、弹性变形、打滑或任意碰撞；球图示半径固定。有限接触面先到边界就停止，保留边界原因，不产生正常停止读数。详见[模型与手算基准](../models/kinetic-energy.md)。
