# M9 / J-OPT-04 光折射时的特点验收

日期：2026-11-17。Windows / Node 24.14.1 / Edge / Playwright，另有 WebKit iPhone 15、iPad (gen 7) landscape 模拟。不是实体设备或课堂验收。

## 实现范围

初中光学新增“探究光折射时的特点”，总目录 42 项（初中 30、高中 12）。复用通用光学空白、窄光束光源、两把半圆量角器、法线和可选独立尺，仅新增透明水槽。新器材与现有工作台共用选择、拖动、即时属性、撤销、保存和导入校验。不兼容器材禁用；兼容集合检查数量，两把量角器也能确定折射模型，不弹切换实验窗口。

支持空气→水、水→空气、不同入射方向、垂直入射和沿实际折射光反向入射。传播箭头、有限水槽边界、独立校准、正立的双侧刻度、可滚动/缩放的量角窗口完成。无传播折射光时折射角为 null，不补 0°；理论默认隐藏。

手工角度和偏折观察成组保存，角度内部 rad、界面和 CSV 为 °；不同传播方向独立成系列。来源、交点、器材与观察冻结，支持修订、删除、图线、CSV/JSON、保存加载。已存在的熔化专有 11 份文件与本轮开始时逐字节一致。

## 发现与复测

首次新折射/反射/分类批次 **11/12**。新用例把角度修订框当成普通量的“修订抄表值”定位，实际标签为“修订抄表值（°）”，因此等待超时；更正定位，保留用例并在 25 项及最终 14 项中通过。

截图发现放大视图中新增下半法线未继承非缩放描边，造成水下大片绿色；将其纳入已有实物图描边规则。再修正上下半圆 90°端点数字重叠、手机水槽标签靠近裁切边界。增加放大后四个 90°标签不相交的断言，最终专项和 WebKit 复验通过。

跨领域唯一透镜失败是器材库断言预期 13 种，实际新增水槽后为 14 种；只更新该数量预期，不改透镜模型，最终透镜五项通过。初轮失败如实保留，没有删除失败用例或修改物理结果迎合测试。

## 限制与后续

二维单一水平空气—水界面，水取 4/3 的教学近似。槽壁与槽底只截断可见光路，不模拟玻璃壁二次折射、光源壳体、散射强度、多重反射、色散或干涉。放大量角窗口保持实际失准，不自动移动工具；手工缺失/失准值不形成有效角度图点。

教材版本/章节/页码、真实水槽材料、实体 iPhone/iPad 与课堂观察仍待教师核验，教材映射 `pending_teacher_review`。继续使用 0.2.0-dev.1，下一步为教师试用与核验，不自动实施高中折射率或其他新实验。
