## 发现与修复

首轮浏览器运行 5/8 通过：属性 select 的嵌套标签导致精确标签定位失败，以及触摸拖动后下一次卡片选择失效。补充稳定 aria-label 后，鼠标/键盘通过。通过短时事件记录确认触摸拖动后浏览器未提供兼容 click，改为 pointerup 处理触摸/笔激活，并去重可能随后出现的 click；调试监听已移除，保留回归断言。

另修复触摸拖动后未产生 click 时的过期抑制状态；新 pointerdown 重置状态。检查发现低倍率下 44 px 端口命中区重叠，已按倍率缩小并补测；默认倍率保持 44 px。恢复原有禁用撤销/重做占位，增加属性区 Escape 和折点键盘路径。类型检查也曾发现新 E2E 元组推断的 undefined 分支，使用明确只读元组修正，未关闭 strict 检查。最终 9/9 全部通过，未删除或跳过失败用例。
