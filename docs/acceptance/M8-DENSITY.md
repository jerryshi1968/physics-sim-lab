# M8：测量固体与液体密度

日期：2026-11-09。工作区 G:/physics-sim-lab，0.2.0-dev.1。按维护者明确回复，同时实现固体和液体密度，分别为 J-MEAS-01 和方法变体 J-MEAS-01-L；未实施第9.2节其他新实验，旧候选包未操作。

## 交付与复现

运行 `npm run dev`，顶部“测量密度实验”选择方法及一套器材/空白搭建，预览后确认。力学目录15→20件，增加托盘天平、量筒、固体、砝码盒、液体烧杯。先游码归零、空载调零；拖物至左盘或用位置下拉，点砝码加减、移动游码，参数即时生效，无额外调平确认。

固体独立记录质量、原水面和完全浸没后的水面；液体独立记录倒前总质量、倒后总质量和倒出体积。烧杯倒液为一次可撤销的守恒操作；不模拟倒液动画。右侧放大刻度和液面、俯/仰视对照，读数不自动填入记录。

选择三个同组、同样品且条件连续的来源，显式计算 m、V、ρ。真实浏览器用53.8 g、50→70 mL得到2.69 g/cm³，模型参考仍为2.7；改源为54 g后，旧结果保持2.69，明确重算才增加2.7。液体110→80 g和30 mL得到1 g/cm³。来源行删除后，结果引用的三个快照继续保留，JSON和CSV可追溯。

未调零、失衡、超量程、未完全浸没、俯仰视、溢出、浮体、不同液体混合或不同来源条件均受保护。左盘不能重叠放两件物品；拖放拒绝保留原位置，清空会把载荷放回桌面。鼠标、软件触摸、键盘、预览取消、一次历史提交、撤销/重做和父器材删除解除关联均已检查。
