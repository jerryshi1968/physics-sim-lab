# 工作台换选与取消操作

日期：2026-11-24。范围：共享工作台交互修复，不增加实验、器材或物理模型。

## 行为

- 导线与器材仍共用一个选择状态；点击另一对象直接换选。Shift 保留原有器材多选规则。
- 点击器材本体、开关或滑片，结束待接线状态并选择该器材；器材下拉框换选遵循相同规则。
- 点击画布空白清除选择和待接线状态。正在从器材库放置器材时，空白点击仍执行放置。
- 点击接线柱仍可逐次选择起终点；线头仍支持点击后接线和直接拖动吸附。拖动线头松手后退出待接线状态，保留该导线选中；无效连接仍显示原校验错误。
- Esc 清除选择、待放置、接线和拖动预览，并退出平移。平移状态由应用统一管理，焦点在画布、工具栏或侧栏时均可退出；属性输入框自身拦截 Esc 回退草稿的原规则保留。
- 平移模式下拖动继续只移动视图；不拖动的点击/轻触可以换选对象，空白点击可以清除选择，平移按钮仍保持启用，便于继续拖动画布。
- 加载、重建或切换实验时重置平移；选择、取消和单纯平移不新增实验修订或测量记录。
