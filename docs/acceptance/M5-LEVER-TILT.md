# 杠杆加载失衡的下沉示意验收

日期：2026-11-04。用户反馈左侧力矩大但杆仍水平，容易误解。本次增加明确的左右下沉示意及挂载随动，不实施任务 11，不改原始受力计算。

## 行为与契约

左 −4 格/0.1 kg、右 +2 格/0.1 kg 时左端明显低于右端；右质量改 0.2 kg 时恢复水平，改 0.3 kg 时右端下沉。显示杆绕原支点转动，已挂接器材随显示挂点移动，器材自身方向保持。

画布有持续的失衡方向提示及原位置虚线，明确为状态示意。计算、受力辅助、力臂、反力、测量/快照和存档仍取原装置，示意角不作为读尺数据或写入真实杆转角。空载调螺母行为保持。模型无效不绘正常倾斜结果，恢复平衡立即取消倾斜。

拖放以当前显示挂点吸附，避免外侧挂点偏离原位置后无法连接；钩码挂钩扩大透明命中区域，防止误抓下面的杆。预览、取消、撤销、保存和刷新均不把示意变成物理参数。详见[模型说明](../models/lever-tilt.md)。
