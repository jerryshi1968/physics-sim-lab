# H-MECH-06 实际验收：纸带平均速度与瞬时速度

日期：2026-11-25。基于此前已提交的完整工作区，新建一个高中力学实验，不改下一实验，不提交或部署。

## 实际功能

入口：高中物理实验 → 力学实验 → 测量纸带的平均速度和瞬时速度。目录现为44项：初中30项保持，高中14项（力学10、电学4）。只复用原打点计时器、独立刻度尺及配套纸带、夹具、电源与工作台；没有新硬件类型、依赖、网络资源或外部图片。

实际画布拖放穿带、机身开关、扣夹/开夹、跟手水平拉带、松手停拉、断电开夹取带、手动摆尺、高倍率厘米/毫米读数保持。新实验只在记录区增加选点和处理数据：选择清晰参考点0，按5或3个原始时间间隔选计数点，可改分组或直接选端点，手填到参考0的位置xA、xB，计算Δx、Δt和平均速度。50/60 Hz按实际频率换算，不硬写0.10/0.06 s。

瞬时速度始终为近似值。目标E须位于区间内部，可围绕同一E对称缩短或扩大区间，显示目标时刻、非对称偏离提示，以及两端各估读±0.5 mm时的速度误差上界示意。该示意不包含方法近似误差，不是统计不确定度；不宣称有限区间平均速度等于任意时刻精确速度，也不宣称区间越短总误差越小。

记录保存两个原始手工位置和冻结来源；Δx、Δt、v及对应时刻从当前读数重算。手工修订、部分删除、缺失/反序/超范围、来源真值与原始输入、撤销/重做、平均/瞬时近似/同E区间比较图、速度汇总CSV、原始CSV和SI JSON、保存重载均有检查。记录表可横向滚动，展开记录区可查看更多列。完整未采样纸带不续存，重载后装置为断电、开夹、未穿带，已存表格与计算结果恢复。
