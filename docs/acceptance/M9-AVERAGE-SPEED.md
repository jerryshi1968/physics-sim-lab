# M9 / J-MECH-04 平均速度验收记录

日期：2026-11-13。环境：Windows、Node 24.14.1、Edge / Playwright，以及 WebKit 的 iPhone 15、iPad (gen 7) landscape 模拟；不等同于真实设备或课堂验收。

## 交付范围

初中力学新增预搭建、空白搭建两个入口。复用原小车、轨道、木块、独立尺和计时器，只增加金属挡片。原高中轨道的滑轮、牵引和计时流程保留；本实验单独按斜面运动模型计算，不把复用器材等同于调用高中实验。

支持同一起点的全程与上半程两次静止释放，撞片精确停表，移片快捷操作及拖动吸附、即时坡度、暂停/继续、单步和慢放。读取沿斜面的同一车头标记，毫米放大尺可横向滚动定位两端。学生保存两次尺读数与时间后计算 s/t；可修订、删除、查看路程—时间散点、导出 CSV/JSON、保存加载。运行位置不覆盖初态。

## 数值及行为证据

g=10 m/s²、sinθ=0.1 时，全程 1 m 理论时间 √2 s，上半程 0.5 m 重新释放为 1 s；释放 0.5 s 位移 0.125 m。碰撞后车头投影与挡片面重合，30/60 Hz 和单大步得到同一时刻、位置。

默认 2° 起点实际停表示数为全程 2.39 s、上半程 1.69 s；学生填 109 cm→9 cm / 109 cm→59 cm 后，表格为 1 m / 0.5 m，速度约 0.418410 / 0.295858 m/s。修改挡片抄表至 19 cm 后，第一组路程为 0.9 m，速度由该组原时间重新计算；保存重载后记录保留、小车归初态、停表 0.00 s。

完整核心最初有一项旧器材清单断言未含新增挡片，更新清单后 442 项通过。独立专项的早期测试还修正了撤销 API 的返回值使用，以及竖直移动斜尺会同时改变尺轴投影的预期（两端读数同改，差值不变）；未为通过断言修改正确的投影模型。

## 证据与限制

本机日志位于忽略提交的 `artifacts/average-speed-*.log`，首次浏览器与相关回归结果分别存于 `artifacts/average-speed-first-e2e-results.json`、`artifacts/average-speed-first-regression-results.json`。设备模拟截图/结果位于 `artifacts/average-speed-webkit-20261113/`；Playwright 输出位于本次 `test-results/`。这些是本地实际生成证据，不代表云端 CI。

- 采用无阻力斜面质点近似；忽略车轮转动惯量、滚阻、碰撞反弹和人工按表反应误差。木块用于装置外观，不从刚体接触计算坡度。
- 当前支持右高左低的 1°～8° 小坡度。更换关键初态要求重新释放；尺、停表位置可独立摆放读数，不恢复旧运行时刻。
- 沿用已有来源器材保护：尺/停表已有测量记录时不能直接删除来源，须先处理对应记录。非来源装置删除后保留历史快照。
- 入口 JS 约 1030 kB，保留既有大包警告；未顺带拆包或运行全目录 E2E。未新增第三方依赖或复制教材原图。
- 教材、实体 iPhone/iPad、真实器材及课堂测量效果保持待核验。教材映射 `pending_teacher_review`，不编造出版社/版次/页码的审阅通过结论。
