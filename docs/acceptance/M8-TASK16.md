# 任务 16：J-OPT-01 光的反射定律

日期：2026-11-05。工作区：G:/physics-sim-lab，0.2.0-dev.1 / M8。按维护者选择，仅实现第 9.2 节的反射定律，不扩展欧姆定律、折射或其他实验。原首版待核验项继续保留。

## 交付与复现

`npm run dev` 后点击顶部“光的反射定律实验”，选择一套器材/反射空白搭建，预览确认。光学页签从原 5 件增至 10 件，新增镜、光源、可折纸板、量角器、法线；可直接在未指定实验的空工作台放置。透镜与反射子实验混放改为可取消的另建入口，导入混合场景诊断明确。

默认镜水平、源从左侧斜入射，量角器零线沿法线。独立位置/方向即时生效，显式按钮分别校准指定器材；光源圆周控件明确移动并瞄准中心。展开读角至少三组，再折起右板、展开复现。折角支持鼠标/软件触摸、键盘、取消和一次历史；预览禁记。

主画布只显示落在纸板上的连续光迹，斜视图显示真实空间折板。局部三维反射和射线—有限承接面裁剪决定光迹，不是将折角直接作为显示开关；折板后自由空间 r 保持。正入射沿轴、右侧入射落固定左板均有反例提示，不能误称为共面证据。理论默认关闭，不代填学生估读。

手工 ° 输入转 SI rad，原始度数字符串、折角、观察、器材和配置随共享快照保留。摘要用 °；通用表修订、CSV 和图线用 rad 并明确提示。三行一次采样，折起时反射角 out-of-model/null、观察仍可保存；空白不填零。图线来自学生有效记录，故测试中的 30/31、45/46、60/61 度估读保留误差，并未改成等角答案。保存/刷新/严格 JSON 重导入、CSV、撤销和旧快照沿原数据模块。

模型、独立手算和边界见[模型](../models/reflection-experiment.md)，教材字段见[需求卡](../requirements/J-OPT-01.md)，设计取舍见[决策 0019](../decisions/0019-m8-reflection-folding-paper.md)。

## 真实失败和修复

首轮 4 项均失败：集成替换同时在两个导线循环之前插入光迹，造成重复渲染。检查实际 DOM 后移除第二处，保留计数断言。目视还发现 polygon 未继承现有 rect/path 的 non-scaling-stroke，边框被放大成大色块；为新折叶单独指定该属性。[首轮 JSON](m8-task16-first-e2e.json)和[日志](m8-task16-first-e2e.txt)保留。

第二轮 3 通过/1 失败：测试将原凸透镜对话框标题写成按钮名称，实际标题是“探究凸透镜成像规律”；更正选择器，原取消/不改装置检查保留。见[第二轮 JSON](m8-task16-second-e2e.json)和[日志](m8-task16-second-e2e.txt)。随后全量 90 项通过。截图发现纸板名在小画布贴顶并靠近法线名，增加顶边留白并移至左叶上方；增加实际名称矩形无交叠检查，最后专项通过。随后复查补充了光源方位角逐字输入草稿（合法即应用，无效/未完成保留，失焦/Esc 恢复）和小半径量角器比例。该轮 3 通过/1 失败的原因是空白装置镜面实际在视口中心 y=0.27 m，而测试把光源圆周方位误当作 120°；明确把镜面摆到 y=0 后复验，并保留原断言与[该次 JSON](m8-task16-draft-first-edge.json)/[日志](m8-task16-draft-first-edge.txt)。加入原透镜拒绝混入的独立边界后全量单元/模型为 316/316；最终两浏览器光学专项各 10/10。新核心最初随机误差用例只开 enabled 而 distribution 仍 none，触发通用文档错误；补成合法 uniform 配置后验证领域拒绝，不降低断言。开发中的 TS 对自定义 Window 计数字段的可选性检查也已修复，最终三份类型检查通过。
