# M5 / 任务 11 实际验收

日期：2026-11-04。范围：J-MECH-01 水平一维滑动摩擦，Matter.js + 自研模型。工程实现及自动检查完成；教材、实体设备、课堂与正式发行尚未验收，未实施任务 12。

## 交付

- 力学库新增木块、接触面、牵引器和砝码，复用测力计与独立尺；正式“滑动摩擦实验”入口含器材起点/空白搭建与取消/替换预览。
- 接触面/测力计/牵引器在装配区连接，砝码支持实际鼠标拖到块顶加载、拖离取下、取消及单次撤销；牵引器可不安装，直接控制水平拉力。
- 自研静/滑摩擦、常加速度片段与过零事件处理；匀速辅助有实际启动过程，支持可控力、反向、开始/暂停/单步/重置及明确初态待测状态。控制变化可连续，条件变化重置；不从拖速换算力。
- Matter.js 静态表示与接触查询同步自研轨迹，逐步核验单位/位置/速度；禁用其重力、摩擦与独立运动，不重复施力/积分。
- 测量保留稳态/非稳态、超量程与模型外资格；压力、材料、面积对照与 F–N 图，手工/仪表记录、CSV/JSON、保存/加载均复用原通道。初态与运行态分离，重载从 t=0 重跑。
- 新增原子器材批量配置及仪表非稳态记录资格；不改旧电学/光学/杠杆物理方程。所有既有注释保留，未对未变逻辑作格式化。

详细公式、范围、独立预期值、数值容差和 API 依据见[模型](../models/friction-experiment.md)，计算归属见[决策 0014](../decisions/0014-m5-friction-matter-adapter.md)。

## 真实失败与修复

- 原单元首轮仅器材清单断言失败：机械类型从 5 增为 9，更新预期并保留旧断言/用例。[首轮](m5-task11-tests-first.tap)。旧浏览器清单数量也同步 5→9。
- 新核心首轮 12/13：Matter.js 创建静态体后自设 friction=1，测试要求明确为 0。创建后通过其 API 清零摩擦/空气阻力，13/13 通过；随后补充目标零速与可选牵引器，共新增 15 项。[首轮](m5-task11-friction-first.tap)。
- 浏览器首轮 2/4：空白摩擦实验没有被机械领域识别，导致器材库仍是电学；补齐空白领域识别。另一个为新测试在隐藏记录页找 CSV 按钮，调整为切回记录页后导出。修复后 4/4，通过后加入可选牵引器并执行全量。[首轮](m5-task11-e2e-first.txt)、[专项](m5-task11-e2e-targeted.txt)。
- 全量 71 项虽通过，目视发现新器材文字继承画布描边造成巨大遮挡；显式禁止新图形文字继承描边，并增加实际 CSS 断言。首轮标签间距检查在窄屏失败，按文字真实边界加大分行间距，不放宽“不重叠”的断言。[标签检查首轮](m5-task11-e2e-label-first.txt)、[失败截图](m5-task11-label-failure.png)。最终截图和专项以最后生成文件为准。
