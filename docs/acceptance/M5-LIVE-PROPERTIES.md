# M5 用户修订：全器材即时属性与选中反馈

日期：2026-11-05。范围：修复砝码、牵引器、木板/接触面与木块的选中反馈，将所有电学、光学、力学器材属性改为即时编辑；未实施任务 12。

## 实现与行为

- 原选中框位于实物后方并与实物边缘重叠，填色会遮住边框。现在在全部实物、导线和端子前景绘制独立虚线框，固定 7 CSS px 边距、2 px 线宽，随姿态与缩放定位；单选和 Shift 多选均适用。框不接受指针事件，不阻挡接线、拖动或操作器材。
- 统一即时属性编辑器处理位置、可用转角、所有注册数值与布尔参数。合法输入、键盘/原生上下箭头和复选框立即提交，移除“应用属性”；杠杆/钩码及摩擦装配下拉设置也立即提交，无额外应用步骤。
- 输入节点不因 revision 重建，保留焦点及编辑时的滚动位置。空白、未输完、非有限值或不满足参数组合约束的草稿显示无效提示，保持最后有效参数，失焦或 Esc 恢复；上下量程/分度值等仍须满足原组合约束，可先增大量程上限。摩擦系数手动修改显式切换为自定义材料。
- 继续使用原命令历史、文档校验与保存加载，每次有效参数变化为一次历史操作，相同值不新增历史。输入框保留原生文本撤销，其恢复的合法值也即时应用；工具栏/画布仍撤销场景命令。拖拽仍预览、松手一次提交，测量记录仍由用户主动采集，不把器材参数编辑当作学生测量。
- 选择摩擦器材的其他装配引用时，不再重复覆盖已连接测力计的方向；新连接测力计时按原水平装配规则初始化方向。保留单挂点占用、串接、防循环及原模型无效状态保护。

实现入口：[共享属性界面](../../src/app/workbench/LiveProperties.tsx)、[草稿/候选校验](../../src/core/workbench/properties.ts)、[工作台画布](../../src/app/workbench/SceneBoard.tsx)。操作约定见[工作台说明](../models/workbench.md)。

## 真实失败与处理

- 新单元用例首轮的量程组合测试选用了不满足原表盘分格上限的 5/10 A 配置，断言失败。改用满足原分格约束的 0.4/0.5 A 候选，与单独降低大量程造成无效的状态对照；原校验规则未放宽。[首轮](m5-live-properties-tests-first.tap)。
- 初次 lint 指出返回 JSX 的辅助函数使 React ref 检查认为渲染路径可能访问 ref；改为字段描述数组直接渲染，将滚动锚点访问保留在事件/布局 effect 中，未禁用规则。
- 首轮全量 70/75：三项旧测试仍等待提交后全局报错；更新为校验行内无效状态，同时保留原数据不变/重选恢复的断言。一项旧文本撤销测试仍预期输入不改变 revision；现在核验 9 V 立即写入、原生撤销恢复 3 V 并递增 revision，器材结构保持。另一项挂点拒绝测试因下拉选择现在立即挂接到 0 号点，使抓取点落到旧小画布上边界之外；将该实际拖放测试设为 1920×1080，保留占用提示和源文档不变断言。五项复核全部通过，再运行最终 75 项全量，无删除失败用例。[首轮](m5-live-properties-e2e-first.txt)、[首轮 JSON](m5-live-properties-e2e-first.json)、[复核](m5-live-properties-e2e-recheck.txt)。
