# M1 / 任务 03 用户修订验收

日期：2026-11-03。结果：已按用户补充要求完成实物风格器材与独立导线交互。

## 交付与操作

器材库为电池盒、电阻、开关、导线；电池符号为一长一短。实验区使用原创、可缩放的实物风格 SVG 插图，不是元件符号或外部照片。接线柱仍与模型端口对齐，刀开关姿态随 closed 参数改变。

拖入导线后可直接移动整根线，拖动线头到接线柱完成连接；选中后可拖动弯曲点，也能拖动已接线身改变形状。曲线准确经过弯曲点，手柄绘制在器材上方，避免被器材遮挡。属性区提供选择线头、拔开、添加/清除弯曲点与键盘替代路径。多根线可共用接线柱，不再要求显式结点。

自由线头是明确开口，吸附并提交后才变为端口引用；未接线头不参与电气结点合并。模型版本更新为 schemaVersion=2，不伪造有效导通、电流或测量。格式与后续迁移要求见[决策记录](../decisions/0005-m1-physical-apparatus-and-loose-wires.md)。
