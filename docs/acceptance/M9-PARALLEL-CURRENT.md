## 首次失败与修正

首轮专项 36/37：测试将灯泡 a→b 内部电流预期为正，而教师实际接法从 b→a 流过灯泡；核对原求解器分支后将灯泡电压、电流的独立预期明确改为负值，保留电流表正向读数及 KCL 断言，未改变教师接线或物理模型。随后专项 37/37 和完整 564/564。

初次相关 ESLint 发现旧引导验证函数在目录合并后不再调用，现用于旧六器材桌面兼容用例。首轮 Edge 26/27：旧触屏引导用例在调用同一辅助函数后，嵌套步骤保持展开，再次轻触将其关闭，导致找不到表格；将辅助验证留在独立桌面旧存档用例，触屏用例恢复自己的初始状态，六条旧灯泡回归最终全部通过。没有强制点击、删除断言或放宽物理结果。
