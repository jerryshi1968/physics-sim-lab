## 交付

新增“高中物理实验 → 力学实验 → 探究小车速度随时间变化的规律”。全部复用已有小车、带滑轮轨道、配重、槽码、打点计时器、纸带和独立尺；没有增加器材类型、依赖或外部素材。小车运动仍使用既有系统质量与悬挂重力模型，计时器采用原画布开关和翻折固定夹。

学生断电开夹拖纸带穿入、拖右端连接车尾、扣夹通电、点击车身释放；小车自动牵引纸带，释放时转全景。停止后断电开夹取带，移到尺旁并放大，毫米细格仍为前景。安装区可单独放大，短窗口初始全景避开工具栏。禁止通电或闭夹穿取；提前断电停止打点但不令小车凭空停止。

手工选时间零点和计数点，E前后对称取端点读RA、RB；实际频率决定Δt，允许t=0有非零速度。只按手工读数生成速度表和散点图，三条纸带分别成组；可选自由截距线性拟合，不自动填写规律。原始读数修订后结果重算，空白、反序或越界为缺失；来源冻结、撤销/重做、速度CSV、原始CSV、SI JSON和保存重载已接入。完整纸带与未保存表单不续存。

## 发现与修正

1. 初轮核心4项失败：默认g继承10 m/s²，独立预期误用9.81；另一项对二进制浮点CSV做字面匹配。按真实配置修正手算基准和CSV断言，之后全量632/632。未改变原物理引擎或舍入原始数据迎合测试。
2. 初轮浏览器2/4：桌面测试写错“悬挂总质量”控件名称；短窗口初始视口使计时器被工具栏遮挡。已修正名称及全景高度/中心，增加释放后自动全景；第二轮4/4。
3. 新增联锁用例先在同一位置做零位移拖动，纸带此前已移到通道，未触发再次拖放；改用实际支持的键盘Enter穿带。随后发现未连接车尾的纸带提示文字挡住开关，修正为不接收指针事件，仅对本项生效。测试保留并复验。
4. 最后类型检查发现新增测试对可空DOM属性缺少类型断言，已补充；没有放宽产品校验。
