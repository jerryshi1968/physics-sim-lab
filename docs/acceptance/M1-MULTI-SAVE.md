# M1 / 多实验保存修复

后续已增加实验删除及确认、事务回滚和刷新防恢复，见[删除补充验收](M1-DELETE-SAVE.md)。本文其余内容为多实验保存初版记录。

日期：2026-11-03。用户场景：先保存串联实验，新建并保存并联实验，再加载时找不到串联。原因：任务 04 初版仅保留 documents/latest 单槽。本次改为按 documentId 分别保存；新建使用新 ID，改名和再保存更新同一 ID，同名不同 ID 仍可并存。

“加载”展示实验名称、保存时间和 ID，选择后校验、预览并确认；列表关闭/预览取消不改当前工作。刷新仍恢复最近一次保存的实验。IndexedDB 数据库升为 2，新 experiments 仓库存放各实验；旧 latest 剩余快照原文备份并复制为列表项。数据库版本和场景 JSON 版本是独立概念，JSON 仍支持格式 1/2。

保存实验记录与最近保存快照使用同一事务；失败时一起回滚。升级前已被单槽覆盖的记录并不存在于旧数据中，本次修复无法凭空恢复；已有 JSON 备份可导入。详细规则见[当前持久化契约](../models/history-and-persistence.md)。

## 实际验证

- 类型检查（build 内三份配置）、lint、生产构建退出码 0；JS 373.79 kB / gzip 114.58 kB。无新增依赖，纯核心、场景 JSON 格式与现有代码注释保持；本次未重跑之前 111 项纯核心/物理单元测试。
- 完整 Edge / msedge 浏览器回归 21/21 通过，29.5 秒，0 失败/跳过/重试；原 18 项保留，新增 3 项，见[输出](m1-multi-save-e2e.txt)与[JSON](m1-multi-save-e2e.json)。
- 两份实验通过界面新建、改名、放置/连线并保存，刷新恢复并联，再从列表加载串联；导出文件逐字段对比原场景。改名串联再保存后仍只有两份，并联内容不变；列表关闭/预览取消不改变当前工作。
- 两份同名“未命名实验”按 ID 分开保存和选择，不用名称作覆盖键。
- 在独立测试浏览器先建立真实 IndexedDB v1/latest，再刷新升级 v2，旧实验自动恢复并进入列表，新增保存不覆盖旧实验；检查 legacy-v1-latest 备份与原 JSON 完全一致。
- 原配额失败测试改为先写实验记录、在写 documents/latest 时抛 QuotaExceededError，验证整个事务回滚，旧保存可刷新恢复；存储拒绝、损坏记录、JSON 导入、撤销、鼠标/触摸与各视口回归继续通过。
- [390 px 实验列表截图](m1-saved-experiments.png)已目视核对，无横向溢出。测试临时服务已退出，没有修改用户其他开发服务或用户真实浏览器的数据。

## 使用与限制

刷新开发页面后即可使用：各实验分别“保存”，再点“加载”从列表选择，确认替换当前工作。当前没有删除、另存副本、搜索或跨标签同步；导入相同 ID 的文件视为同一实验。数据仍属于当前浏览器配置/地址源，清理站点数据会删除它；跨设备使用 JSON 备份。
