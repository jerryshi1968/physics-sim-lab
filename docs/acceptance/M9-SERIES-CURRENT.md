# 串联三处电流关系修订验收

日期：2026-11-24；J-ELEC-01 专用起点 `J-ELEC-01-SERIES`，版本仍为 `0.2.0-dev.1`。本轮按教师提供的三张装置图片、三份 JSON 及“不用电压表”的补充要求实施，不顺带合并并联入口或开展电压关系实验。

## 结果

- 初中电学原两个串联灯泡条目合并为一个“探究串联电路中各处电流的关系”。目录总数 50（初中 38、高中 12），初中电学 8 项；其余学科、初中力学顺序和两个并联入口保留。
- 新实验五件现有器材、五根导线，没有电压表；器材库禁用电压表和其他不支持类型。默认不同灯泡/9 V，开关断开；相同灯泡为两只 3 V / 0.3 A；补充修订后切换组合保留当前电源。
- A/B/C 三处在右侧选择，电流表留在教师图示下方，实际改接五根导线；器材位置、翻转、端点和弯曲路径按原 JSON。灯泡在画布标记为 L1/L2。
- 换位置不改电源、灯泡、姿态或所选电流档；换灯泡组合仅配置灯泡额定参数，保留当前电源全部参数和导线。两类操作均断开 S、一次撤销/重做，已有记录保留。
- 使用原 MNA 计算，不按菜单填示数。六个组合/测点的手工记录及采集、冻结来源、修订、比较表、CSV、SI JSON 和保存重载完成。比较表按实际快照归类，不自动补值或写结论。
- 用户自定义接线不静默覆盖；明确点击恢复才重建参考路线。删除重取后的新器材 ID 可绑定。教师五件旧场景可识别选项；旧含电压表串联、五件或六件并联以及通用空白不自动删改。
