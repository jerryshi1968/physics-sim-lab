# M9 / J-MEAS-02 天平测量质量验收

日期：2026-11-18。Windows / Node 24.14.1 / Edge / Playwright；WebKit 使用 iPhone 15、iPad (gen 7) landscape 模拟配置。不是实体设备或课堂验收。

## 交付

初中力学新增“用天平测量固体的质量”和“用天平测量液体的质量”两个起点，总目录 44 项（初中 32、高中 12）。全部复用天平、砝码盒、待测固体和烧杯，不增加器材类型；两个起点分别只放固体或空杯，不要求量筒，不提供重复空白入口。用户可自行增删另一种被测物。

固体可换橡皮/铅笔，质量参数可在 1～180 g 即时设置。直接拖动螺母调零、拖游码配平、点击砝码盒增减砝码。液体先称空杯，再移到桌面加水并称总质量；按同一杯的两条手工记录相减。空杯不绑定后来液体的名称，物理状态、称量资格和密度记录分别处理。

支持 g 手工记录、缺失/无效状态、冻结来源、修订/删除、计算液体质量、质量图线、CSV/JSON、保存加载和撤销。内部保持 kg。修改来源后明确重算才新增结果，不悄悄覆盖旧结果。模型和独立预期见[说明](../models/mass-measurement.md)，教材状态继续 `pending_teacher_review`。

## 发现与修正

首次类型检查发现新增目录 family 未加入预览来源类型、称量联合类型未显式缩窄；补齐类型，没有降低检查规则。首次核心 483/486：回放早期来源时误带入较晚版本的记录，导致来源重放失败。将重放隔离为源快照装置、清空后来记录，原用例保留，486/486 通过。

首次浏览器批次 22/23：来源选择框使用隐式标签，测试定位包含了选项文本；改为明确 aria-label，保留原定位测试。下一批 14/15：液体计算仍错误要求空杯和加水后液体标签相同，默认空杯 A 与加入的水不同，实际操作暴露该问题。空杯没有待测液体，移除不合理的液体标签/密度相等条件，保留同杯、空杯质量和校准校验，并新增独立容器/校准边界测试；最终 487/487 和质量流程通过。

首批六实验回归中，旧摩擦用例在等待“暂停牵引”时超时；没有修改其物理、测试或放宽超时，单独 1/1 复测通过，未宣称首轮一次全通过。截图另发现左盘固体标签被裁切、天平标题与砝码盒重叠；仅对质量实验调整标签位置并显示实际样品名，最终专项和 WebKit 复验通过。没有删除失败用例、修改物理预期迎合断言或改动未请求的摩擦逻辑。
