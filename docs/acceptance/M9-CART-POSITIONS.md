# H-MECH-07 逐点位置记录修订

2026-11-26。用户指出A/B/E操作混淆记录流程，确认改为“选计数点 → 逐点填写位置 → 计算点间距离与速度 → 三次汇总画图”。本轮只修订本实验的数据记录和相关画布标注，不改变牵引运动、通电释放及固定夹联锁。

## 实现

- 起点0可在纸带清晰点直接选取，保留列表辅助；纸带按固定打点间隔标出计数0、1、2……，起点前完整计数间隔处记为辅助−1。点击表格编号或输入格高亮对应纸带点，查看速度计算时高亮前后两个计数点。放大读尺以当前点为中心，超出视口的选中点自动进入画面。
- 一条纸带用一张横向位置表，按Tab逐格填写cm值，0点按坐标定义为0，不伪造仪器采集值。辅助点为负，其余点沿运动方向为正；默认录到点6，可增加/减少末点。所有选择和原始位置都是学生操作，不填模型值。
- 一张表一次保存、一次撤销；每个非零计数点只存一份原始位置。内部SI值与当前抄表文本按m保存，context.originalRawInput保留实际输入的cm原文，以CART_POSITION_CM标识输入/显示单位；快照明确inputUnit=cm。元数据只保存选点规则与纸带位置，具体源位置在记录上下文中，避免500字符快照备注限制。无需改文档格式或通用Schema。
- 相邻距离为xᵢ₊₁−xᵢ，计数周期T=stride/f，vᵢ≈(xᵢ₊₁−xᵢ₋₁)/(2T)。0点速度需要辅助点；末点缺后一点、缺失/超范围/矛盾读数均不补速度。速度只依赖实际所需的前后位置，中心位置缺失时可由已有两端计算，但相邻距离仍留空；中心位置已知且与两端顺序矛盾时不输出速度。
- 已保存的位置表可直接按cm修订，相关距离、相邻目标时刻的速度、汇总表、散点图和CSV同步重算。三次汇总表增加“位置编号”一行，保留时间、v1/v2/v3。自由截距拟合仍可选，未自动填写规律结论。
- 老版区间快照和原始记录保持原文，归为“旧版区间记录”，仍能查看、修订和绘图；不会伪装成完整位置表。刷新不续存完整纸带及未保存草稿，已存位置表与修订可恢复。

## 限制与下一项

一次保存要求所选片段（包括存在的辅助点）均在水平正向尺内。可移动纸带/尺，或减少末点；不允许在尺外自动读取或以真值填表。辅助位置按运动方向有符号输入，不等于尺面原始刻度读数；尺零位未对准时学生自行量相对距离。最多按已打出的清晰点扩展，不计算末端重合点。
