# 器材支持与禁用规则统一验收

日期：2026-11-11。维护修订，保持 0.2.0-dev.1；不新增实验或物理模型。

## 交付范围

- 当前实验、器材库、属性面板和放置入口共用实验支持规则。正式实验 ID 优先，旧文档中的外来器材不再使界面悄悄识别为另一个实验。
- 不支持或达到数量上限的器材保留显示、禁用并说明原因；支持的器材排在前面。选择器材不触发实验切换；明确的新建实验入口保留预览确认。
- 覆盖鼠标、触摸、拖放与中心放置，删除、撤销、重做、加载后重新判断数量。
- 杠杆不再把未处理的其他力学器材静默当作有效装置；光学、杠杆、摩擦和弹簧使用共用名单。没有修改物理公式、SI 单位、文件格式或历史快照。
- 烧杯统一基础名称；卡片说明弹簧、测力计、钩码、木块加压砝码和天平砝码的用途。未将不同类型合并成通用器材。

## 实际验证

| 检查 | 结果 |
| --- | --- |
| 核心测试 | 360/360，新增 4 项，覆盖跨实验拒绝、数量释放、空白/旧文档保持、杠杆拒绝未处理器材 |
| TypeScript / ESLint | 三份类型配置通过；lint 零警告 |
| Vite 构建 | 通过；原有分块大于 500 kB 的提示保留 |
| Edge 全量首轮 | 135/136；唯一失败为原小车测试要求“预置已有一台打点计时器时，仍允许继续添加” |
| 最终 Edge 受影响复测 | 21/21，包括 12 个正式实验 ID 的器材矩阵、鼠标/触摸禁用、数量与撤销重载、混合旧文档、两个小车完整流程和四项即时属性回归 |
| WebKit 模拟 | iPhone 15 与 iPad 横屏 2/2，浮力弹簧、第二只测力计和平抛天平禁用，强制轻点无弹窗，禁用原因可见且无页面横向溢出 |

小车旧断言已按新需求改为检查禁用及“一件上限”提示，保留其后续采样、纸带、图线、导出与保存加载断言，最终完整小车流程通过。全量之后收尾统一了属性面板的实验识别，并扩展了旧文档反例，已包含在最终 21 项复测中；没有再次完整运行 136 项，不把分批结果写成一次全量全绿。

本机报告与截图保存在忽略目录 `artifacts/equipment-support-20261111/`，包括首轮全量、最终受影响复测与 WebKit 结果。既有源码注释逐字保持，修改文件的原换行形式保留；无新增依赖或第三方内容。

## 待核验

本次没有实现跨实验自由物理组合，支持范围保持表中已有能力。旧的不兼容装置保留，由用户移除多余器材后继续；没有迁移或重写历史测量。WebKit 结果属于软件模拟，实体 iPhone/iPad 与课堂体验仍待核验。前次记录的摩擦时序用例本轮全量通过，但不以单次通过宣称其时序差异已定位或修复。
