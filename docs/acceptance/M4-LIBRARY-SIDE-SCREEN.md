# 器材分类页签与斜侧视光屏修订验收

日期：2026-11-04。按用户截图反馈修订任务 09：实验区光屏采用斜侧视外观，成像集中在右侧；默认工作台的器材库能通过页签找到光学器材。没有实施任务 10。

## 最终行为

- 器材库始终显示“电学 / 光学”，默认电学 8 项、光学 5 项。鼠标、触摸、左右键和 Home/End 可切换，ARIA 页签与面板分组独立于下方记录面板。
- 空白工作台切到光学即可直接放置，不必先找到顶部实验入口。切页不改场景/历史/保存，仅取消待放置或拖入状态。
- 已有其他领域装置、连接或正式实验时仍可浏览另一类器材，放置按钮禁用，并提供“新建光学/电学实验”。使用既有替换预览，取消保留当前装置，确认才新建独立空白实验，避免加入当前求解器不支持的混合器材。
- 实验区与器材库中的光屏统一斜侧视，支杆、底座和命中范围跟随外观。右侧仍用实际光线落点、屏宽高与离焦绘制完整正视成像。斜视仅为画法，物理屏面位置、朝向、尺寸、五类成像和保存格式没有变化。
- 直接放置首个光学器材会切换观察/记录/图线领域；图线原选项在新领域不存在时，使用该领域首个有效配置，避免页面报错。
