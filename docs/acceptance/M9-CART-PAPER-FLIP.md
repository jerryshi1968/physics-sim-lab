# H-MECH-07 纸带左右翻转修订

2026-11-26，按教师建议让纸带计数点沿尺的递增方向排列。本轮只修改小车实验取带后的测量摆放与相关显示/来源，不改打点时序、小车运动或既有开关固定夹条件。

## 行为和模型

- 小车纸带断电开夹、取下并结束拖动后，默认左右翻转，计数点从左向右递增。键盘方向键取带在松键时完成同样处理。画布原“查看计时器”位置在取带后切换为“左右翻转”，可用鼠标、触屏或Enter翻回，装在计时器内或运动中不提供翻转。
- 默认以清晰的初始计数0点为翻转中心；再次手动翻转以当前选中计数点为中心，保持它在尺上的位置。其余点反射，不改点序、打点时间、位移、学生输入或速度。取新纸带恢复装配方向。
- 纸带放置增加可选flippedX；省略为原方向，旧文档可读。世界横坐标为P+s·d，P为原始第0点的纸带锚点，d为原始位移，翻转时s=+1，原方向s=−1。围绕位移dₚ翻转时P'=P+2s·dₚ，故P'+(−s)dₚ=P+s·dₚ；连续翻转两次恢复各点位置。
- 点选、前景尺近点选择、纸带边界、拖动/取消、键盘平移、全景、放大定位及计数标注使用相同方向。摆尺校验同时检查两端读数的最小/最大值，翻转后不能把超出尺右端的点当成有效测量。
- 位置表来源在原paper坐标之外可选记录flippedX=true，原有SI位置与计算不受影响。顺向时位置=该点尺读数−0点尺读数；翻回时顺序相反。旧记录没有方向字段仍按原方向解释，通用文档Schema不变。

## 失败和限制

初次类型检查发现纸带位置推断未含可选方向，随后发现器材pose的可选属性显式允许undefined；已补齐位置类型注解和兼容类型，未放宽场景校验。第一次浏览器运行在构建被类型检查中止后误用了旧dist，1/7通过、6项因缺少新方向属性失败；该记录不是新版功能验收，保留在`artifacts/cart-flip-browser-first.log`及同名证据目录。修正类型、重新构建后14/14通过，没有删除用例。

翻转是测量摆放，会话中的完整纸带仍不跨刷新续存，冻结的方向来源和已记录位置可恢复；尺不自动对齐到0点，不自动填位置。只有本小车实验默认翻转，练习计时器和原纸带测速的操作方向保持。未重复首批六实验全部浏览器流程，物理和场景由本轮完整核心覆盖；未验证WebKit、实体触屏或课堂，教材仍pending_teacher_review。下一项为教师试用取带、双向翻转与逐点读尺。
