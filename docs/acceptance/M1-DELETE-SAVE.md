# M1 / 已保存实验删除补充

日期：2026-11-03。用户反馈实验列表没有删除入口；现已在每条保存旁增加删除按钮，按 ID 定位，确认界面显示名称/ID 和不可撤销说明，并默认聚焦“取消删除”。取消或 Escape 只回到列表，不改数据。

删除只移除本地保存，不清空当前工作台、不修改文档或历史。删除当前文档的保存后标为“尚未保存”，再次保存可重新加入列表。删除最近保存的实验时，启动快照改为剩余最近保存；没有剩余则清除启动快照。对应旧库备份同时移除，其他实验保留；失败整事务回滚，不伪装已删除。当前实验仍可导出 JSON，删除本地保存不删除用户已下载的备份文件。
