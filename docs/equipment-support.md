# 器材支持范围与禁用规则

更新：2026-11-12。规则位于 `src/equipment/support.ts`，用于当前实验识别、器材库禁用以及放置前检查。光学、杠杆、摩擦和弹簧的器材白名单也由该模块提供；其余实验沿用定义文件中已有的共用名单。

## 操作规则

- 当前实验支持的器材排在前面。未支持的器材保留显示并禁用，卡片文字及鼠标提示说明原因。
- 达到模型数量上限时禁用继续添加。删除、撤销、重做及保存重载后按实际装置重新判断。
- 点击、触摸、拖入、画布点击放置及“在视口中心放置”均执行同一检查。选择器材不打开其他实验窗口。
- 更换实验通过顶部实验入口，或跨学科页签中明确的“新建某学科实验”按钮发起，继续使用预览和确认替换。
- 完全空白且未指定实验的场景可从任一学科开始放置；随后按场景器材识别实验范围。正式实验的空白搭建仍遵守其支持名单。
- 已有实验 ID 优先确定当前模型。旧文档含有不兼容或超量器材时保留原装置，不自动删除、转换器材或更换实验；模型校验失败时不提供正常结果，用户可移除多余器材。

## 通用空白

学段目录新增初中电学空白 `J-ELEC-FREE`、高中恒定电流空白 `H-ELEC-FREE` 和光学空白 `J-OPT-FREE`。两种电学空白使用通用电路范围；光学空白按已放器材求兼容模型，独立尺不单独选定模型，互斥卡片禁用。空白未确定模型及互斥导入不输出正常领域结果，删除/撤销和存档重载后重新判断。自由反射中独立尺作为被动工具，正式反射实验的支持表保持。详见[目录与自由搭建规则](experiment-catalog.md)。

初中通用电学空白统一提供“普通记录 / I–U 探究 / I–1/R 探究 / 伏安法测电阻”选择。切换不改实验身份和通用器材范围，不自动移除或改接已有器材；专用记录仍检查是否满足定值电阻探究的接线条件。两个预搭建 J-ELEC-02 起点继续使用专用器材范围，旧空白存档保留兼容。

| 电源电动势与内阻 | 电池盒、电阻、开关、电流表、电压表、四柱滑动变阻器、导线 | 电源、开关、两种电表、变阻器各最多 1 件；电阻与导线可多件，仅对支持的电阻性结构拟合 |

| 杠杆平衡 | 杠杆、支架、钩码、弹簧测力计、力学独立刻度尺 | 杠杆最多 1 根，挂点约束沿用原规则 |
| 滑动摩擦力 | 木块、接触面、牵引器、砝码、弹簧测力计、力学独立刻度尺 | 木块最多 1 件，计算使用实际挂接的器材 |
| 弹簧弹力 | 弹簧、支架、钩码、力学独立刻度尺 | 弹簧最多 1 根 |
| 单摆测 g | 单摆、支架、力学独立刻度尺、计时器（与平抛共用） | 单摆、支架和计时器各最多 1 件，独立尺可重复放置 |

“最多 1 件”是添加上限，不表示每个可选器材都必须放入；完整测量所需器材继续由各模型和记录流程校验。显式电学结点保留旧文档兼容，器材库仍隐藏。

## 名称与现有能力

烧杯的基础名称统一为“烧杯”，在浮力中按盛液、接液用途显示；用途和容量约束保留。弹簧、弹簧测力计以及三类加载器材在器材卡片中说明不同用途。

本次没有把不同类型的物体、砝码、计时器或两种独立尺合并成通用器材，也没有新增跨实验的物理耦合。小车配重和悬挂质量继续作为小车参数；浮力圆柱体与密度待测固体仍是两个类型。物理公式、单位、测量来源追溯和文档格式保持。

## J-ELEC-03 伏安法

预搭建起点仅允许现有电池盒、开关、定值电阻、电流表、电压表、四柱变阻器各一件及导线；不支持灯泡，继续禁用不兼容器材。没有新器材类型。待测电阻是现有电阻的隐藏阻值显示设置；断开开关后可更换并保留导线。初中电表固定为 0 Ω / ∞。通用空白选择伏安法记录时仍保留自由器材范围，仅在成组记录前检查专用接线与理想表条件。
