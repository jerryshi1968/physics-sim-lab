# 0008 — M2 灯泡、电表与浏览器调度

日期：2026-11-04。状态：任务 06 已实施，课堂/正式实验验收待进行。

任务 06 要求真实非线性灯泡、双量程表及旧回包保护；用户进一步要求非对称器材左右翻转、直接开合开关及通电反应。

- 沿用独立 MNA，以灯泡电流为未知量的阻尼 Newton 统一求解，复用线性盖章和残差；采用明确的迭代/回溯上限，无隐藏 gmin、恒阻替代或旧值降级。功率驱动亮度。
- 电表的公共/小/大量程端独立参与真实图编译；量程依接线确定，双正端误接拒绝计算。仪器显示、模型真值和未来学生记录分开，异常不生成正常读数。
- 浏览器采用原生模块 Worker，按文档、revision、runId、sequence 精确接收，20 ms 合并修改、10 s 超时，并终止过期任务。运行态不进入历史和持久化；不新增依赖。
- 按用户要求为 pose 增加可选 flippedX，局部反射先于旋转，端口 ID 保持；沿用格式 2 缺省兼容和格式 1 严格迁移。翻转及开关动作复用命令历史，支持鼠标/触摸/键盘。
- 保持原实物插图、自由导线和多实验保存/删除。新增灯泡与表盘仍为原创 SVG/CSS，无图片或外部资源。

实际数学、边界、调度与交互验证见[验收](../acceptance/M2-TASK06.md)，接口与限制见[模型说明](../models/lamps-and-meters.md)。任务 07 的记录/CSV 和任务 08 的正式串并联实验流程未提前实施；热惯性、烧毁、全局器材模式仍不在本次范围。

2026-11-04 用户补充：闭合开关应直接看到效果。调度改为默认自动运行，加载/刷新后同样按初态重算，无需手动启动；仅用户主动暂停时停更。“重新计算”建立新运行并恢复自动更新，空白无器材不创建 Worker。保留原 20 ms 合并、超时、终止及标签校验，未修改物理模型或持久化格式。
