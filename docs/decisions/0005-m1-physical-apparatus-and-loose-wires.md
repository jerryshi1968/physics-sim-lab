# 0005：实物风格器材与可独立摆放的导线

日期：2026-11-03。依据：用户在任务 03 后明确要求电池符号一长一短、实验区展示实物图、器材库用导线替代显式结点，并允许鼠标或触摸拖动弯曲导线。该要求优先于原方案和 0004 的显式结点 UI 设计；不是任务 04 的存储实现。

## 已实施的修订

实验区改为原创 SVG 实物风格插图：双节电池盒、木底陶瓷电阻与胶木底刀开关，采用本地渐变、金属接线柱和阴影，不引入在线素材或新依赖。电池盒卡片的图标明确为一对长短极线（24/12 单位），不再使用容易误读的 Unicode 组合。图形是教学示意，尚不承诺照片级外观、特定品牌或真实电池化学特性。

器材库现在为电池盒、电阻、开关、导线，不提供显式结点入口。多根导线直接连接同一个器材接线柱。旧 junction 定义暂保留在核心注册表以免把历史类型悄悄当作不存在，但不出现在可取用器材库；原有核心结点测试作为历史能力回归保留，不代表继续要求用户使用结点。

导线是 Connection 而不是虚构器材。可以先拖入、后接线；未接时有两个明确的自由线头位置，线身可整体移动。已接导线的端点固定随器材，拖动线身可弯曲；所有弯曲控制点都在曲线上，可用鼠标、触摸或方向键移动。选中线头可拖出/吸附到接线柱，或用属性按钮选择线头再点目标接线柱；支持拔开与重新连接，不改变其他端点。选中导线的手柄在最上层，器材选框不拦截其操作。

曲线采用经过所有路径点的分段三次曲线；没有中间点的快捷接线也有轻微弯曲。绝缘线身、金属线头和弯曲外观只影响显示，不改变连接图。吸附仅选择半径 20 px 内的最近 electrical-terminal，不因线条交叉、自由线头重叠或视觉靠近自动导通。

## 场景版本 2

新增“尚未连接的线头”是场景格式能力变化，schemaVersion 升为 2。Connection 的 from/to 允许 null；对应自由位置分别为 freeFromWorldM/freeToWorldM（x/y，单位 m）。一个线头必须且只能具有有效端口引用或有限自由位置；已连接端不能同时携带自由位置，非 wire 连接不允许自由线头。旧的两端完整连接字段保持同义。

只有两端都已接到有效接线柱的导线才合并电气结点；一端或两端未接的导线保持开口，不伪造电流、量测或连接。改接同一端口到两头仍被拒绝，失败恢复原导线。移动整根自由导线和编辑线头使用未提交预览，松手只提交一次 revision，取消回滚。

当前尚无文件导入/持久化，不静默把 v1 文档当成 v2：v1 直接校验被拒绝。任务 04 必须提供明确的 v1→v2 迁移及测试（旧 from/to 完整连接可原样保留，顶层版本转换需显式执行），不得删除未知器材或编造自由端位置。原始实施方案保持原文，本记录和最新进度说明覆盖其旧交互约定。
