# 0017：M7 工程复测、运行态隔离与离线边界

日期：2026-11-05，任务 14。

六实验复用既有物理和测量接口，重新执行完整单元/模型与 Edge、Chrome 浏览器流程。性能测量独立运行，避免和全量浏览器回归同时竞争 CPU；记录本机、构建、采样方法和实际输出，不外推到所有课堂电脑。rAF 节拍与输入到后续两帧是浏览器可观察指标，Worker 往返单独报告；它们不能替代实体投影/平板的显示评价。

反复切换发现摩擦的 runningKey/frame 可在同一源初态重新出现时复用旧值。关键初态/启用状态切换时清理旧帧及运行标志，替换文档和新建时显式重置摩擦；保留控制拉力/速度的即时调节行为。新增同文档运行中导入、跨实验返回、初态改变后撤销/重做的回归，不改变摩擦公式、积分步长或 Matter.js 适配契约。

最低离线交付采用静态 dist + 只用 Node 内置模块的本机 HTTP，不增加 Service Worker/PWA、后端或运行依赖。服务器只监听 loopback，限制只读方法、路径与实际文件边界，不允许目录穿越/外部联接，不缓存旧构建。测试用 ZIP 包保留运行时第三方声明；正式发行许可仍属任务 15。

无外网检查使用禁用缓存的新上下文，阻断全部非 loopback 页面/Worker 请求，并从解压后的构建验证。保留本机 HTTP 才是此交付的运行条件；不把禁用全部 loopback 后的失败或浏览器预缓存误称为离线可用。软件触摸、150% CSS 布局缩放、单机无头性能与实体硬件检查分别记录。
