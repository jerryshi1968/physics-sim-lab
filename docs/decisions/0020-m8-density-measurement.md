# 0020：在既有工作台加入固体/液体密度测量

日期：2026-11-09；状态：本次实现。承接第9.2节，用户明确要求同时实现固体与液体。

共用一套天平、砝码盒、量筒、待测固体、液体烧杯，注册在力学页签，以单独实验入口选择方法。采用静态称量、等截面排水和守恒倒液模型，保留手工读尺、调零、逐阶段测量与错误观察；不引入通用流体引擎、图片素材或新依赖。左物右码、移动游码，不用数字秤直接给答案。空载调零由物理参数判断，不新增确认按钮。

复用场景、历史、通用记录/图线、CSV与保存导入。每次读数先形成独立快照，再由用户选择三个来源计算；新增可选 sourceSnapshotIds 连接结果与历史条件，删除来源行时保留被引用的快照。引用仅允许较早版本以保证无环；不自动重算旧结果。

物理/JSON 使用 SI，教学界面使用 g、mL/cm³、g/cm³；扩展既有显示转换以兼容原角度转换。文件版本不迁移，旧实验数据保持；新器材混入旧实验时拒绝正常求解或弹出可取消的另建入口。冻结候选包保持，版本仍为0.2.0-dev.1。教材映射与实体设备/课堂待核验项不因自动测试通过而完成。
