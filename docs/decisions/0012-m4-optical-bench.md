# 0012 — M4 光具座、透镜与离焦光屏

日期：2026-11-04。状态：已实施。

用户要求实施任务 09。在既有工作台中添加光学器材注册与实验入口，复用场景、历史、保存、测量/图线/CSV，不新建平行应用或后端。原电学注册工厂保持，应用层组合两领域注册；器材库按实验领域显示，光学场景关闭电学 Worker，混合场景明确诊断。

采用原近轴薄镜小样及独立圆孔径光线传播，光屏由多个非对称火焰物点的实际落点绘图。屏位置连续影响离焦，同高/偏心影响落屏，不按公式像距切换一张贴图，不自动摆放或对焦。虚像观察仅在可关闭辅助中出现，实际屏上不承接虚像；u=f 的像距与放大率为 null。

独立尺只改变零点，读尺窗保留原刻度。手工输入、尺分度显示、理论真值分开；明确区分屏距 s 与实测像距 v，后者只在清晰实像时有效。观察文本与器材/尺参数存入既有共享快照；保留不可用及空值，不把理论数写为学生数据。格式/存储版本不变，教材未核验字段保持原约束。

仅参考 [Ray Optics 官网](https://phydemo.app/ray-optics/)关于理想镜、尺与视图的介绍，未复制源码或素材，无新依赖；未来若复用再逐文件核验。模型参数、边界、采样与独立手算见[模型说明](../models/optical-bench.md)，证据见[验收](../acceptance/M4-TASK09.md)。任务 10 未实施。
