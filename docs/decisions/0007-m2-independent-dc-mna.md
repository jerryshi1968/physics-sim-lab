# 0007：独立直流网表与 MNA

日期：2026-11-04。范围：实施方案任务 05。任务 00～04 的文档、实物图、电池电压、历史、多实验保存/删除均原样保留；不提前开发任务 06 的灯泡、仪表 UI 或调度。

新增 src/core/electrical 领域核心，使用已有 Zod 验证网表，以未知量节点电压和电压支路电流构造 MNA；拓扑、线性代数、求解结果和场景编译分别独立文件。依赖方向为场景/注册表→编译→netlist→拓扑/盖章/求解，React 不参与。

SceneDocument 的模型入口以 modelAdapterId 分派，默认适配器单独位于 src/equipment/electrical；保留原定义 `.uncompiled.v1` 标识的兼容映射，不改变存储或库内容。接线由真实端口引用编译，几何/标题/实验 ID 不作拓扑提示；自由线头保留为显式 open，不丢弃或误合并。

零阻导线/闭合开关并查集合并；理想电流测量用零伏源保留未知支路电流，不能直接合并。每分量独立选参考，跨分量理想探针不可用。源/理想测流零阻环先做拓扑约束检查；病态、无解或不唯一不返回正常 solution，不采用 gmin 等隐藏修补。

有限内阻源、测量电阻和电压输入电阻在独立 netlist 中显式支持；默认 UI 场景现只有理想设备，不擅自给 apparatus 配置添加参数，未配置模式明确失败。输出使用被动符号电流与功率，合并理想线的单支路电流不可观测，以 null 标记，不伪装 0。

用行列均衡、部分主元消元、原方程后向残差与独立 KCL/本构/功率残差，限定每分量 256 未知量；不承诺任意病态或大规模电路精度。保留经过测试的仿射电导盖章入口给下一阶段非线性迭代。

理论仅核对 Qucs 官方 MNA 公式；没有复制第三方物理或线性代数代码，不增加依赖。详见[模型与独立预期值](../models/dc-mna.md)、[台账](../THIRD_PARTY.md)和[实际验收](../acceptance/M2-TASK05.md)。
