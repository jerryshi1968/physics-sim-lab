日期：2026-11-03。范围：任务 03 / M1；不提前实现任务 04 的历史/存储或任务 05 的电路求解。

## 分层与器材

沿用现有 React、Zod、Vite、npm 锁文件和测试工具，不增加依赖。正式器材定义在 src/equipment/electrical/definitions.ts，提供电源、电阻、开关及明确接线汇合所需的显式结点；不把任务 02 测试夹具作为生产器材。注册表工厂每次建立独立注册实例，默认 EquipmentRegistry 类自身仍为空，原有核心用例继续成立。

电源默认 3 V（允许 0 V），电阻默认 10 Ω（必须 >0），开关默认断开；结点只有一个可接多线的 electrical-terminal。定义版本均为 1；modelAdapterId 明确标为 uncompiled，尚未接入求解器，不据此输出电流或亮灯。所有端口坐标是器材局部世界坐标 m，稳定 ID 与显示文字分离。

核心编辑与坐标运算放在 src/core/workbench，不依赖 React/DOM。新增器材、参数/位置更新、接线、线路折点和删除先生成独立候选文档，再走既有结构/注册表校验；失败无部分文档，原装置不变。场景版本不变，电线颜色是视图状态，不混入连接关系。核心 tsconfig 只新增正式器材 TS 目录，继续不含 DOM 类型。

## 指针、键盘与事务边界

器材库采用 Pointer Events：点击后点画布放置，或拖入画布；同时提供“在视口中心放置”，无需拖动。器材拖动与导线折点拖动使用 SVG 指针捕获，预览不写入文档；松手成功提交一次 revision，取消清除预览并恢复原位置，为下一任务的一次手势/一个历史事务保留边界。目前尚无命令历史。

触摸/笔的选择、放置和端口激活直接由 pointerup 完成，并去重随后可能出现的兼容 click；鼠标和键盘仍可使用 click。真实浏览器测试发现触摸拖动后兼容 click 可能缺失，不能依赖它完成下一次触摸选择。取消和丢失捕获清除手势；多指缩放不在本任务范围。API 依据见 [Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events) 与 [React 指针事件](https://react.dev/reference/react-dom/components/common#pointerevent-handler)。

选中器材可由下拉框选择，用 m/° 位置转角与有单位的参数表单精确编辑；器材在 SVG 获焦后可用方向键每次移动 0.01 m。端口可以用 Tab/Enter 或属性区按钮完成接线；接线起点保留到选择终点或取消，Escape 在画布及属性区均有效。导线也可由列表选中、删除、添加/清除折点，折点可拖动或用方向键移动 0.01 m。

默认缩放双端口命中直径 44 px；低倍率下缩小命中区，避免前一端口被后一端口覆盖而接错。缩小时可用属性区端口按钮，无须依赖小端口点击。器材库卡片和 SVG 使用 touch-action:none，页面其他区域仍可滚动。

## 几何与连接语义

世界坐标 y 向上，屏幕 y 向下；缩放范围 100～2400 px/m，默认 600 px/m。滚轮以指针为锚点缩放，按钮以视口中心缩放；平移和缩放只更新 viewport，不增加装置 revision 或修改物理参数。局部端口经器材旋转/平移后投影，导线每次从端口重新取点，器材移动/转角和缩放后端点始终跟随。

wire 的 from/to 是唯一连接依据，routeWorldM 是折线路径；折点、交叉和器材靠近都不生成电气接点。显式结点必须被导线真正连接，放在交叉处本身也不自动连通。允许一个端口多条导线和冗余导线；wiringNodes 仅对明确端点合并，不能把支路元件、电压源或开关的内部模型误当作普通导线合并。

同一个端口连自己被拒绝并解释，未知端点或错误类型交给既有校验并提供中文消息。错误类型测试用未在 UI 开放的光学安装端口，验证导线只能接 electrical-terminal；生产四类器材目前全部为合法电气端口。

删除器材时删除它的相连导线，不改其他器材/连接。已有历史测量引用的器材暂拒绝删除以避免丢失记录（UI 尚无测量功能），历史器材快照策略留到任务 07。保存、导入/导出和撤销/重做仍禁用，刷新不持久化装置。
