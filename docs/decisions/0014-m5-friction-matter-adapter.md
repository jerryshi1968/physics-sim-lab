# 0014：水平一维摩擦由自研模型独占轨迹

日期：2026-11-04。范围：任务 11 / M5。

实施方案明确要求 Matter.js 与教学模型的每个自由度只有一个来源。本次不使用 Matter.js 自带摩擦/积分作为教材摩擦真值，而是保留 M0 代数小样，新增带过零事件的一维自研积分器与牵引控制器。Matter.js 0.20.0 的两个静态形状同步自研轨迹、查询受限接触，统一固定长度/时间映射并逐步核验一致性；不混用 kg/m 与引擎默认密度、摩擦或约束伸长。

牵引器可选：装配区不连接牵引器时使用直接可控水平拉力，连接后可使用匀速辅助。示数是实际 Fpull；仅连续 0.3 s 匀速滑动时可等同滑动摩擦力。静止/加速记录保留资格标记，F–N 图不接纳无效摩擦点。面积、材料和总质量独立，参数/采样可追溯，不强行填入学生读数。

采用现有原生 SVG、React/Zod、参数引用、SceneCommand/原子批量更新、文档格式 2、共享快照、表格/CSV/图线和 IndexedDB。运行状态不写回设备姿态，重载从初态重跑；运行中仅牵引控制变化连续，条件变化安全重置。新增类型独立于旧杠杆、光学和电学，未把 Matter.js 引入旧模型运动计算。

依赖在引入前登记，使用 npm 官方固定版本和 sha512，保留未修改包内 MIT 许可及构建声明；参见[第三方台账](../THIRD_PARTY.md)。不引入第三方插图或物理实现片段。
