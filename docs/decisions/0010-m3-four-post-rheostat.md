# 0010 — M3 用户追加四柱滑动变阻器

日期：2026-11-04。状态：已实施。

用户明确要求器材库增加四柱滑动变阻器、可拖入接线及滑动滑片。此追加需求优先于原方案首版排除滑动变阻器的范围；采用原方案第 6.3 节已有的四端电阻段定义，不把本次扩展标为任务 08 或新增欧姆定律正式实验。

采用真实 A/B 电阻丝、C/D 共用滑片的图结构，保留任意多柱接法。端点零阻合并，不引入隐藏小电阻；复用现有线性/非线性 MNA、灯泡和双量程电表，无外部求解库。为覆盖最大合法四柱场景，端子上限调整为 1800，分量矩阵上限保持。

图形为原创 SVG 实物图，与器材库一致。滑片坐标先逆旋转再逆反射，四个外接柱固定在器材上。接线、旋转、翻转、保线删除、历史和 JSON 沿用既有机制。

拖动中使用独立暂态参数及预览身份，不伪造文档 revision；限速并补发最后位置。预览只驱动显示，阻止测量采样，保存仍读取正式文档；松手一笔历史，取消回滚。这样不会把拖动中间值混入学生记录或保存。

模型、边界和手算见[四柱模型说明](../models/rheostat.md)；实际检查、截图和限制见[验收记录](../acceptance/M3-RHEOSTAT.md)。不增加依赖、外部素材或修改实施方案原文。
