# 0009 — M3 测量快照、记录与导出

日期：2026-11-04。状态：任务 07 工程实现；正式实验闭环和课堂验收待任务 08。

- 沿用 MeasurementRecord，增加可选 context/correctedAt 和文档共享 measurementSnapshots，保留 schemaVersion=2 的旧文档读取，严格拒绝格式 1 中的新字段。每次多测点只存一份全接线/器材快照，标签和历史配置不可由后来编辑改写。
- 明确三种值：仪表采集取分度显示值，手工来源保存学生原文与当前修订值，物理真值仅在追溯中独立保留。异常可记录状态但不能留正常数值；缺失不补零。过期版本不允许采样。
- 采样、手工修订和删除走原有事务历史，批量采样一步撤销；快照、引用和大小均先校验，失败无部分数据。维持已有器材测量引用保护，不引入删除后的虚假当前器材。
- 表格/图线/CSV 共用记录行；当前只开放 I/V 多测点比较，其他领域仅定义量纲/测点/变换接口并禁用 UI，不生成领域数据或任务 08 模板。
- SVG 图线为本项目编写，无图表依赖；明示异常断线和真实零值，稳健投影极端有限数据。CSV 带 BOM、引用转义与文本公式前导中和，共享大快照只在每组首行输出，保留精确 JSON 备份路径。
- 采样后优先展示表格，设置可折叠；切页保留草稿并回到顶部，追溯详情按需渲染。保持实物图、双圈表盘、自动更新、左右翻转、多选/保线删除和多实验存储。

接口、范围与 CSV 限制见[模型说明](../models/measurements-and-export.md)，实际结果和截图见[验收](../acceptance/M3-TASK07.md)。未新增依赖或复制第三方代码。
