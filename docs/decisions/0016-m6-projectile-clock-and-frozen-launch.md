# 0016：平抛使用解析时钟，记录区分冻结初态与待发装置

日期：2026-11-05，任务 13 / M6。

正式平抛复用原自研解析小样，一次发射复制初态，所有位姿、计时、等时标记和采样读取同一仿真时刻。rAF 只提供经过秒数，暂停不计墙钟，恢复从最后展示时刻继续；跨落地帧在解析事件时刻截断，不用 Matter.js 或逐帧积分替代。重复发射重置帧时间原点，运行中参数修改用于下一次；本次源输入不随编辑漂移。

新增五类原生 SVG 器材和高中入口，复用即时属性、拖放、历史、数据表和 CSV/JSON；提供实际二维标尺、计时器和至少三组落地前的手工读数，按 runId 分轨迹绘制 x–t 与 ydrop–t²。三点拟合为平抛显式参数，弹簧默认五点门槛保持。

为避免记录旧轨迹时错误引用新参数，在格式 2 中给共享快照增加受限可选 captureState。主快照/记录配置仍是本次真实物理初态；captureState 用于对采样时待发源文档作严格比对与追溯。仅新平抛模型允许此扩展，两套状态均递归校验，旧快照规则不变；CSV 只在有新扩展时增加对应列。

读数、理论与学生记录分开，理论辅助默认关闭；无效新装置不发射，删除本次关键器材使本次不可用。源初态与已有记录可保存，运行时刻不续存，同文档加载也重置。模型、独立预期与教材待核验边界见[说明](../models/projectile-experiment.md)，真实工程检查见[验收](../acceptance/M6-TASK13.md)。无新依赖、素材或第三方物理实现；本次未进入任务 14。
