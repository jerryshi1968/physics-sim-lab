# 静态构建与离线运行

本项目的六个实验在浏览器本地运行，不需要业务后端、账户或数据库。任务 14 提供测试用静态构建包；教师核验和发行授权状态见验收记录，不能把测试包当作正式发行结论。

## 在开发电脑准备

```powershell
npm ci --ignore-scripts
npm run build
node scripts/serve-dist.mjs
```

安装依赖需要事先联网或准备完整缓存。构建后只需要 dist 目录、scripts/serve-dist.mjs 和已安装的 Node.js；上面的 HTTP 启动器只使用 Node 内置模块，不调用 npm、不下载包。当前实测 Node 24.14.1。

## 在无外网的教学电脑运行

1. 提前安装 Node.js，并将测试包完整解压到一个本地目录。保留 dist 和 scripts 的相对位置。
2. 在解压目录打开终端，运行 `node scripts/serve-dist.mjs`。
3. 用 Edge 或 Chrome 打开 `http://127.0.0.1:8080/`，选择实验。终端保持运行，结束时按 Ctrl+C。
4. 需要迁移原来的实验时，先在原地址导出 JSON，再在离线地址导入；需要测量数据副本时导出 CSV。

不要双击 dist/index.html。ES 模块、Worker 和资源需要通过本地 HTTP 加载。服务器只监听 127.0.0.1，不能直接供其他电脑访问；它只读取构建目录，不接收或上传实验数据。

若 8080 已占用，使用 `node scripts/serve-dist.mjs --port 8081` 并打开对应地址。也可用 `--root` 指定另一份 dist。保存属于“浏览器配置 + 地址源”，5173、8080、8081、localhost 与 127.0.0.1 的存储不同；更换端口或浏览器后看不到原列表，不表示原数据被删除。无痕模式及清理站点数据可能丢弃本地保存，重要实验请保留 JSON。

## 断网能力与更新边界

所有运行资源来自本地 dist，没有远程字体、CDN、分析 SDK 或模型服务。首次打开也可在没有外网时完成，前提是本机 HTTP 服务可用。单纯“网页已经打开后把网络全部禁用”会同时禁用 loopback，不能代表保留本地 HTTP 的课堂场景。

本次工程检查使用新浏览器上下文、禁用缓存，阻断所有非本机请求，同时保留本机 HTTP；六实验冷启动、计算、键盘/软件触摸、保存重载和文件导出均分别记录。没有修改操作系统网卡，也没有将这一检查称为实体教室断网验收。实际结果见[任务 14 验收](acceptance/M7-TASK14.md)。

没有安装 Service Worker/PWA，不承诺关闭本地服务后仍能重新加载。HTTP 响应不使用旧缓存；更新时停止服务后更换整份 dist，重新启动并刷新页面。不要把两次构建的 index.html 和哈希资源混装。

## 课堂操作建议

1366×768 投屏与 1920×1080 桌面均有复测。大字号可以使用浏览器缩放；本次额外检查 150% CSS 布局缩放，不能替代操作系统高 DPI 或真实投影可读性评价。窄屏和软件触摸可滚动到器材库、属性与记录区，画布内可放大/平移；超出视口的器材需要平移查看。

触屏和教师的检查步骤、待填写反馈见[两学段试用清单](acceptance/TEACHER-TRIAL.md)。真实平板、其他硬件、第二位教师和具体教材版次仍需补充核验。
