# 中国大陆初高中开源 Web 虚拟物理实验室：分阶段实施方案

版本：1.1（按用户补充的原始六实验清单修订）  
整理与公开资料核对日期：2026-11-03  
用途：作为 Codex 的项目需求、架构约束、阶段任务与验收依据。  
项目暂定名：中学物理实验室（CN Physics Lab）。正式发布前另行检查名称与商标。

> 核心目标：学生从器材库中选择器材，摆放、接线或连接，自主完成实验，读取仪表示数、记录数据、分析规律；教师可以准备、保存并分享同一套可编辑的实验装置。

## 0. 如何使用本文

1. 把本文件放入实际项目的 `docs/implementation-plan.md`，不要仅将聊天摘要当作需求。
2. 先执行第 15 章的任务 00，检查项目现状并建立阶段记录；随后按依赖顺序执行，每次只实现一个可验收任务。
3. 用 `docs/PROGRESS.md` 记录已完成事项、测试证据和下一步；新开 Codex 对话时，让它先读本方案和进度文件。
4. 每个阶段交付可运行演示、相关测试、模型说明；未通过阶段门槛，不通过添加新实验掩盖基础问题。
5. 本文中的目录、接口与命令是拟定的工程契约，需在项目内实际实现；本文不是已经存在的代码或已通过的测试报告。

### 0.1 与原对话的关系

本文整合原对话中“面向中国大陆教材、以器材为核心、兼容自由搭建和预设实验、最终开源”的方向，并补全工程设计。以初中串并联电路形成第一个完整闭环，再逐步交付透镜、杠杆、摩擦、弹簧和平抛实验；首批同时覆盖初中与高中，但各实验仍分阶段实现。

用户已补充原对话的“首批六实验”清单。本版以该清单为准：凸透镜成像、串并联电路、杠杆平衡、滑动摩擦力、弹簧弹力与形变量、平抛运动。第 8 章按原清单顺序列出；实际开发顺序见第 9、15 章，不要求两种顺序相同。

v1.0 自行补选的欧姆定律、伏安法测电阻、反射定律三项移至后续扩展，相关器材与模型不再是 v0.1 发布前置条件。为避免混淆已有引用，保留原有项目 ID 的含义，新增杠杆及高中实验 ID；编号不必连续。

### 0.2 已核实与待核实的边界

- 已核对公开课程标准发布入口、相关教材研究机构页面、参考项目仓库介绍及许可证声明，链接见各章节和第 16 章。

- 未取得具体学校正在使用的教材实物、版次及当地实验操作评分细则。本文按主题适配，具体章节、页码和考试要求须由教师核实。

## 1. 项目目标与边界

### 1.1 用户与场景

| 用户 | 主要操作 | 预期产出 |
| --- | --- | --- |
| 初中学生 | 选择器材、搭建、测量、改变条件、记录 | 装置文件、实验数据、结论与反思 |
| 高中学生 | 在同一框架中进行更精细的测量和数据拟合 | 图线、物理量估计、误差讨论 |
| 教师 | 配置器材、设置模型和提示、投屏演示、发布模板 | 可修改的课堂实验模板与教学活动 |
| 开源贡献者 | 新增器材、实验、教材映射或求解器 | 可审核、可测试、授权清楚的贡献 |

### 1.2 必须保留的产品特征

1. **器材可复用。** 电流表、测力计、透镜等只实现一次，由多个实验组合使用。
2. **装置可编辑。** 预设实验是同一工作台中的场景文件；不是单独制作、无法拆装的动画页面。
3. **物理来自装置。** 求解器读取真实的器材、参数和连接图，不能按实验标题直接生成预期答案。
4. **实验包含测量。** 支持量程、刻度、单位、读数、记录表和图线，不只是显示公式结果。
5. **允许出现错误。** 接错线、反接电表、选择错误量程、光屏找不到像等情况有可解释的结果。
6. **适配中国大陆课堂。** 简体中文、常用器材外观、控制变量、探究过程和教材主题映射。
7. **默认本地可用。** 首版不依赖账户、云数据库、AI 接口、境外 CDN 或在线字体。
8. **公开可维护。** 原创实现与第三方授权可追溯，教师可以贡献实验模板。

### 1.3 首版范围

首版 v0.1 面向桌面和平板浏览器，采用二维场景，覆盖第 8 章六个实验：四个初中主线实验（透镜、串并联电路、杠杆、摩擦）和两个高中主线实验（弹簧弹力与形变量、平抛运动）。弹簧也可提供初中定性拓展，但高中定量活动独立配置。最低包括器材拖放、端口连接、属性编辑、开始/暂停/重置、撤销/重做、JSON 导入导出、本地保存、数据表、CSV 导出和模型说明。

暂不纳入首版：完整三维实验室、任意跨领域耦合、通用多体绳轮求解、完整流体与热传导、大学物理专题、登录与班级管理、在线协作、AI 自动批改、付费系统。高中弹簧与平抛属于首批范围，其余高中内容后续扩展。四柱滑动变阻器、欧姆定律/伏安法完整模板和反射折板不作为首版必做项。

### 1.4 成功标准

学生可以从空白工作台完成一个有效实验，而不仅能操作模板；教师可以保存模板，让另一台电脑导入并复现实验；每个实验都有独立数值基准、边界测试和教师审阅记录。仿真用于课堂探究与实验准备，不将仿真操作熟练度直接当作真实器材操作能力的证明。

## 2. 教材与课程标准适配

### 2.1 依据与适配层级

初中以《义务教育物理课程标准（2022 年版）》为基线，发布依据见[教育部通知及附件](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)。实验目录作为覆盖范围的补充依据，参见[教育部关于初中物理实验教学基本目录的介绍](https://hudong.moe.gov.cn/jyb_xwfb/moe_2082/2023/2023_zl24/202311/t20231123_1091839.html)。不能把一批核心实验当作全部实验教学内容。

高中使用《普通高中物理课程标准（2017 年版 2025 年修订）》版本字段；本次查到的版本信息见[华南师范大学国家教材建设重点研究基地页面](https://pmc.scnu.edu.cn/a/20251127/25.html)。该页面不是本方案逐条核对高中实验条目的证据。首批高中弹簧、平抛教学活动定稿前须取得标准正式全文并由教师确认；对仍使用不同版次教材的学校，保留独立映射。高中器材形态也可参考教育部发布的[《普通高中物理教学装备配置标准》JY/T 0654—2025](https://www.moe.gov.cn/srcsite/A06/s3732/202507/W020250701322477386053.pdf)，但器材配置标准不能替代课程标准或教材。

按四层组织内容：

```text
课程标准版本与主题
  └─ 本项目实验 ID
       ├─ 教学活动与器材模板
       └─ 教材映射：出版社 + 版次/出版年 + 册次 + 章节 + 可选页码
```

使用项目自有实验 ID，例如 `J-ELEC-02`；不得把自编 ID 命名为“教育部实验编号”。只有拿到可追溯正式条目后，才填写外部标准的条款号或实验编号。

### 2.2 教材策略

- 优先建立人教版主题映射，再扩展沪科版、教科版、苏科版等；不假设相同出版社的不同版次章节一致。
- 首版只承诺“适配相应物理主题与实验方法”；具体教材映射在教师核验后标记 `verified`。
- 章节名称、年级、册次、页码保存在数据中，不能写进电路求解器、光线追踪器或器材代码。
- 不复制教材插图、实验图片或整段教材文字。器材图形和实验说明自行创作，第三方素材单独核对授权。
- 不宣称官方审定、全教材覆盖或适用于所有地区实验操作考试。地方考试步骤与评分规则作为后续独立配置。

### 2.3 首批主题覆盖

| 项目实验 ID | 教学主题与主学段 | 首版适配重点 | 复用方向 |
| --- | --- | --- | --- |
| J-OPT-02 | 凸透镜成像规律／初中 | 光具座、蜡烛、三心同高、寻找清晰像 | 薄透镜及光学测量 |
| J-ELEC-01 | 串、并联电路规律／初中 | 灯泡接线、学生改接电表、比较多个位置 | 恒定电流网络、仪表影响 |
| J-MECH-02 | 杠杆平衡条件／初中 | 水平调平、挂点、力臂、力矩与多组验证 | 高中静力学与力矩 |
| J-MECH-01 | 滑动摩擦力／初中 | 匀速条件、压力与接触面性质、对照实验 | 静摩擦、动力学与能量 |
| H-MECH-01 | 弹簧弹力与形变量／高中 | 原长、载荷、弹性限度、F-x 图与劲度系数 | 弹性势能、弹簧振动 |
| H-MECH-02 | 平抛运动／高中 | 水平发射、位移与时间测量、轨迹与分运动 | 运动合成、能量分析 |

### 2.4 教学流程与模式

每个实验模板提供：实验问题 → 猜想 → 器材选择 → 搭建 → 检查 → 测量 → 数据分析 → 结论 → 误差与反思。允许教师删减提示，学生不必按唯一预设步骤才能取得数据。

| 模式 | 行为 |
| --- | --- |
| 自由搭建 | 展示该领域已实现的器材，可保存任意合法场景 |
| 引导实验 | 提供目标、器材建议、分层提示；不自动替学生接线 |
| 教师演示 | 大字号、可选显示法线/力箭头/理论量、快速切换模板 |

所有模式使用同一场景模型与求解器。理论真值、自动读数和答案显示由教师配置；学生手工录入值与仪器输出分别保存。

```text
顶部：实验名称 / 模式 / 教材主题 / 保存 / 导入导出 / 撤销重做
左侧：器材库与搜索
中间：二维实验工作台，支持缩放、平移、拖放、选中与连接
右侧：器材属性 / 仪表量程 / 操作诊断 / 模型假设
底部：实验步骤 / 记录表 / 图线 / 结论与反思
```

投屏时可折叠侧栏；窄屏切换面板，避免强行同时显示所有区域。器材需能通过“选择器材→点击放置”的替代流程加入场景，关键功能不依赖鼠标拖动或悬停。

### 4.2 基础交互约定

- 鼠标、触控笔和触屏采用 Pointer Events；拖拽过程有明确命中区域。
- 端口悬停或点选后高亮；接线前后都能看出连接终点。
- 线条交叉默认不连接，只有明确结点才连接；电线颜色不决定电气关系。
- 移动器材后导线跟随端口，不能只移动图形而丢失连接。
- 删除器材时同步删除其连接；撤销可以恢复器材、参数和连接。
- 选中器材后能通过属性面板精确输入参数与位置，单位始终可见。
- 接线、换挡和更换电阻属于可记录操作；引导模式提示断开开关，但不能后台偷偷修正学生装置。
- 连接不合法类型的端口直接解释原因；物理上可以做但有风险的接法保留并交给模型诊断。

### 4.3 测量与数据

学生可选择手工抄表或点击采集；采集数据必须带时间、器材 ID、量程、单位、配置版本和测量状态。手工值保留录入原文，计算时使用经过校验的数值，不能悄悄替换为理论真值。

图表必须明确横纵轴及单位。首批提供电路多位置读数比较、杠杆力矩比较、摩擦力与压力关系、弹簧 `F-Δx` 图、平抛 `x-t` 与 `ydrop-t²` 图。弹簧图以 Δx 为横轴、F 为纵轴，斜率单位为 N/m；平抛向下位移 ydrop 的 `ydrop-t²` 斜率为 g/2。CSV 导出中文 UTF-8，可按需加 BOM；导出用户文本时处理电子表格公式注入，避免以 `= + - @` 等开头的文本被当作公式执行。

PixiJS、Three.js 不作为首版必选项；Matter.js 只接入首批摩擦实验的受控适配层，不作为杠杆、静态弹簧和平抛的默认求解来源。已有仓库如果采用其他等价方案，应先评估迁移成本，不为了符合名词列表重写成熟模块。

### 5.2 依赖方向

```text
React 页面与器材视图
        ↓ 命令 / 选择器
编辑命令层 + SceneDocument + 教学活动数据
        ↓ 纯数据快照
场景编译器（几何 / 电气连接图 / 模型参数）
        ↓
领域求解器（电学 / 光学 / 力学，独立测试）
        ↓ SimulationSnapshot + Diagnostics
仪表测量层 → 记录表 / 图线 / 导出
```

`core` 不依赖 React、DOM 或某个绘图库；领域求解器不依赖教材章节、实验 ID 或 CSS 坐标。视图仅消费结果，实验模板只组装器材与教学要求。

### 5.3 状态边界

| 状态 | 内容 | 保存/撤销策略 |
| --- | --- | --- |
| SceneDocument | 器材、参数、连接、初始姿态、模型配置 | 保存，编辑命令可撤销 |
| RuntimeState | 仿真时间、速度、求解器内部缓存、瞬时电压电流 | 不进入编辑撤销；首版重载后从初态开始 |
| MeasurementRecord | 已采集或手工录入的数据及当时配置 | 保存；不能被后续参数修改覆盖 |
| UIState | 选中、悬停、打开面板、视口 | 视口可保存，其余按需 |
| CurriculumMetadata | 课标主题、教材映射、核验状态 | 与模板分版本维护 |

用户拖动器材完成一次手势只产生一个编辑命令；求解器每个时间步不能产生历史记录。编辑动力学初态前暂停，修改后明确重新开始；运行中的变阻器调节等允许的操作进入运行事件记录。

### 5.4 Worker 协议与确定性

消息包含 `documentRevision`、`runId`、`sequence`、`commandType` 和可序列化 payload。主线程丢弃旧 revision 或旧 runId 的结果；快速改接电路不能让慢任务覆盖新状态。

力学采用固定物理步长，例如 1/120 s；显示使用 requestAnimationFrame 插值。每帧最多执行有限追赶步数，页面隐藏后暂停或按明确策略恢复，避免把长时间卡顿当成巨大积分步。记录模型版本、初态、参数变化和随机种子，才能复现实验；首版不承诺跨浏览器逐位相同，按数值容差复现。

首版不同领域独立运行，一个场景可包含多个互不耦合的领域组件。电热、机电等耦合只在明确有对应模型与测试时开放，不能将多个引擎同时运行就称为统一多物理场。

## 6. 器材、连接与文档模型

### 6.1 器材定义与实例分离

器材定义提供类型、可编辑参数、端口、模型适配器和视图映射；实例只保存 ID、定义版本、参数和姿态。器材注册表是唯一入口，禁止把所有器材行为写进一个持续增长的 `switch` 页面组件。

下面的 TS 结构用于约定边界，具体器材参数应进一步细化为可区分联合类型或注册表类型，不能长期依赖无约束对象：

```ts
type Domain = 'electrical' | 'optical' | 'mechanical';
type PortKind = 'electrical-terminal' | 'mechanical-anchor' | 'optical-mount';
type Scalar = number | string | boolean;

interface Pose2D {
  xM: number;
  yM: number;
  rotationRad: number;
}

interface PortDefinition {
  id: string;
  kind: PortKind;
  localPositionM: { x: number; y: number };
}

interface EquipmentDefinition {
  type: string;
  definitionVersion: number;
  domain: Domain;
  ports: readonly PortDefinition[];
  parameterSchemaId: string;
  modelAdapterId: string;
  viewId: string;
}

interface EquipmentInstance {
  id: string;
  type: string;
  definitionVersion: number;
  pose: Pose2D;
  parameters: Record<string, Scalar>;
}

interface Endpoint {
  equipmentId: string;
  portId: string;
}

interface Connection {
  id: string;
  kind: 'wire' | 'rigid-mount' | 'rope';
  from: Endpoint;
  to: Endpoint;
  routeWorldM?: Array<{ x: number; y: number }>;
}

interface Diagnostic {
  code: string;
  severity: 'info' | 'warning' | 'error';
  equipmentIds: string[];
  messageKey: string;
  measurementUsable: boolean;
}
```

接口中预留绳连接，不代表首版已支持任意绳轮系统。首版未实现的连接类型在注册能力表中关闭，不能导入后假装生效。

### 6.2 连接规则

- 端口 ID 稳定，不使用显示文本或数组顺序充当长期标识。
- 导线连接端子；机械连接使用锚点；光学器件通过位置、方向和安装约束起作用，光线交点不属于“接线”。
- 电路结点由导线、显式接点与器材内部连接共同编译，几何相邻不自动导通。
- 首版每个接线柱允许多根线；显式接点使用可序列化 junction 器材。导线折点只是路线，不是电气结点。
- 一根导线连接同一电气结点时报告冗余，不制造假电阻；重复导线不改变等效电路。
- 端口类型兼容性在编辑层校验；短路、反接等电气后果由领域层判断。
- 参数变化、增删器材和改接触发相应领域重新编译；纯粹改变导线路径不必重建电气矩阵。

### 6.3 中国课堂常见器材细节

| 器材 | 首版必须实现 | 模型边界 |
| --- | --- | --- |
| 电源 | 正负端、输出电压、开关状态或外接开关 | 理想模式与有限内阻模式分开 |
| 电流表 | 负端与双正量程端、0～0.6 A / 0～3 A 示例刻度、反偏与超量程提示 | 具体刻度可配置，不把示例当作全部学校器材 |
| 电压表 | 负端与双正量程端、0～3 V / 0～15 V 示例刻度 | 理想无限内阻与有限内阻模式分开 |
| 小灯泡 | 首版必做，两个接线端、额定值、发光亮度与状态 | 使用公开参数的非线性准静态教学模型；不冒充实测钨丝特性 |
| 定值电阻 | 电路基准测试器材，阻值、额定功率可配置 | 可供自由搭建；不能替代原清单要求的灯泡实验 |
| 滑动变阻器 | 后续欧姆定律/伏安法扩展器材 | 四柱真实连接图，不是两端电阻配一个滑块；不阻断首版 |
| 光具座 | 标尺、物体、透镜与光屏可独立移动 | 世界单位为 m，显示可用 cm |
| 蜡烛与光屏 | 可独立摆放、调整高度，物体图像与清晰度可见 | 虚拟蜡烛作为物体，不增加燃烧或热学计算 |
| 平面镜与光源 | 后续反射实验器材 | 几何光学，无衍射模型；首版只需透镜的物体光源 |
| 弹簧测力计 | 挂钩、量程、指针、示数状态 | 首版为无质量、准静态测量器材 |
| 物块与接触面 | 质量、接触面性质、接触面积设置 | 首版约束于水平一维运动 |
| 杠杆、支架与钩码 | 支点、刻度挂点、调平、钩码质量与作用线、测力计拉力 | 首版采用刚性杠杆静力矩模型，允许失衡，不做通用刚体系统 |
| 弹簧、支架与钩码 | 原长、劲度系数、线性范围、挂载和长度读数 | 自研静态胡克模型，超出范围不继续伪造线性结果 |
| 小球、发射器、标尺与计时器 | 初速、发射高度、水平校准、轨迹、采样及落地事件 | 自研无空气阻力平抛模型；首版不做发射器内部机构动力学 |

后续滑动变阻器记下端为 A、B，上端为 C、D；C、D 连接滑片结点 S。滑片参数 `t∈[0,1]`，理想电阻丝段为 `R_AS=tRmax`、`R_SB=(1-t)Rmax`。接 A-B 得到固定总阻值，接 C-D 得到低阻导体，接一上端一下端才得到可调阻值。端点零阻段按理想导线合并结点，或在明确的非理想模式中使用接触电阻，不暗中添加电阻改变实验。

电表的两个正量程端不能当作两个互不相关的输入。首版模型明确定义每档有效端子与内部连接；同时误接两个正量程端时保留场景并提示“当前多端接法超出首版仪表模型”，停止该表有效读数，不能任意选择一个档位输出数字。

### 6.4 坐标、量纲与精度

- 物理计算统一 SI：m、kg、s、A、V、Ω、N；角度内部用 rad。
- 世界坐标 y 轴向上，屏幕坐标 y 轴向下，转换集中到视口模块。
- 缩放、平移和设备像素比只改变显示，不改变物理长度、力或时间。
- 物理量使用带单位的命名或量纲类型；所有输入在边界处转换，不散布 `*100` 等隐式换算。
- 求解器保存双精度；仪器按分度值、量程和模式处理显示，不先四舍五入再求解。
- 数值容差与仪器分辨率分别定义。实际读数误差不能用“求解器很精确”替代。

### 6.5 场景格式与导入

场景顶层至少包含：`schemaVersion`、`documentId`、`title`、`experimentId`（可空）、`equipment`、`connections`、`simulationConfig`、`measurementRecords`、`curriculumRef`、`provenance` 和可选 `viewport`。

`simulationConfig` 包括领域模型版本、理想/非理想配置、g、时间步、随机种子与误差开关。首版导出的是可复现实验初态与记录，不保证保存任意时刻的动态续跑状态；界面必须说明重载后从初态重新运行。

导入流程：读取文件 → 大小限制 → JSON 解析 → schema 校验 → 版本检查与迁移 → 唯一 ID/引用完整性检查 → 器材与端口能力检查 → 预览 → 替换当前文档。失败时保留现有场景，未知类型不能静默丢失。导入数据仅当数据处理，不执行代码、不加载远程脚本或用户 HTML。

初始建议限制：文件不超过 5 MiB、最多 200 个器材和 500 个连接；发布前根据性能测试调整并记录。重大未知版本拒绝导入并解释原因；已支持旧版本通过有测试的迁移器升级。分享首版使用下载/上传 JSON，在线短链接属于后续功能。

## 7. 领域物理引擎

### 7.1 共同契约

每个领域提供 `compile(document)`、`reset(initialState)`、`solve()` 或 `step(dt)`、`getSnapshot()`、`getDiagnostics()`、`dispose()`。编译产物与实时状态不写回原场景；求解失败输出结构化诊断和无效测量标志，而不是沿用上次成功的读数。

统一结果包括可观测量、器材 ID、单位、模型状态与残差；仪表测量层把真实物理量转换成指针、数字或光屏图像。测试直接调用领域模块，无需启动 React。

### 7.2 直流电路：独立 MNA 求解器

首版支持电源、灯泡、电阻、导线、开关、电流表、电压表。以修改节点分析法 MNA 建立方程，线性元件直接求解，灯泡采用受控迭代；算法可参考公开电路理论，具体实现自行编写。四柱变阻器后续扩展。暂不支持 AC、RLC 瞬态或半导体网络。

计算步骤：

1. 对导线、闭合的理想开关、理想零阻段做并查集合并。
2. 建立电阻、灯泡支路、电压源及电流测量支路；不允许把断开的支路删除后误判整电路。
3. 按电气连通分量选择数值参考点。参考点只定义电势零点，不是自动替学生加一条接地线。
4. 对电导支路盖章，对理想电压源和理想电流表增加 MNA 未知支路电流。
5. 使用带主元选择的线性求解；灯泡网络增加阻尼 Newton 迭代、最大迭代数和非线性残差检查。不收敛时返回诊断，不能沿用旧值。
6. 计算支路电流、电压、功率及仪表状态，输出拓扑诊断。

断开的独立电路之间没有确定的绝对电位差。跨接在不同浮置分量之间的理想电压表显示“电位差未定义”，不能把各自参考零点相减得到假读数。普通开路电路中，部分节点和表读数仍可能确定，需逐项判断。

**理想模式：** 理想电流表采用零伏电压源支路；理想电压表不加载被测网络。理想电源被理想导线直接短接时没有有限稳态解，返回 `IDEAL_SOURCE_SHORT`；冗余理想电压源或零阻回路也可能造成电流不唯一，应报告具体拓扑问题，不能以极小电阻“修好”后仍标称理想。

**器材模式：** 显式配置电源内阻、电流表内阻、电压表输入电阻、导线/接触电阻。短路电流由这些公开参数决定，可模拟超量程或教学保护跳闸。教学保护动作属于可见模型事件，不等于真实器材一定具有该保护功能。

示例：E=3 V，电源内阻 r=0.5 Ω，总回路电阻 0.5 Ω 时短路电流为 6 A；不能输出无穷大或把表针直接绘制到屏幕之外。超量程、反偏、断路、短路、无解和不唯一是不同状态。

电流正方向按端口约定确定。电源输出功率与电阻、灯泡等负载耗散功率应满足能量校验。电路图几何布局和导线颜色不能影响解。

**灯泡教学模型：** 首版使用单调的经验关系 `U=Rcold·I+a·I³`，Rcold>0、a≥0；按额定 Ur、Ir 与冷态电阻配置 `a=(Ur-Rcold·Ir)/Ir³`，并校验参数。该关系仅用于展示电阻随工作点变化的准静态教学现象，不声称是钨丝灯泡的精确材料定律，也不模拟热惯性或熔断过程。亮度由负载耗散功率映射，映射规则公开，不影响电路求解。实际灯泡升温或烧毁需要另行验证模型。

在额定 Ur=3 V、Ir=0.3 A、Rcold=2 Ω 的示例中，a=800/9 V/A³。两只相同灯泡串联于理想 6 V 电源时各 3 V、回路 0.3 A；并联于理想 3 V 电源时各 0.3 A、总电流 0.6 A。非相同灯泡须按实际模型重新求解，不能套用等分电压或等分电流。额定点之外还须验证非线性残差和不同参数网络。

### 7.3 几何光学

首版以二维近轴薄透镜成像为主，提供光线与器件求交、光屏检测和标尺读数。光线方向单位化；设置交点距离容差、最大传播距离和最大交互次数，防止同一界面重复命中和无限传播。镜面反射与折板属于后续实验能力。

后续镜面反射使用 `r = d - 2(d·n)n`。n 为单位法线，入射角与反射角都相对法线定义。虚像辅助线使用不同线型，并可隐藏。

薄凸透镜采用 `1/f = 1/u + 1/v`、`m = -v/u`。首版物体位于入射侧时 u>0、凸透镜 f>0，实像 v>0、虚像 v<0；若反向照明，先切换局部光轴坐标，不能混用符号。非近轴射线不应假装符合这一模型。

`u=f` 时出射光在近轴模型中平行，没有有限像距；使用“无有限像”枚举，不能把 Infinity 写进 JSON。`u<f` 时为正立放大虚像，光屏不能承接；不能把虚像贴到物体另一侧的真实光屏上。

光屏清晰度采用公开的教学近似：由多个物点采样发出的近轴光线，在光屏平面形成光斑，离焦越大，光斑展开越大；同高与偏心影响是否落入光屏范围。必须说明不模拟衍射、像差与真实照明细节。能拖动光屏寻找清晰像，而不是只判断公式像距并切换一个“清晰”布尔值。

后续反射实验关于“共面”的证据用独立的可折叠承接纸板视图表达：纸板绕法线折转后，反射光不再沿纸板传播。底层保留射线与承接平面的空间关系。这个局部几何计算不要求建设三维实验室；如果未实现，就不得把只有二维等角演示的模板标记为完整反射定律实验。此项不阻断首版透镜实验发布。

后续折射可增加 Snell 定律与全反射分支，但不能把几何光学接口用于双缝干涉并声称得到波动光学结果。

### 7.4 首版力学：四类有边界的教学模型

#### 7.4.1 滑动摩擦：Matter.js + 自研

首版摩擦实验限定水平面上的一维平动、水平拉力、无质量测力计及已配置材料参数。测力计通过匀速牵引机构或可控拉力与物块连接，不允许从屏幕拖动速度随意换算成牛顿。

- 静止时静摩擦满足 `|Fs|≤μsN`，按外力需求匹配；超出阈值转入滑动。
- 滑动时 `Fk=μkN`，方向与相对速度相反；接近零速时执行静止/滑动状态切换，防止数值抖动。
- 只有水平受力且无竖直加速度的本实验条件下 `N=mg`；后续斜面或斜拉模型需重新计算支持力。
- 匀速牵引的稳态满足 `Fpull=Fk`；加速牵引时测力计示数不能直接等同摩擦力。
- 改变接触面积时质量、材料参数不变；在本模型适用范围内不改变滑动摩擦力，并明确这是干摩擦近似。
- 粗糙程度体现为材料对参数，不把“粗糙程度”当作可直接测量的统一物理单位。

首版按原清单采用 Matter.js + 自研适配：Matter.js 管理物块形状与受限接触场景；自研模型负责一维教学摩擦、静/滑状态、牵引及测量。每个自由度明确唯一计算来源：自研模型生成的物块轨迹同步到 Matter.js 表示，不再对该物块叠加 Matter.js 的摩擦力或第二套积分。碰撞后的复杂接触不属于此模型范围。其 friction 参数不自动等于教材中的 μ，也不通过游戏引擎约束伸长直接推算精确张力；所有测量有独立物理基准。

#### 7.4.2 杠杆：自研力矩求解器

由支点与各受力点计算 `τz=rx·Fy-ry·Fx`（N·m），平衡条件为总力矩为零且支点约束承受合力；力臂为支点到力作用线的垂直距离。竖直挂钩码时 F=mg，水平杠杆的力臂才等于沿杆刻度距离。测力计斜拉须按真实作用线计算，不把沿杆距离当成力臂。

首版采用质量可忽略的刚性杠杆，教师可切换有自重配置；有自重时重力作用于质心并计入力矩。支点反力单独求出；无可承担该反力的有效支撑时报告约束无效。先在不挂载情况下调平，再比较多组挂载；调平不能在后台抵消后来施加的力矩。

给定挂载时返回顺/逆时针力矩、残差与平衡状态；测力计目标读数只在其挂点、拉力方向和约束足以唯一确定时求解。非平衡时保留初始装置并显示转动趋势，不输出假平衡示数；若制作转动提示，明确为状态示意，不当作时间准确的转动动力学。

#### 7.4.3 弹簧：自研静态胡克模型

首版为支架上悬挂的竖直、无质量理想弹簧，具有原长 L0、劲度系数 k>0、最大线性伸长和额定载荷；钩码总质量包括挂载盘等配置。静态平衡 `F=mg=kΔx`，总长 `L=L0+Δx`。学生通过刻度尺测 L0 与 L，再计算 Δx，不能直接把总长当作形变量。

支架连接、方向与挂载图决定模型是否可用。超出线性范围或载荷时返回范围外状态，不继续以 F=kΔx 预测真实材料；未实现塑性变形就不绘制有定量含义的永久伸长。首版不做振动/阻尼计算，挂载变化直接更新静态平衡，任何过渡动画仅作示意并且期间不采样。

#### 7.4.4 平抛：自研运动模型

首版忽略空气阻力，重力恒定；发射器提供水平初速度 v0 和高度 h>0，小球视为质点。世界坐标 y 向上，发射点 `(x0,y0)`：`x=x0+v0t`、`y=y0-gt²/2`、`vx=v0`、`vy=-gt`。教学表中的向下位移为 `ydrop=y0-y`，不可与世界 y 混用。

在水平地面高度 yground 下，`t_hit=sqrt(2h/g)`、`range=v0·t_hit`，其中 h=y0-yground；以事件时间准确截断落地，不能等下一个显示帧才停止。发射器未水平时提示超出当前实验模型，不能悄悄把倾角归零。改变视口缩放不能改变米和秒。

物理模型按发射时保存的初态解析求值；固定时间采样驱动轨迹和计时器，绘图帧率不改变结果。运行中调整发射参数只作用于下一次发射。用户通过标尺、定时采样或时间门读出位置与时间；自动真值显示遵循教师设置，不把整条轨迹直接当作学生完成测量。

通用绳、滑轮和连接体仍是后续器材，需要长度约束、张力、无质量/有质量假设及误差测试；不得把绳只画成线就声称完成滑轮组仿真。

### 7.5 理想、测量与误差模式

三者分开配置：物理模型是否理想、仪器是否有限分辨率、是否添加随机误差。理想电路也可以用指针仪表练习读数；有限内阻也可以配理想数字读数。

默认基准测试关闭随机误差。启用误差时记录种子、分布、幅度与作用位置；给测量值加随机扰动不能改变物理守恒关系。教学报告明确哪些差异来自仪表加载、量化、手工估读、离焦或模型近似，不把一切都称作随机误差。

## 8. 首批六个实验的实施规格

以下按用户补充的原清单顺序列出。主学段为四项初中、两项高中；技术基础指参考或实现路线，不自动授权直接复制外部代码。首版六项全部完成后才进入 v0.1 发布验收。

### 8.1 J-OPT-02：探究凸透镜成像规律（初中）

**技术基础：** Ray Optics；优先参考其光线与器件模型，可在逐文件授权核验后复用合适模块，通过适配器接入本项目工作台。

**目标：** 通过移动蜡烛、透镜和光屏，在不同物距下寻找像，记录像的正倒、大小、虚实与像距。

**器材：** 光具座、虚拟蜡烛、凸透镜、光屏、刻度尺。三者可独立移动并调整高度；刻度尺可独立放置，光具座也带刻度。

**操作：** 先调三心同高，设置 f=10 cm；分别探索 u>2f、u=2f、f<u<2f、u=f、u<f；实像区间移动光屏寻找清晰像；虚像区间通过观察辅助视图查看，不在光屏上呈现可承接的虚像。

| 物距 u | 预期像距 v | 放大率 m | 现象 |
| --- | --- | --- | --- |
| 30 cm | 15 cm | -0.5 | 倒立缩小实像 |
| 20 cm | 20 cm | -1 | 倒立等大实像 |
| 15 cm | 30 cm | -2 | 倒立放大实像 |
| 10 cm | 无有限像 | 不适用 | 近轴出射光平行 |
| 5 cm | -10 cm | +2 | 正立放大虚像，光屏无法承接 |

**记录：** 物距、像距、屏位置、像的特点、是否清晰及对齐状态。理论辅助线可关闭，不能让屏自动跳到答案位置。

**边界：** u 接近 f、物体与透镜重合、超出光具座长度、光屏错侧、未同高、光线未落入光屏。允许“当前范围内找不到清晰像”。

**完成标准：** 光屏位置影响离焦程度；光线、公式、像和记录共享同一模型；无穷像距不进入序列化数据。

### 8.2 J-ELEC-01：探究串并联电路规律（初中）

**技术基础：** CircuitJS1 的拓扑和求解思路；首版独立实现 MNA 与灯泡教学模型，不默认合入 GPL 代码。

**目标：** 自主搭建两类电路，测量不同位置，比较串联电流相等、电压分配及并联支路电压相等、电流汇合关系。

**器材：** 电源、两个或多个小灯泡、开关、导线、电流表、电压表。定值电阻可用于独立基准与对照，不能替代灯泡主模板。

**操作：** 从空白场景取器材接线；断开开关后改接电表；测三处电流与电源、两灯泡电压；更换为不同参数灯泡重复；填写记录后归纳规律。只用相同灯泡不足以证明支路电流或串联电压普遍相等，提示应引导比较不同灯泡。

**基准 A（线性求解器）：** 理想电源 3 V，R1=10 Ω、R2=20 Ω。串联 I=0.1 A，U1=1 V、U2=2 V；并联 I1=0.3 A、I2=0.15 A、总电流 0.45 A，支路电压均 3 V。

**基准 B（灯泡主模板）：** 按第 7.2 节模型，两只相同灯泡 Ur=3 V、Ir=0.3 A、Rcold=2 Ω。串联使用理想 6 V 电源：I=0.3 A、每灯 3 V；并联使用理想 3 V 电源：每支路 0.3 A、总电流 0.6 A。两种接法的电源设置不同，必须分别保存并标明。并联总电流可选 0～3 A 量程，避免把恰好满量程当作推荐操作。

**记录：** 接法、电源设置、测点、电流、电压、量程、灯泡参数配置和状态；亮度只作辅助现象，不代替测量。另用不同参数灯泡测试一般关系，验证 KCL/KVL 与非线性支路残差。

**边界：** 开关断开、电流表反接、某支路断路、电流表误并联、导线交叉未连接、更换量程、灯泡超出模型范围、迭代不收敛。接法必须由连接图识别。

**完成标准：** 灯泡串并联都可从空白搭建；图形亮度与耗散功率一致；重载后连接和结果可复现；线性与灯泡基准、一般网络残差均达标。

### 8.3 J-MECH-02：探究杠杆平衡条件（初中）

**技术基础：** 自研力矩求解器。

**目标：** 通过改变力和力臂，以多组数据探究平衡条件，理解力臂是到力作用线的垂直距离。

**器材：** 杠杆、支架、钩码、测力计；杠杆带等距挂点与刻度，测力计可选择挂点和拉力方向。

**操作：** 空载调至水平平衡；在不同侧、不同位置挂钩码；改变质量与挂点寻找平衡，记录至少三组；用测力计替换一侧钩码，比较竖直与斜拉。只有学生明确请求时才显示理论力矩，不自动移动挂点或修正拉力。

**基准：** g=10 N/kg、忽略杠杆自重。支点左侧 0.20 m 挂 0.10 kg 钩码，右侧 0.10 m 挂 0.20 kg 钩码，反向力矩大小各 0.20 N·m。用右侧 0.10 m 处竖直向下拉力代替右钩码，平衡所需拉力 2 N；拉力与杆夹角 30° 时所需 4 N，对应力臂 0.05 m。

**记录：** 力、挂点、方向、力臂、力矩、是否平衡与杠杆自重模式。先由测量形成数据，再检查力矩关系。

**边界：** 挂点在支点、力作用线通过支点、两力同向力矩、无有效支架、超量程、未空载调平、有自重时质心力矩、改变支点位置。无解或失衡不能输出“已平衡”。

**完成标准：** 平衡/失衡由真实受力点与作用线计算；能完成钩码和测力计两种搭建；斜拉时不把沿杆距离当作力臂；保存加载保留连接和受力方向。

### 8.4 J-MECH-01：探究滑动摩擦力（初中）

**技术基础：** Matter.js + 自研教学模型；按第 7.4.1 节明确计算归属，避免重复摩擦和积分。

**目标：** 在水平匀速拉动条件下，用测力计示数比较滑动摩擦力与压力、接触面性质的关系；可拓展接触面积的对照。

**器材：** 木块、不同接触面、弹簧测力计；补充砝码用于改变压力，提供可选匀速牵引器及速度提示作为教学辅助。

**操作：** 同一表面改变总质量；同一压力改变材料对；同质量同材料改变接触面积；每次进入滑动稳态再读取。记录控制条件，比较加速阶段和匀速阶段。

**基准：** g=10 N/kg、μk=0.2。总质量 0.5 kg 与 1.0 kg 时 N=5/10 N，稳态摩擦力为 1/2 N；质量 0.5 kg、μk=0.4 时为 2 N。显示 g 的配置值，不把教学近似写成自然常数的唯一值。

**边界：** 未进入匀速、静摩擦未突破、测力计超量程、材料不一致、斜拉超出模型。引导任务提示采样时机，但可保留带“非稳态”标签的数据。

**完成标准：** 表针读取真实牵引力；匀速、加速、静止可区分；接近零速时无持续抖动；缩放不改变牛顿读数；Matter.js 适配没有第二套力或轨迹覆盖教学模型。

### 8.5 H-MECH-01：探究弹簧弹力与形变量（高中）

**技术基础：** 自研弹簧模型。

**目标：** 测量载荷下弹簧长度，计算相对原长的形变量，在弹性线性范围内探究 F 与 Δx 的关系并估计劲度系数。

**器材：** 弹簧、支架、钩码、刻度尺；标明挂载盘质量或配置为零，原长与载荷均可读取和记录。

**操作：** 安装弹簧与刻度尺；无载时测 L0；依次增加已知质量钩码并读取静态长度；在模型线性范围内采集不少于五个工作点；记录卸载复测点；计算 Δx，绘制 `F-Δx` 图并求斜率。初中拓展模式只提供较简化的定性任务。

**基准：** L0=0.10 m、k=20 N/m、g=10 N/kg，挂载盘质量为零，最大线性伸长配置为 0.06 m。总质量 m=0/0.025/0.05/0.075/0.10 kg 时，F=0/0.25/0.5/0.75/1 N，Δx=0/0.0125/0.025/0.0375/0.05 m，总长 L=L0+Δx；图线斜率为 20 N/m。

**边界：** 把 L 当作 Δx、刻度尺零点偏移、挂载盘质量遗漏、支架未连接、k≤0、超线性范围、超载、过渡示意期间采样。超限后不继续沿直线生成“实测”数据；卸载回复仅对有效弹性模型作承诺。

**完成标准：** 学生能摆放器材、加载、读尺并形成数据；形变量与总长分开；显示与拟合使用同一记录；范围外数据明确标记，不编造材料的真实塑性行为。

### 8.6 H-MECH-02：探究平抛运动（高中）

**技术基础：** 自研运动模型。

**目标：** 通过水平发射、定时位置采样与位移测量，探究水平方向匀速、竖直方向自由落体及二者的合成。

**器材：** 小球、发射器、标尺、计时器；可开启等时位置标记，提供水平校准与发射高度设置。

**操作：** 摆放发射器并校准水平；测量相对地面的发射高度；设置初速并发射，暂停或逐步查看固定时刻位置；记录不少于三组落地前 t、x、向下位移 ydrop；作 `x-t`、`ydrop-t²` 图；固定高度改变初速、固定初速改变高度开展对照。

**基准：** g=10 m/s²、发射点距水平地面 h=1.25 m、v0=2 m/s。t=0.1/0.2/0.3 s 时水平位移 x=0.2/0.4/0.6 m，向下位移 ydrop=0.05/0.20/0.45 m；落地时间 0.5 s、水平射程 1 m。`x-t` 斜率为 2 m/s，`ydrop-t²` 斜率为 5 m/s²。

**边界：** h≤0、g≤0、发射器未水平、v0=0 的自由落体对照、运行中修改下次发射参数、显示帧跨越落地、暂停后恢复、重复发射、视口缩放。记录以发射时初态为准，不能让修改参数改写已发生轨迹。

**完成标准：** 小球运动、计时、位置标记与图线共享同一时间源；落地事件准确截断；学生可使用标尺和计时器测量而非只看公式；30/60 FPS 显示下固定时刻结果一致。

## 11. 测试与验收标准

### 11.1 分层测试

| 层 | 重点 | 有意义的验证 |
| --- | --- | --- |
| 单元 | 公式、数值、单位、状态切换 | 由手算或独立推导给定基准值，避免测试复制实现 |
| 领域集成 | 连接图→求解→仪表 | 同一电路改布局结果不变；错误拓扑给出明确诊断 |
| 文档 | 保存、加载、迁移、校验 | round-trip、旧版本迁移、坏文件不破坏当前场景 |
| 交互 | 拖放、接线、换挡、撤销 | 端口跟随器材；一次拖动一次撤销；触屏替代操作 |
| 端到端 | 六实验全过程 | 空白搭建、测量、导出、重载、再次测量 |
| 教学审阅 | 内容、器材、误区 | 教师判断提示与读数是否支持真实探究 |

### 11.2 数值门槛

以下是首版受限基准范围的工程门槛，不代表对任意规模病态网络或任意真实器材承诺同等精度：

- 小型、尺度适当的理想线性电路：内部值误差满足 `|actual-expected| ≤ 1e-9 + 1e-6×|expected|`（各物理量按其 SI 单位）；归一化 KCL 残差、功率平衡残差分别不超过 `1e-6`。
- 灯泡非线性网络：第 8.2 节额定点基准内部电压/电流误差满足上述绝对加相对容差；非相同灯泡网络归一化 KCL、KVL、元件非线性关系和功率残差均不超过 `1e-6`；不收敛必须报告且禁止正常采样。
- 透镜：第 8.1 节远离焦点的有限像距测试误差不超过 `1e-6 m`；临近焦点单独测试分类与数值稳定性，不套用固定绝对误差。
- 杠杆：已知载荷的解析力矩测试误差不超过 `1e-9 N·m`，反求拉力误差不超过 `1e-6 N`；平衡判定采用公开的绝对/相对力矩阈值，测量模式另按仪器分辨率判断。作用线过支点时不能除以零力臂。
- 摩擦静态/稳态解析测试误差不超过 `1e-6 N`；积分动态在约定稳定采样窗口内示数相对误差不超过 1%，并通过步长减半收敛检查。
- 弹簧：有效范围内 Δx、L 的解析值误差不超过 `1e-6 m`；无误差基准的 F-Δx 拟合劲度系数相对误差不超过 `1e-6`。超限、无支撑或过渡示意时不产生正常测量记录。
- 平抛：固定采样时刻的位置误差不超过 `1e-6 m`、落地事件时间误差不超过 `1e-6 s`；解析速度与能量关系满足相应归一化残差门槛 `1e-6`。改变绘图帧率后同一物理时刻结果不变。
- 后续反射扩展再验收射线角误差 `1e-6 rad` 与量角器分辨率；首版不要求交付反射折板。
- 显示值误差按仪器分度值或数字分辨率单独判断；不能要求 0.1 A 分度的表盘显示 1e-6 A 精度。
- 开启随机误差的测试固定种子；检验范围、可复现性和配置传播，不要求每次噪声恰好抵消。

归一化残差的分母须记录，例如使用 `max(参考尺度, 相关支路绝对值和)`；零电流情形用绝对容差，避免除零。不同量纲不共享一个没有单位的全局 epsilon。

### 11.3 必测异常与不变量

**电学：** 开路、短路、反接、超量程、浮置分量、重复导线、导线交叉、冗余理想源、多量程端误接、相同/不同灯泡、零电压、非法灯泡参数、不收敛与同一拓扑改变绘图位置。变阻器三类接法及端点属于后续扩展验收。

**光学：** u=f、u<f、接近焦点、光屏错侧、未同高、独立刻度尺、物体/透镜重合、光具座范围限制、设备缩放。镜面、掠射和折板离面后续再测。

**杠杆：** 水平平衡、不同挂点、同向力矩、斜拉、力作用线过支点、移动支点、无支撑、有自重、超量程与未调平；旋转/平移画面不改变实际力矩。

**摩擦：** 静止匹配静摩擦、突破最大静摩擦、反向运动、接近零速、稳态、加速、超量程；同质量材料下接触面积变化；Matter.js 与自研模型不重复施力/积分。

**弹簧：** 零载、挂载盘质量、原长与总长区分、尺零点偏移、无支架、k≤0、超线性范围、超载、有效范围内卸载回复；范围外不输出未验证的塑性结果。

**平抛：** 水平校准、无效高度/重力、v0=0 对照、定时采样、落地截断、暂停/恢复、重复发射与运行中修改下次参数。改变帧率不改变固定物理时刻结果，地面以下不继续生成有效轨迹。

**文档与调度：** 重复 ID、缺端口、未知器材、未知版本、超大文件、非法数值、旧 Worker 回包、重置后迟到回包、反复进入退出实验无重复计时器或事件监听。

### 11.4 性能与兼容

在 M1 明确一台实际可获得的基准电脑，记录 CPU、内存、操作系统、浏览器版本和构建模式。测试结果必须附这些条件，不能把单机结果写成所有教学电脑的保证。

建议 v0.1 目标：

- 标准场景含不超过 50 个器材、100 条连接；电路数值目标不超过 100 个未知量；光学目标不超过 300 条可见射线、每条最多 20 次交互。
- 在记录的基准机上持续操作至少 5 分钟，平均显示帧率不少于 30 FPS，交互响应 P95 小于 100 ms。
- 超出计算预算时降低射线显示采样、限制追赶步数或输出复杂度提示，不能静默降低物理求解精度。
- 支持实际验收时的稳定版 Edge、Chrome；平板至少验证一种触屏浏览器。其他浏览器列出实际测试状态。
- 1366×768 投屏和 1920×1080 桌面可完成所有操作；平板通过折叠面板避免关键按钮被遮挡。
- 运行时不依赖在线字体、分析 SDK 或远程仿真资源。初次加载所需网络与加载后离线能力分别说明。

### 11.5 无障碍与可用性

关键按钮有文本名称和焦点样式；颜色之外还有线型/符号区分；端口可通过列表或键盘选择；表盘提供可读测量摘要，显示真值与否遵循教师设置。数据表可键盘编辑，图表有数据表替代。避免闪烁和仅靠动画才能理解的信息。

## 12. 存储、部署与离线使用

首版提供静态网站部署和本地构建包，不需要数据库。教师分享完整 JSON 场景文件，学生导入后本地编辑；导入前提示替换当前工作台，未保存内容可以先导出。

课堂离线的最低交付是“构建产物 + 本地 HTTP 启动说明”，不能保证直接双击 `index.html` 即可正常加载 ES 模块、Worker 和资源。Service Worker/PWA 是可选增强；若实现，需测试缓存版本更新、旧资源清理和错误恢复，不能把缓存故障带进课堂。

分享文件默认不携带姓名、学号、班级或设备标识。教师报告中需要身份信息时让学校明确其存储与使用方式；首版不上传测量数据、不添加行为跟踪。

不把密钥放进前端环境变量并声称安全。以后若有 AI、云存储或账户功能，另设后端与权限设计，不影响核心实验离线运行。

## 13. 开源协作与变更约束

### 13.1 新器材的贡献要求

提交必须包含定义、参数校验、端口说明、模型假设、视图、示例场景和有意义的测试。涉及第三方来源时添加授权台账。仪器还须说明量程、分度值、内部模型、异常读数和测量值来源。

### 13.2 新实验的贡献要求

实验应包含项目 ID、学段主题、可核验的课程映射、问题与猜想、器材清单、操作建议、空记录表、独立数值基准、常见错误、模型限制及教师审阅状态。只有模板和步骤而无新物理能力的实验，不应复制一套求解器。

### 13.3 对 Codex 与维护者的代码规则

1. 修改、重构或优化任何代码时，完整保留已有中文与英文注释，包括序号注释、块注释和行尾注释；不删除、精简或改写。
2. 若代码移动，原注释完整迁移到对应新代码之后或上方。
3. 只修改当前任务需要的逻辑；无关代码、空格、换行与格式保持原样，避免整文件格式化。
4. Windows PowerShell 5.1 读取文本显式使用 `Get-Content -Encoding UTF8`，不把默认显示乱码当作编码错误。
5. 仓库根目录已有 `.codegraph/` 时，在定位或理解代码前优先使用 CodeGraph；没有则跳过，不自行建立索引。
6. 不覆盖用户未提交的修改、不为了通过测试删除失败用例、不生成假验收报告。
7. 每个任务交付最小必要改动；发现超出范围的问题记录为后续事项，除非它阻断本任务。

这些规则应纳入项目实际 `AGENTS.md`；存在更具体的仓库规则时一并读取。

## 14. 风险与待决策事项

| 问题 | 对实施的影响 | 处理方式 |
| --- | --- | --- |
| 教材具体版次未知 | 无法承诺章节和页码精确匹配 | 主题先行，映射保留 pending，教师核验后升级 |
| 工具引擎与教学理想模型不同 | 可能看起来合理但测量错误 | 领域模型独立测试，Matter.js 结果不直接充当教材真值 |
| 想一次支持所有器材与实验 | 架构和验证成本失控 | 六实验范围固定，新增项走模型与验收流程 |
| 理想电路奇异或浮置 | 产生错误读数、NaN 或卡死 | 拓扑诊断、残差检测、无效测量状态 |
| 指针读数与内部数值混淆 | 学生无法练习估读、误差被掩盖 | 测量层独立，真值/显示值/学生录入值分开 |
| 光学只画理想像不模拟光屏 | 实验退化为公式展示 | 实现光屏位置、离焦与对齐的实际效果 |
| 用电阻代替灯泡或用亮度代替读数 | 漏掉原清单器材并可能形成错误规律 | 灯泡模型公开，测量来自电路解，含不同灯泡对照 |
| 杠杆距离、弹簧长度与物理量混淆 | 错把沿杆距离当力臂、总长当形变量 | 保留作用线、原长和实际读尺步骤 |
| 平抛动画与采样时钟分离 | 位移/时间图线无法对应真实运动 | 解析运动、计时、轨迹和落地使用同一初态与时间源 |
| copyleft 或素材授权不匹配 | 影响开源分发 | 首版独立实现核心，逐项核对引入内容 |
| 课堂网络与设备差异 | 演示中断或交互不流畅 | 本地资源、离线包、基准机测试与复杂度预算 |

M0 必须落地的决策：包管理器与版本、原创代码许可证、基准机器、首批教材核验对象、默认理想/器材模式、是否第一版就启用 Worker。未决定时可按本文默认值继续做可逆的小样，但不能在发布记录中隐去待核验项。

```text
验收：第 8.6 节基准、重复发射、暂停恢复、帧率不变量与端到端流程通过。
```

### 任务 14：两学段教师试用、性能与离线（M7）

```text
对原清单六实验完成统一检查：透镜、灯泡串并联、杠杆、摩擦、弹簧、平抛。
检查投屏、大字号、触屏、键盘、单位、提示和从空白搭建能力。
在记录的基准机上测性能、长时间运行和反复切换场景，处理泄漏及旧回包。
提供静态构建产物与本地 HTTP 运行说明，验证断网使用，不依赖境外 CDN。
生成覆盖初中与高中教师的试用清单，记录实际反馈，不编造通过结论。
修复阻碍完成实验或造成物理误解的问题。
验收：第 11.4～11.6 节有真实证据；两学段核验及剩余限制明确记录。
```

### 任务 15：开源发布准备（M7）

```text
审查实际源码、构建产物和素材来源，完善 LICENSE、适用 NOTICE 与 THIRD_PARTY。
记录各引入项版本/提交、范围、修改和声明位置；未核验内容不纳入发行。
完善 README、器材/实验贡献指南、模型说明和六实验演示步骤。
执行实际类型检查、测试、端到端和构建；失败如实记录并修复阶段问题。
确认首批含四个初中和两个高中实验，不能把高中两项遗漏后宣称全六项完成。
整理 v0.1 发布说明、已知限制与可本地审核的发布包。
本任务只准备交付物；是否上传或发布远端按用户实际授权执行。
验收：第 11.6 节逐项有证据，待教师核验或未审授权的项目不能写成通过。
```

### 任务 16：后续扩展（M8/M9，首版验收后）

```text
从第 9.2 节选择一项后续实验，本次只实现这一项并明确 ID。
初中可选欧姆定律、伏安法测电阻、反射定律；高中可选其他运动/电学专题。
涉及欧姆定律/伏安法时新增真实四柱变阻器与相应接法、量程和控制变量检查。
涉及反射定律时新增镜、量角器与承接纸板共面证据，不只做二维等角演示。
复用已有器材、场景、测量与数据模块；新增模型给出假设、手算基准和边界测试。
教材版次和章节由教师核验，未知信息保留 pending。
验收：新实验符合贡献规范且首批六实验回归通过；不重建另一套工作台。
```
